# 微电网特种调控装置（MUPC）通信管理模块功能清单

## 1. 核心架构与角色

* **架构定位**：作为MUPC“异构双核心模块主控架构”中的**非实时处理核心**，与“实时控制核心模块”协同工作。
* **核心职责**：承担“**大脑**”决策角色，负责北向通信、策略计算、AI优化、OTA升级等非实时任务，并将指令下达给负责“小脑”执行的实时控制模块。**不参与任何硬实时控制**（如10kHz电流环）。

## 2. 通信网关功能

### 2.1 北向通信（对上）

* **协议支持**：

  * 全面兼容**IEC 60870-5-104**协议，用于与**调度主站**通信。
  * 支持**IEC 61850-7-420**协议，用于**配电自动化**。
  * 支持**MQTT over TLS**协议，用于连接**物联平台**或虚拟电厂（VPP）聚合平台。
* **安全要求**：

  * 支持**国密SM2/SM4算法**对通信数据进行加密。
  * 支持**双向证书认证**。
  * 所有控制指令需经过**纵向加密认证**，符合电力监控系统安全防护规定。

### 2.2 南向通信（对下及横向）

* **与台区设备通信**：

  * 支持通过**RS485**或**HPLC**与**台区智能融合终端（TTU）** 通信。
  * 支持通过RS485/以太网与**光伏逆变器、充电桩、柔性负荷控制装置**进行通信。
* **与本地系统对接**：支持通过RS485/以太网与**本地消防控制系统**对接。
*

### 2.3 本地运维通信

* 支持**星闪（NearLink）、Wi-Fi或蓝牙**，用于本地配置、日志导出、固件升级。
* 支持通过标准**浏览器访问远程运维管理界面**。

## 3. 数据处理与边缘计算功能

### 3.1 数据汇聚与上送

* **数据采集**：周期性从实时控制模块读取电气量、电池数据（SOC、SOH、温度）。
* **高频遥测**：采集并上报遥测量，刷新率**≥1Hz**。
* **数据上报**：将处理后的数据通过IEC 104、MQTT等协议上报，实现“可观、可测”。
* **故障录波**：记录故障前后特定时间段波形，支持本地存储或上报。

### 3.2 指令接收与下发

* **调度指令执行**：接收并验证来自调度主站或VPP平台下发的指令，如有功/无功设定值、一次调频参数、远程启停命令等。
* **指令转发**：将验证合法的指令转发给实时控制模块执行，实现“可调、可控”。

### 3.3 本地策略引擎（保底与基础模式）

* **功能描述**：作为AI引擎的备份与补充，运行预设的、确定性的控制策略，确保在AI未启用或失效时系统仍可安全可靠运行。
* **策略库**：

  * **固定策略**：如基于固定时间表的削峰填谷、定时需量控制、防逆流保护。
  * **反应式策略**：基于实时测量的电压越限、三相不平衡度进行无功补偿。
* **协同模式**：与AI引擎采用“**AI优先，本地兜底**”机制。AI指令需经本地策略安全校验；AI异常时，自动无缝切换至本地策略模式。

### 3.4 数据存储与管理

* **运行数据存储**：在本地数据库中存储历史运行数据、告警日志、事件记录。
* **设备信息管理**：管理并上送设备台账信息。

## 4. 系统协同与状态管理功能

* **核间通信**：通过RJ45网线与实时控制模块进行快速数据交换。
* **状态监控**：通过看门狗与心跳机制，监控实时控制模块运行状态，异常时触发复位或告警。
* **资源管理**：提供稳定的内存、进程、网络管理，确保长期运行不宕机（**MTBF ≥ 50,000小时**）。

## 5. 平台与基础功能

* **操作系统**：运行基于**openEuler的**国产操作系统**，需支持一定的实时性。
* 硬件选型：采用基于RK3588的硬件。
* **安全启动**：支持安全启动验证，确保系统镜像完整性。
* **远程维护**：支持**OTA（空中下载）升级**。
* **边缘计算框架**：具备插件化边缘计算框架，支持功能按需加载。

## 6. 人工智能边缘优化引擎功能（高级）

### 6.1 多源数据融合与场景自适应

* **数据融合**：周期性融合实时电气数据、电池数据、外部信息（电价、气象、调度指令）。
* **场景识别**：基于负荷与电源特征，自动识别“**农网灌溉模式**”、“**工商业模式**”等，并动态调整优化目标权重。
* **性能**：为AI推理分配专用计算资源（如NPU），确保**推理延迟<100ms**。

### 6.2 超短期预测能力

* **光伏预测**：运行**LSTM/TCN**等模型，输出未来15-30分钟光伏出力预测曲线。
* **负荷预测**：区分基荷与可调负荷，预测未来短期负荷曲线，对灌溉等冲击负荷进行概率预测。

### 6.3 基于强化学习的多目标实时决策

* **核心算法**：采用**多智能体深度强化学习（如MADDPG/PPO）** 框架。
* **状态空间**：[实时数据， 预测数据， 电价， 需量状态， 电能质量指标]。
* **动作空间**：[电池有功设定(`P_batt_set`)， 装置无功设定(`Q_batt_set`)， 分相补偿系数]。
* **多场景奖励函数**：

  * **农网模式**：奖励 = `光伏消纳奖励 + 电压治理奖励 - 电池损耗惩罚 - 变压器过载惩罚`。
  * **工商业模式-自主套利**：奖励 = `电价差收益 - 电池损耗成本`。
  * **工商业模式-需量控制**：奖励 = `需量罚金减免`。
  * **工商业模式-虚拟电厂(VPP)**：奖励 = `辅助服务收益 + 响应精度奖励`。
  * **工商业模式-极致绿色**：奖励 = `绿电消纳比例 + 碳排减少量`。

### 6.4 在线学习与专家干预

* **在线微调**：在系统闲时，利用本地新运行数据对AI策略网络进行微调，实现自适应优化。
* **可视化与干预**：

  * 展示AI决策逻辑、预测曲线、实时奖励。
  * 支持专家**手动调整优化目标权重**，或**强制切换运行模式**。
  * 模型更新支持**A/B测试**与**安全回滚**。

### 6.5 与控制系统协同接口

* **指令下发**：AI引擎输出的最优指令，通过核间通信下达给实时控制模块。
* **性能需求**：从AI决策完成到指令下发至实时控制模块，整体延迟**<200ms**。

---

### **功能索引与关联**

* **基础控制流**：`通信网关(2) -> 数据汇聚(3.1) -> 本地策略引擎(3.3) -> 指令下发(3.2) -> 实时控制模块`
* **智能优化流**：`通信网关(2) + 数据汇聚(3.1) -> AI数据融合(6.1) -> AI预测(6.2) -> AI决策(6.3) -> (经本地策略引擎3.3安全校验) -> 指令下发(3.2) -> 实时控制模块`
* **保底机制**：当AI引擎(6)失效时，系统自动、无缝地降级至**本地策略引擎(3.3)** 接管控制，保障台区基本安全与运行。

此清单定义了MUPC通信管理模块从基础连接到高级智能的完整能力图谱，是其作为新型配电台区“智能边缘大脑”的核心软件架构。

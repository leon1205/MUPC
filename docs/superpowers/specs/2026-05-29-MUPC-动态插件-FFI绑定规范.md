# MUPC 动态插件 FFI 绑定规范

**版本**: v1.0
**日期**: 2026-05-29
**状态**: ACTIVE

---

## 1. 概述

本文档定义 MUPC 动态插件的 FFI 绑定规范，插件开发者需按照此规范实现 `create_plugin` 和 `plugin_meta` 两个导出函数。

### 1.1 插件接口

插件必须实现 `device_trait::Plugin` trait：

```rust
pub trait Plugin: Send + Sync {
    fn meta(&self) -> PluginMeta;
    fn init(&self, config: serde_json::Value) -> Result<(), PluginError>;
    fn start(&self) -> Result<(), PluginError>;
    fn stop(&self) -> Result<(), PluginError>;
    fn shutdown(self: Box<Self>) -> Result<(), PluginError>;
}
```

### 1.2 必需导出符号

| 符号 | 类型 | 说明 |
|------|------|------|
| `create_plugin` | `unsafe extern "C" fn() -> *mut dyn Plugin` | 插件工厂函数 |
| `plugin_meta` | `unsafe extern "C" fn() -> PluginMeta` | 获取插件元信息 |

## 2. 插件开发指南

### 2.1 项目结构

```
my-plugin/
├── Cargo.toml
├── src/
│   └── lib.rs
└── build.rs (可选)
```

### 2.2 Cargo.toml 配置

```toml
[package]
name = "my-plugin"
version = "1.0.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]  # 必须编译为动态库

[dependencies]
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

### 2.3 插件实现示例

```rust
use serde::{Deserialize, Serialize};
use device_trait::{Plugin, PluginError, PluginMeta};
use std::sync::Arc;

// 插件配置（用户定义）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MyPluginConfig {
    pub device_path: String,
    pub timeout_ms: u64,
}

// 插件实现
pub struct MyPlugin {
    meta: PluginMeta,
    config: Option<MyPluginConfig>,
}

impl MyPlugin {
    pub fn new() -> Self {
        Self {
            meta: PluginMeta::new(
                "my-plugin",
                "1.0.0",
                "Developer",
                "My custom plugin for MUPC",
            ),
            config: None,
        }
    }
}

impl Plugin for MyPlugin {
    fn meta(&self) -> PluginMeta {
        self.meta.clone()
    }

    fn init(&self, config: serde_json::Value) -> Result<(), PluginError> {
        // 解析配置
        let cfg: MyPluginConfig = serde_json::from_value(config)
            .map_err(|e| PluginError::init_failed(format!("配置解析失败: {}", e)))?;

        // 存储配置
        // 注意：实际实现需要使用 Arc<Mutex<>> 等线程安全方式
        self.config = Some(cfg);

        tracing::info!("MyPlugin 初始化完成");
        Ok(())
    }

    fn start(&self) -> Result<(), PluginError> {
        tracing::info!("MyPlugin 启动");
        Ok(())
    }

    fn stop(&self) -> Result<(), PluginError> {
        tracing::info!("MyPlugin 停止");
        Ok(())
    }

    fn shutdown(self: Box<Self>) -> Result<(), PluginError> {
        tracing::info!("MyPlugin 关闭");
        Ok(())
    }
}

// ========== FFI 导出函数 ==========

/// 插件工厂函数
///
/// # Safety
/// 必须确保在调用此函数前没有其他插件实例存在
#[no_mangle]
pub unsafe extern "C" fn create_plugin() -> *mut dyn Plugin {
    let plugin = MyPlugin::new();
    Arc::new(plugin) as Arc<dyn Plugin>
    // 使用 Arc::into_raw 转换，但这里直接返回 trait object
    // 实际实现需要 Box::into_raw(Box::new(plugin)) as *mut dyn Plugin
    Box::into_raw(Box::new(MyPlugin::new())) as *mut dyn Plugin
}

/// 获取插件元信息
///
/// # Safety
/// 此函数是线程安全的
#[no_mangle]
pub unsafe extern "C" fn plugin_meta() -> PluginMeta {
    MyPlugin::new().meta()
}
```

### 2.4 完整的 FFI 导出代码

```rust
use device_trait::{Plugin, PluginError, PluginMeta};
use std::sync::Arc;

// ... 插件实现 ...

// ========== FFI 导出 ==========

/// 插件工厂函数
///
///MUPC 调用此函数创建插件实例
///
/// # Returns
/// 插件实例的原始指针
///
/// # Safety
/// 调用者负责在不需要时调用 shutdown() 并释放内存
#[no_mangle]
pub unsafe extern "C" fn create_plugin() -> *mut dyn Plugin {
    let plugin = MyPlugin::new();
    Box::into_raw(Box::new(plugin)) as *mut dyn Plugin
}

/// 获取插件元信息
///
/// 供 MUPC 在加载前获取插件基本信息
///
/// # Returns
/// 插件元信息结构体副本
#[no_mangle]
pub unsafe extern "C" fn plugin_meta() -> PluginMeta {
    MyPlugin::new().meta()
}
```

## 3. 类型映射

### 3.1 PluginMeta 结构体

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | `String` | 插件名称 |
| `version` | `String` | 插件版本 |
| `author` | `String` | 作者 |
| `description` | `String` | 描述 |

### 3.2 PluginError 变体

| 变体 | 说明 |
|------|------|
| `LoadFailed(String)` | 加载失败 |
| `InitFailed(String)` | 初始化失败 |
| `StartFailed(String)` | 启动失败 |
| `StopFailed(String)` | 停止失败 |
| `NotFound(String)` | 资源不存在 |
| `MetaError(String)` | 元信息错误 |
| `Other(String)` | 其他错误 |

### 3.3 PluginState 枚举

| 状态 | 说明 |
|------|------|
| `Loaded` | 已加载 |
| `Initialized` | 已初始化 |
| `Running` | 运行中 |
| `Stopped` | 已停止 |
| `Unloaded` | 已卸载 |

## 4. 生命周期

### 4.1 加载流程

```
1. PluginLoaderImpl::load() 调用
2. dlopen/libloading 加载 .so/.dll
3. 获取 create_plugin 符号
4. 调用 create_plugin() 获取插件实例
5. 获取 plugin_meta 符号
6. 调用 plugin_meta() 获取元信息
7. 插件注册到 PluginRegistry
```

### 4.2 初始化流程

```
1. 用户调用 loader.init(plugin_name, config)
2. 调用 plugin.init(config)
3. 更新插件状态为 Initialized
```

### 4.3 启动流程

```
1. 用户调用 loader.start(plugin_name)
2. 调用 plugin.start()
3. 更新插件状态为 Running
```

### 4.4 停止/卸载流程

```
1. 用户调用 loader.stop(plugin_name)
2. 调用 plugin.stop()
3. 更新插件状态为 Stopped

5. 用户调用 loader.unload(plugin_name)
6. 插件从注册表移除
7. Library 自动卸载
```

## 7. 错误处理

### 7.1 返回错误

```rust
fn init(&self, config: serde_json::Value) -> Result<(), PluginError> {
    Err(PluginError::init_failed("配置无效"))
}

fn start(&self) -> Result<(), PluginError> {
    Err(PluginError::start_failed("设备未连接"))
}
```

```rust
        warn!("使用默认配置");
    }
    Ok(())
}
```

### 9.2 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 符号未找到 | 未使用 `#[no_mangle]` | 添加 `#[no_mangle]` |
| 类型不匹配 | FFI 类型错误 | 检查函数签名 |
| 内存泄漏 | 未正确释放 Box | 使用 `Box::into_raw` |
| 线程安全 | trait 对象非线程安全 | trait 有 `Send + Sync` bound |

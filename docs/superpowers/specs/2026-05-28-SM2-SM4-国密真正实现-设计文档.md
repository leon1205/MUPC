## 1. 概述

### 1.1 背景

当前 `security` 模块中的 SM2/SM4 实现使用 `ring` 库的 P-256/AES-256-GCM 曲线进行模拟，不符合国家密码管理局发布的国密标准。Phase 2 交付报告中明确标注：

> **注意**：当前为模拟实现，生产环境需替换为真正的国密算法（如 gmsm crate）

### 1.2 目标

使用纯 Rust 国密库 **gmsm** 替换现有模拟实现，提供真正的 SM2/SM3/SM4 国密算法支持。

### 1.3 范围

| 模块 | 功能 | 优先级 |
|------|------|--------|
| sm2.rs | SM2 签名/验签、密钥交换 | 必须 |
| sm4.rs | SM4 分组加密/解密 | 必须 |
| sm3.rs | SM3 消息摘要 | 高 |
| cert.rs | SM2 证书支持 | 中 |
| tls.rs | SM2 TLS 支持 | 中 |

## 3. 模块设计

### 3.1 sm2.rs - SM2 签名与验签

**接口设计**（兼容现有调用）：

```rust
// 现有接口（保持兼容）
pub fn sm2_sign(data: &[u8], private_key: &str) -> Result<Vec<u8>>;  // private_key: PEM 字符串或文件路径
pub fn sm2_verify(data: &[u8], signature: &[u8], public_key: &str) -> Result<bool>;

// 新增接口（支持完整 SM2 功能）
pub fn sm2_key_generate() -> Result<Sm2KeyPair>;  // 返回 Sm2KeyPair，不是元组
pub fn sm2_derive_shared_key(key_pair: &Sm2KeyPair, peer_public_key: &[u8]) -> Result<Vec<u8>>;  // ECDH 风格
```

**SM2 曲线参数**：国密局指定的 `sm2p256v1` 曲线（gmsm 默认）

**gmsm 0.14 实现方式**：

```rust
use gmsm::{Sm2, Sm2KeyPair};

pub fn sm2_sign(data: &[u8], private_key_pem: &str) -> Result<Vec<u8>> {
    let key = Sm2KeyPair::from_pem(private_key_pem)
        .map_err(|e| GmError::KeyLoadFailed(format!("密钥加载失败: {}", e)))?;

    let signature = key.sign(data)
        .map_err(|e| GmError::SignFailed(format!("签名失败: {}", e)))?;

    Ok(signature.to_bytes())
}

pub fn sm2_key_generate() -> Result<Sm2KeyPair> {
    Sm2KeyPair::generate(&mut OsRng)
        .map_err(|e| GmError::KeyGenerationFailed(format!("密钥生成失败: {}", e)))
}

pub fn sm2_derive_shared_key(key_pair: &Sm2KeyPair, peer_public_key: &[u8]) -> Result<Vec<u8>> {
    use gmsm::Ecdsa;
    let peer_key = Sm2::from_public_key_slice(peer_public_key)
        .map_err(|e| GmError::KeyLoadFailed(format!("公钥解析失败: {}", e)))?;
    key_pair.derive_shared_secret(&peer_key)
        .map_err(|e| GmError::KeyDeriveFailed(format!("共享密钥派生失败: {}", e)))
}
```

### 3.2 sm4.rs - SM4 对称加密

**接口保持不变**：

```rust
// 现有接口（保持不变）
// 密钥长度: 16 字节 (128位)，不是 32 字节
pub fn sm4_gcm_encrypt(data: &[u8], key: &[u8], iv: &[u8]) -> Result<Vec<u8>>;
pub fn sm4_gcm_decrypt(data: &[u8], key: &[u8], iv: &[u8]) -> Result<Vec<u8>>;
pub struct Sm4Key { ... }

// 新增接口
pub fn sm4_cbc_encrypt(data: &[u8], key: &[u8], iv: &[u8]) -> Result<Vec<u8>>;  // CBC 模式
pub fn sm4_cbc_decrypt(data: &[u8], key: &[u8], iv: &[u8]) -> Result<Vec<u8>>;
```

**安全警告：IV 重用风险**
> **重要**：GCM 模式下 IV 严禁重用！同一 IV 用于加密多条消息会导致密文可被攻击者解密。每次加密应使用不同的 IV（推荐 12 字节随机数）。

**gmsm 实现方式**：

```rust
use gmsm::{Sm4, Mode::Cbc, padding::Pkcs7};

pub fn sm4_cbc_encrypt(data: &[u8], key: &[u8], iv: &[u8]) -> Result<Vec<u8>> {
    // 密钥长度验证: 16 字节
    if key.len() != 16 {
        return Err(GmError::InvalidKeyLength(format!("SM4 密钥必须为 16 字节，当前为 {} 字节", key.len())));
    }
    let cipher = Sm4::new(key.into())
        .map_err(|e| GmError::EncryptFailed(format!("密钥创建失败: {}", e)))?;

    cipher.encrypt(Mode::Cbc(iv.into()), data, Pkcs7)
        .map_err(|e| GmError::EncryptFailed(format!("加密失败: {}", e)))
}
```

### 3.3 sm3.rs - SM3 消息摘要（新建）

> **状态**：sm3.rs 文件需新建，gmsm 已提供完整实现

```rust
use gmsm::Sm3;

pub fn sm3_hash(data: &[u8]) -> Result<Vec<u8>> {
    let mut hasher = Sm3::new();
    hasher.update(data);
    Ok(hasher.finalize())
}
```

**标准依据**：GM/T 0004-2012《SM3 密码杂凑算法》

## 4. 错误处理

### 4.1 现有错误类型（保持不变）

```rust
#[derive(Debug, thiserror::Error)]
pub enum GmError {
    #[error("密钥加载失败: {0}")]
    KeyLoadFailed(String),

    #[error("密钥生成失败: {0}")]
    KeyGenerationFailed(String),

    #[error("密钥派生失败: {0}")]
    KeyDeriveFailed(String),

    #[error("签名失败: {0}")]
    SignFailed(String),

    #[error("验签失败: {0}")]
    VerifyFailed(String),

    #[error("加密失败: {0}")]
    EncryptFailed(String),

    #[error("解密失败: {0}")]
    DecryptFailed(String),

    #[error("证书验证失败: {0}")]
    CertVerifyFailed(String),

    #[error("无效格式: {0}")]
    InvalidFormat(String),

    #[error("无效密钥长度: {0}")]
    InvalidKeyLength(String),

    #[error("无效参数: {0}")]
    InvalidParam(String),
}
```

### 4.2 新增错误映射

gmsm 错误 → GmError 映射：

| gmsm 错误类型 | GmError | 说明 |
|--------------|---------|------|
| `InvalidKey` | `KeyLoadFailed` | 密钥格式错误或解析失败 |
| `SignError` | `SignFailed` | 签名操作失败 |
| `VerifyError` | `VerifyFailed` | 验签失败 |
| `EncryptionError` | `EncryptFailed` | 加密失败 |
| `DecryptionError` | `DecryptFailed` | 解密失败 |
| `ParseError` | `InvalidFormat` | 格式解析错误 |
| `InvalidParameter` | `InvalidParam` | 参数无效 |
| `KeyGenerationError` | `KeyGenerationFailed` | 密钥生成失败 |
| `KeyDeriveError` | `KeyDeriveFailed` | 密钥派生失败 |

## 5. 兼容性设计

### 5.1 接口兼容性

**原则**：保留现有接口签名，仅替换底层实现。

现有代码：
```rust
use security::sm2::{sm2_sign, sm2_verify};
use security::sm4::{sm4_gcm_encrypt, sm4_gcm_decrypt};
```

**注意**：新增接口（如 `sm2_key_generate`、`sm2_derive_shared_key`）参数语义与旧接口不同，调用方需按新签名调整。

### 5.2 Feature Flag

```toml
[features]
default = ["real_gmsm"]
real_gmsm = ["dep:gmsm"]
# fake_gmsm 通过条件编译实现:
# #[cfg(not(feature = "real_gmsm"))] 使用 ring 模拟实现
# 模拟实现用于 CI 测试和开发环境，无需 gmsm 依赖
fake_gmsm = []
```

**实现方式**：
```rust
#[cfg(feature = "real_gmsm")]
mod sm2_impl {
    use gmsm::{Sm2, Sm2KeyPair};
    // gmsm 实现...
}

#[cfg(not(feature = "real_gmsm"))]
mod sm2_impl {
    // 使用 ring P-256 模拟，仅用于测试
    // 生产环境必须启用 real_gmsm
}
```

## 10. 安全设计

### 10.1 IV 重用防护

> **安全警告**：GCM 模式 IV 重用会导致密文可被攻击者解密！

**对策**：
- 每次加密使用 12 字节随机 IV
- 使用单调递增计数器（适用于流式加密）
- 实现 IV 管理机制，防止重放

### 10.2 敏感数据清除

建议使用 `zeroize` crate 安全清除敏感数据：

```rust
use zeroize::Zeroizing;

let key = Zeroizing::new(sensitive_data);
 // 使用后自动清零
```

| SM3 | GM/T 0004-2012 | SM3 密码杂凑算法 |

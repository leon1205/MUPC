## 1. 产品概述

### 1.1 背景

Phase 1 完成了北向通信网关（IEC 104）和核心架构设计，建立了与调度主站、配电自动化的通信能力。Phase 2 将扩展南向通信能力，支持与台区设备（TTU、光伏逆变器、充电桩、柔性负荷等）的直接通信，并增强安全机制。

### 1.2 目标

- 建立统一的南向设备抽象层，支持多协议插件化接入
- 实现 RS485、HPLC 等南向通信能力
- 引入 IEC 61850-7-420 协议支持配电自动化
- 集成 MQTT 协议支持物联平台接入
- 实施国密 SM2/SM4 安全机制

### 1.3 范围

| 类别 | 内容 |
|------|------|
| **南向通信** | RS485 驱动、HPLC 驱动、设备抽象层 |
| **协议插件** | IEC 61850-7-420、MQTT |
| **安全组件** | 国密 SM2/SM4、证书认证、TLS |
| **平台扩展** | 插件化架构、动态加载 |

### 2.2 架构模式

采用 **核心层 + 插件层** 的混合架构：

- **核心层**：提供基础服务和公共能力，对插件无直接依赖
- **插件层**：通过 trait 接口与核心层解耦，支持运行时动态加载/卸载

| 组件 | 技术选型 |

| 序列化 | `serde` + `serde_json` |
| 密码学 | `GmSSL` / `ring` |
| MQTT | `rumqttc` |

#### 4.1.1 Device Trait（设备抽象）

```rust
/// 设备状态
#[derive(Debug, Clone, PartialEq)]
pub enum DeviceStatus {
    Online,
    Offline,
    Error(String),
}

/// 设备数据帧
#[derive(Debug, Clone)]
pub struct DataFrame {
    pub device_id: String,
    pub timestamp: u64,
    pub data: Vec<u8>,
    pub quality: DataQuality,
}

#[derive(Debug, Clone, PartialEq)]
pub enum DataQuality {
    Good,
    Invalid,
    Reserved,
}

/// 设备抽象接口
pub trait Device: Send + Sync {
    /// 读取设备数据
    fn read(&self) -> Result<DataFrame, DeviceError>;

    /// 写入数据到设备
    fn write(&self, data: &[u8]) -> Result<(), DeviceError>;

    /// 获取设备状态
    fn status(&self) -> Result<DeviceStatus, DeviceError>;

    /// 设备唯一标识
    fn device_id(&self) -> &str;

    /// 设备类型
    fn device_type(&self) -> &str;
}

#[derive(Debug, thiserror::Error)]
pub enum DeviceError {
    #[error("设备离线: {0}")]
    Offline(String),

    #[error("通信超时: {0}")]
    Timeout(String),

    #[error("数据校验失败: {0}")]
    ChecksumFailed(String),

    #[error("协议错误: {0}")]
    ProtocolError(String),

    #[error("设备忙: {0}")]
    Busy(String),
}
```

#### 4.1.2 PluginLoader Trait（插件加载器）

```rust
/// 插件元信息
#[derive(Debug, Clone)]
pub struct PluginMeta {
    pub name: String,
    pub version: String,
    pub author: String,
    pub description: String,
}

/// 插件接口
pub trait Plugin: Send + Sync {
    /// 插件元信息
    fn meta(&self) -> PluginMeta;

    /// 初始化插件
    fn init(&self, config: serde_json::Value) -> Result<(), PluginError>;

    /// 启动插件
    fn start(&self) -> Result<(), PluginError>;

    /// 停止插件
    fn stop(&self) -> Result<(), PluginError>;

    /// 销毁插件（释放资源）
    /// 使用 Box<Self> 确保可通过 trait object 调用
    fn shutdown(self: Box<Self>) -> Result<(), PluginError>;
}

#[derive(Debug, thiserror::Error)]
pub enum PluginError {
    #[error("插件加载失败: {0}")]
    LoadFailed(String),

    #[error("插件初始化失败: {0}")]
    InitFailed(String),

    #[error("插件启动失败: {0}")]
    StartFailed(String),

    #[error("插件停止失败: {0}")]
    StopFailed(String),

    #[error("插件不存在: {0}")]
    NotFound(String),
}

/// 插件加载器接口
pub trait PluginLoader: Send + Sync {
    /// 加载插件
    fn load(&self, plugin_path: &str, config: serde_json::Value) -> Result<(), PluginError>;

    /// 卸载插件
    fn unload(&self, plugin_name: &str) -> Result<(), PluginError>;

    /// 获取已加载插件列表
    fn list(&self) -> Vec<PluginMeta>;

    /// 获取插件实例
    fn get(&self, plugin_name: &str) -> Option<Arc<dyn Plugin>>;
}
```

#### 4.1.3 MessageBus Trait（消息总线）

```rust
/// 消息主题
#[derive(Debug, Clone, Hash, PartialEq, Eq)]
pub struct Topic(String);

impl Topic {
    pub fn new(s: impl Into<String>) -> Self {
        Self(s.into())
    }
    pub fn as_str(&self) -> &str {
        &self.0
    }
}

/// 消息封装
#[derive(Debug, Clone)]
pub struct Message {
    pub topic: Topic,
    pub payload: Vec<u8>,
    pub timestamp: u64,
}

/// 消息订阅者
pub trait MessageHandler: Send + Sync {
    fn handle(&self, msg: Message);
}

/// 消息总线接口
pub trait MessageBus: Send + Sync {
    /// 发布消息
    fn publish(&self, msg: Message) -> Result<(), BusError>;

    /// 订阅主题
    fn subscribe(&self, topic: Topic, handler: Arc<dyn MessageHandler>) -> Result<(), BusError>;

    /// 取消订阅
    fn unsubscribe(&self, topic: &Topic) -> Result<(), BusError>;
}

#[derive(Debug, thiserror::Error)]
pub enum BusError {
    #[error("主题不存在: {0}")]
    TopicNotFound(String),

    #[error("发布失败: {0}")]
    PublishFailed(String),

    #[error("订阅失败: {0}")]
    SubscribeFailed(String),
}
```

|----------|----------|------|------|------|

### 5.4 HPLC 通信参数（Phase 3）

> **备注**：HPLC（宽带电力线载波）技术在 Phase 2 阶段暂无成熟开源 Rust 库支持，技术方案暂不固化。Phase 2 将仅完成设备抽象接口预留，实现延后至 Phase 3。

**技术方案（预留）**：

| 参数 | 规格 |
|------|------|
| 调制方式 | OFDM（正交频分复用），支持 BPSK/QPSK/16QAM/64QAM |
| 通信频段 | 0.7 MHz - 3 MHz |
| 物理层速率 | 2 Mbps - 10 Mbps（自适应） |
| 最大帧长 | 1500 字节 |
| 设备抽象 | `HplcDevice` trait（预留），继承自 `Device` trait |
| 典型应用 | 台区全覆盖场景，替代 RS485 布线困难区域 |

**预留接口**：

```rust
/// HPLC 设备配置
#[derive(Debug, Clone, serde::Deserialize)]
pub struct HplcConfig {
    pub local_mac: String,        // 本地 MAC 地址
    pub network_id: u16,          // 网络 ID（PAN ID）
    pub channel: u8,              // 工作信道（0-15）
    pub tx_power_dbm: i8,         // 发射功率（dBm）
}

/// HPLC 设备接口（预留 Phase 3 实现）
pub trait HplcDevice: Device {
    /// 加入网络
    fn join_network(&self, network_id: u16) -> Result<(), HplcError>;

    /// 断开网络
    fn leave_network(&self) -> Result<(), HplcError>;

    /// 读取相位信息
    fn read_phase(&self) -> Result<PhaseInfo, HplcError>;

pub enum HplcError {
    #[error("网络加入失败: {0}")]
    JoinFailed(String),

    #[error("网络断开失败: {0}")]
    LeaveFailed(String),

    #[error("相位读取失败: {0}")]
    PhaseReadFailed(String),
}
```

## 6. 安全要求

### 6.1 国密算法

| 算法 | 用途 | 要求 |
|------|------|------|
| **SM2** | 数字签名、密钥交换 | 必需 |
| **SM3** | 消息摘要 | 必需 |
| **SM4** | 对称加密 | 必需 |

### 6.2 证书管理

- **双向证书认证**：客户端和服务端均需验证对方证书
- **证书格式**：X.509 v3，支持 SM2 签名算法
- **证书存储**：文件系统（PEM 格式），路径可配置
- **证书轮换**：支持运行时证书更新

### 6.3 传输安全

| 场景 | 传输要求 |
|------|----------|
| MQTT | MQTT over TLS 1.2+ |
| IEC 61850 MMS | TLS 1.2+ |
| RS485 | 物理层安全（暂无加密） |
| 插件加载 | 插件签名验证（可选） |

### 6.4 密钥管理

- SM2 私钥：仅本地存储，禁止网络传输
- SM4 密钥：定期轮换（可配置周期，默认 30 天）
- 密钥存储：文件系统权限控制（600）

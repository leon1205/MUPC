# S3b-1a · 调度器硬化 — M-11 offline 慢站降频 + FC04 input regs + per-station baud 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 硬化 mupc-southd 调度器三项能力：① §10.2 M-11「offline 慢站指数退避降频」落地（当前仅登记未实现）；② 寄存器块支持 FC04 input registers（`RegBlockConf.func`，rs485-plugin 侧 FC04 读已存在但 southd 未暴露）；③ per-station 波特率 `baud_rate`（当前 Rs485PortBus 硬编码 9600）——均为不依赖厂方点表的框架收尾。

**Architecture:** 三项都在 mupc-southd crate 内 + core_config 段内 validate 扩展。baud 因「同口共享物理口波特率 + Rs485Device 无动态切波特 API」设计为**站级字段 + 同口一致性校验**（同 port 各站 baud_rate 必须相同，startup 每口用首站 conf open 天然口级生效）。M-11 退避状态复用既有 `Station.offline_count`：DueCalc 增纯逻辑 `delay_station`，scheduler poll 失败后把该站 next_due 按指数后移。FC04 走 `StationBus` 独立方法 `read_input`，MockBus 用独立 input 键避免与既有 holding 测试冲突。

**Tech Stack:** Rust、tokio、serde、rs485-plugin（`read_input_registers_from` FC04 + Config.baud_rate）、mupc-data-processing（RegFormat 解码，FC03/FC04 同格式同解码）。

**设计合同：** 02 §10 `[DESIGN_APPROVED: 2026-09-08]`（§10.2 M-11 口调度预算、§10.8 L-4 请求级 slave、§10.3 south_stations schema）。范围不依赖厂方语义点表（BMS/空调/消防点表 → S3b-2）。

- [ ] **Step 2: 段内 validate 加同口 baud 一致性**

`SouthStationsConfig::validate()`（config.rs:88）在既有各站检查后（循环结束前或后）加同口一致性检查。在循环内收集 `port → baud`，循环后检查同 port 各站 baud 全等：

```rust
        // 同口 baud 一致性：物理共享口波特率（Rs485Device 无动态切波特，同口只能一个波特率）。
        // 同 port 的站 baud_rate 必须相同，否则 Err（startup 每口用首站 conf open，异 baud 会被静默忽略）。
        let mut port_bauds: Vec<(&str, u32)> = Vec::new();
        for s in &self.stations {
            if let Some((_, prev_baud)) = port_bauds.iter().find(|(p, _)| *p == s.port.as_str()) {
                if *prev_baud != s.baud_rate {
                    return Err(format!(
                        "south_stations: 站 {} port {} baud_rate={} 与同口其它站 {} 不一致（同口共享物理波特率，须统一）",
                        s.id, s.port, s.baud_rate, prev_baud
                    ));
                }
            } else {
                port_bauds.push((s.port.as_str(), s.baud_rate));
            }
        }
        Ok(())
```

- [ ] **Step 3: MockBus 加 input 响应键 + read_input + input_calls**

现状 MockBus：`responses: HashMap<(u8,u16), Vec<u16>>`（holding 键）+ `fail_next: Vec<(u8,u16)>` + `calls: Vec<(u8,u16,u16)>`。加独立 input 存储避免与 holding 键冲突（同 (slave,addr) 可 FC03/FC04 并存）：

```rust
    /// input 读响应（FC04）：(slave, addr) → 寄存器。与 responses（FC03）独立键——同一
    /// (slave,addr) 可同时有 holding/input 两套（Modbus FC03/FC04 是不同寄存器空间）。
    input_responses: std::sync::Mutex<std::collections::HashMap<(u8, u16), Vec<u16>>>,
    /// input 读失败队列（模拟超时；消费即清）
    input_fail_next: std::sync::Mutex<Vec<(u8, u16)>>,
    /// FC04 读调用清单（测试断言）
    pub input_calls: std::sync::Mutex<Vec<(u8, u16, u16)>>,
```

`new()` 初始化三项。加方法：
```rust
    /// 预置 FC04 input 读响应。
    pub fn put_input(&self, slave: u8, addr: u16, regs: Vec<u16>) {
        self.input_responses.lock().unwrap().insert((slave, addr), regs);
    }
    /// FC04 读失败一次（队列；消费即清）。
    pub fn fail_input_once(&self, slave: u8, addr: u16) {
        self.input_fail_next.lock().unwrap().push((slave, addr));
    }
    /// FC04 读调用次数。
    pub fn input_call_count(&self, slave: u8, addr: u16) -> usize {
        self.input_calls.lock().unwrap().iter()
            .filter(|&&(s, a, _)| s == slave && a == addr).count()
    }
```

impl StationBus for MockBus 加 `read_input`（镜像 read_holding，用 input 存储）：
```rust
    async fn read_input(&self, slave: u8, addr: u16, count: u16) -> Result<Vec<u16>, BusError> {
        self.input_calls.lock().unwrap().push((slave, addr, count));
        let to_fail = {
            let mut q = self.input_fail_next.lock().unwrap();
            if let Some(pos) = q.iter().position(|&(s, a)| s == slave && a == addr) {
                q.remove(pos);
                true
            } else {
                false
            }
        };
        if to_fail {
            return Err(BusError::Read { slave, addr, count, reason: "mock 超时".into() });
        }
        self.input_responses.lock().unwrap().get(&(slave, addr)).cloned()
            .ok_or_else(|| BusError::Read { slave, addr, count, reason: "mock input 未预置".into() })
    }
```

### Task 4: scheduler.rs — M-11 offline 慢站指数退避降频

**Files:**
- Modify: `mupc/crates/mupc-southd/src/scheduler.rs`

**背景**：scheduler 模块头（:7-10）登记「offline 慢站指数退避」为 S3b 未落地。当前 `due_round` 只按 interval 推进 next_due，offline 站每轮都尝试（每轮最多一次块超时，early-break 已钳制但持续失败站仍高频试、占口预算）。§10.2 M-11 要求：慢站按 offline 降频，不拖累同口关键站 cadence。

**设计**：退避状态复用 `Station.offline_count`（已 saturating + 恢复清零）。`DueCalc` 增纯逻辑 `delay_station(station_index, now_ms, extra_ms)`——把该站 next_due 后移到 `now_ms + extra_ms`（若现 next_due 更晚则不动）。`poll_station` 返回 `bool`（成功 true/失败 false）；`run_port_round` 对失败站算退避 extra 并调 `delay_station`。

**退避公式**：`extra = interval_ms << min(offline_count - 1, MAX_SHIFT)`（offline_count≥1；MAX_SHIFT=5 → 封顶 32×interval）。offline_count 在 poll 后（handle_failure 已 +1）从 state 读。

- [ ] **Step 1: DueCalc 增 delay_station（纯逻辑）**

```rust
    /// 退避：把站 next_due 后移到 `now_ms + extra_ms`（若现 next_due 已更晚则不动）。
    /// scheduler 在站 poll 失败后调用（offline 慢站降频，§10.2 M-11）。
    pub fn delay_station(&mut self, station_index: usize, now_ms: u64, extra_ms: u64) {
        if let Some(e) = self.entries.iter_mut().find(|e| e.station_index == station_index) {
            let target = now_ms.saturating_add(extra_ms);
            if e.next_due < target {
                e.next_due = target;
            }
        }
    }
```

- [ ] **Step 3: run_port_round 对失败站退避**

```rust
    async fn run_port_round(&self, port_i: usize, now_ms: u64) {
        let runner = &self.runners[port_i];
        let due = runner.calc.lock().unwrap().due_round(now_ms);
        if due.is_empty() {
            return;
        }
        let mut failed: Vec<usize> = Vec::new();
        for poll in due {
            let ok = self.poll_station(poll.station_index, runner.bus.clone()).await;
            if !ok {
                failed.push(poll.station_index);
            }
        }
        // M-11：失败站退避（读 state 的 offline_count 已由 handle_failure +1）
        if !failed.is_empty() {
            let mut calc = runner.calc.lock().unwrap();
            for idx in failed {
                let (interval, oc) = {
                    let st = self.state.read().unwrap();
                    let s = &st[idx];
                    (s.conf.interval_ms, s.offline_count)
                };
                let shift = oc.saturating_sub(1).min(MAX_BACKOFF_SHIFT);
                let extra = interval.saturating_mul(1u64 << shift);
                if extra > 0 {
                    calc.delay_station(idx, now_ms, extra);
                }
            }
        }
    }
```
（一次锁 state 读失败站组更优——可先整体读：`let stats: Vec<(u64,u32)> = { state.read(): failed.map(|i|(s.conf.interval_ms, s.offline_count)) };` 再算。实现者选清晰写法。注意勿持 state 锁跨 calc 锁——分开快取。）

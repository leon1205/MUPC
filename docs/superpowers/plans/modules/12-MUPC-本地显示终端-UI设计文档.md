## 1. 文档目的与读法

本文件给出开发可直接照做的**触摸式本地 HMI 视觉与交互规范**，覆盖：导航框架、6 页布局、可复用触摸控件集、破坏性操作强确认、三态与异常视觉、全屏用字表、与 PRD 验收逐条呼应、与 LVGL 的可映射性、需真机验证项。**不做**：数据获取 / 裁决（mupcd 域值化）、通道形态、渲染栈与字体加载实现、任何源代码。

**铁律（对齐 PRD §5）**：源不可得 → 显式「不可得」，任何区块**不得用 0 / 陈旧值 / 臆测值冒充实时真值**。
**铁律（本版新增，对齐 PRD T-1/F12）**：**全屏零文本输入**——6 页所有交互均由「选项列表 / 分段控件 / 多选 / 步进器 / 确认对话框」完成，**不得出现任何文本输入控件或虚拟键盘**（含中文 / 字母 / 数字软键盘）。

## 2. 设计原则

### 2.1 触摸优先（人机工程尺寸，对齐 TT-08）

| 常量 | 值 | 说明 |
|------|-----|------|
| 最小触摸目标 | **48×48 px** | ≈ 7.6 mm；**所有**可点控件下限 |
| 关键操作目标 | **64×64 px** | ≈ 10 mm；保存 / 恢复默认值 / 联锁释放 / M1 授权 / 导航项 / 返回 |
| 相邻可点控件间距 | **≥ 16 px** | 通用 |
| 破坏性 / 生效性操作与「取消 / 返回」间距 | **≥ 48 px** | 强制 |
| 控件本体高度（按钮 / 步进器 / 分段 / Chip） | **48 px（次） / 64 px（主 / 关键）** | 见 §5 |

- 触摸目标**不等于**视觉图形尺寸：图标可 28 px，但承载它的可点对象必须撑满 48×48（LVGL 中即该 `lv_obj` 的 `lv_obj_set_size(w, 48); (h, 48)` 或 `lv_obj_set_ext_click_area`；图标作为子 `lv_image` / `lv_label` 居中）。
- 控件横向排布一律使用 **LVGL Flex 布局**（`lv_obj_set_layout(obj, LV_LAYOUT_FLEX)` + `lv_obj_set_flex_flow(obj, LV_FLEX_FLOW_ROW)`，`lv_obj_set_flex_grow` 均分）或显式设计常量（§3.5），**禁止裸数值**（LVGL review 检查项）。

### 2.2 就地可读（0.5–1.5 m，对齐 NF-04）

- 目标阅读距离 0.5–1.5 m；1.5 m 处舒适可读字符高约 40 px 起。
- 字号硬约束（PRD §4.2.2）：**主读数 ≥ 64 px**、**过程量 ≥ 32 px**、**标注 / 辅助 ≥ 24 px**。
- **v1.0 的 20 px 字号下限在本版废止**：全屏最小字号提升至 **24 px**（原 REG 编号、图例、刻度等弱注由 20 px 统一升至 24 px，或直接删减）。

### 2.3 信息层级（三档扫读）

| 档 | 用途 | 字号 | 页面落点 |
|----|------|------|----------|
| **L1 主读数（1 s 扫读）** | SOC 数值、PCS 状态词、联锁总态 | 96–148 px | P1、P4 |
| **L2 过程量（2–3 s 确认）** | 三相 P / I、触发源明细、审计结果 | 32–64 px | P1、P4、P5 |
| **L3 标注 / 辅助（按需细看）** | 源标签、角标、图例、单位、说明行 | 24–28 px | 全页 |

层级不得互相压挤：L1 区块之间留 ≥ 24 px 视觉缝隙；数值区不留装饰性渐变。

### 2.4 零文本输入约束下的交互范式（对齐 T-1 / F12）

**核心口径**：把「零文本输入」从纪律要求变成**类型约束**——所有可写字段的输入语义被穷举为下表 7 类，**不存在「自由文本」这一类**，因此界面上**无处可放文本框**。

| 输入语义 | 替代控件 | 本期使用点 | 越界防护 |
|----------|----------|------------|----------|
| 枚举 · 单选 | **分段控件 SegmentedControl** | 日志级别（P2 配置）、时间预设区间（P3 / P5） | 选项封闭，无非法值 |
| 枚举 · 多选 | **多选 Chip 组** | 日志级别多选、模块多选（P3）；审计操作类型多选（P5） | 选项封闭 |
| 数值 · 有界 | **步进器 Stepper（− 值 +）** | 端口 1–65535、心跳 1–60 s、上报周期 ≥1 s（P2） | `−` 在 `value==min` 时 `enabled:false`，`+` 在 `value==max` 时 `enabled:false`——**越界值在控件层不可达**（TT-03） |
| IPv4 | **四段数字步进** | IEC 104 监听地址（P2） | 每段 0–255 硬约束 |
| 日期 / 时间 | **日期 + 时间 选项式步进**（年 / 月 / 日 / 时 / 分 五列步进） | 日志与审计「自定义起止」（P3 / P5） | 分量封闭 |
| 布尔 | **开关 Switch**（**本期 6 页无使用点，预留给后续**） | — | — |
| 确认 / 取消 | **对话框按钮** | 全部写操作 | 默认焦点在「取消」 |

**明确不提供的输入方式**：自由文本搜索（T-1 不做）、关键字过滤、任何软键盘、任何文件 / 导出入口（T-2 不做）。因此 P3 日志页与 P5 审计页**都不存在搜索框**——不是「隐藏了搜索框」，而是**没有这个控件**。

**硬性检查项（LVGL）**：全项目**不得**出现 `lv_keyboard` / `lv_textarea` / `lv_spinbox`（**步进器一律 `lv_button` + `lv_label` 组合**，见 §5.3「零文本输入红线」）——判据 = **界面不存在任何可编辑文本区**——由 **CI 静态扫描断言**固化（技术设计 §11.4）。

### 2.5 破坏性操作的强确认视觉（对齐 TT-09 / F14.3）

**三级操作强度**，视觉区分明确（细则见 §7.3）：

| 级别 | 适用 | 确认方式 | 视觉 |
|------|------|----------|------|
| **L0 只读 / 浏览** | 筛选、滚动、切页 | 无确认 | 常规控件 |
| **L1 一般写** | 配置保存（无连接类字段） | **双步确认**：点击 → 模态弹层（默认焦点「取消」） | 主按钮色；弹层描边 `#4EA6FF` |
| **L2 破坏性 / 生效性写** | 联锁释放、M1 授权、**含连接类字段的配置保存**、恢复默认值 | **双步确认 + 长按保持 1.0 s**（确认按钮内进度环自左向右填充，中途松手取消） | **危险色** `#FF6B6B` 描边 + 弹层顶部 4 px 危险色条 + 必须出现「影响范围」段 |
| **L2+ 将瞬断链路** | 任一字段 `requires_reconnect == true` 的配置保存 | 同上，且弹层**必须**插入 **WarnBanner** | 琥珀警示行（见下） |

**「将瞬断链路」警示行（WarnBanner）规格**（PRD F14.3「影响范围」的实质内容，**不可省略**）：

- 位置：弹层「明细列表」与「按钮行」之间，全宽。
- 尺寸：高 56 px，内边距 16 px，圆角 6 px。
- 色值：底 `#3A2E12`，描边 `#FFB020` 1 px，图标 `⚠` 28 px `#FFB020`，文字 24 px `#FFD75E`。
- 文案（固定）：「**生效瞬间通信将短暂中断（≤ 5 s）**」；连接类字段另加一行「涉及：<字段名列表>」。
- 语义：**不闪烁**、常亮；与危险红（`#FF6B6B`）区分——红表「破坏性动作」，琥珀表「副作用提示」。

### 2.6 降级可见、绝不造假（沿用 v1.0 §2.4）

- 一切不可得状态有**明确、稳定、不闪烁**的视觉标识；数值区以占位符 `--`（灰 `#96A2BC`）表达**而非 0**。
- 全局遵循「点级 valid 独立降级」：A 相失败不影响 B / C 相刷新。
- 「空态」「源不可用」「无权限」为**三种不同语义**，视觉与文案必须可区分（见 §8）。

### 2.7 固定分区 + 主读数不横滚（对齐 B8 / NF-09）

- 布局为**静态固定分区**：值变化只改数字 / 状态字，**不改区块坐标与尺寸**。
- **主状态页（P1）主读数区（SOC / PCS / 三相 P / I）宽度 = 内容区宽度（992 px），永不横向滚动**；信息量超单屏时**允许整页纵向滚动**（T-6 裁定）。
- P2–P6 亦为整页纵向滚动；**全部页面禁止横向滚动**（表格 / 长文本一律换行或截断，不横滚）。
- **本约束同样覆盖筛选区**：P3 模块筛选（≤50 项）**不得使用横向滚动 chip 行**，改用**自动换行 chip 网格**（§6.3 ②），保证全部模块在任何屏幕状态下可达（LG-03 / LG-05）。

**深色仪表风格**（暗夜仪表盘）：近黑藏蓝底 `#0B1220` + 高亮数值文字 + 语义色状态区。理由（柜内中等照度、低反射、大字边缘平滑需求低、行业惯例、背光负荷低助防烧屏）**沿用 v1.0 §3.2 全文，本版不重复论证**。若实测部署于强直射日光下不可读，仅需整体切「日间高亮」变体，**不改变本文件的布局 / 分区 / 三态语义**。

### 3.4 字体（设计要求，实现归架构）

- 中文：**无衬线黑体**（思源黑体 Noto Sans SC / 文泉驿微米黑 / 阿里巴巴普惠体）。
- **子集化工具改为 LVGL 链路**：用 **`lv_font_conv`**（LVGL 官方字体转换器）生成 CJK 子集，**输入字符集 = §3.6 全屏用字表**（含表内中文用字 + 表末声明的拉丁 / 数字符号 / 几何箭头清单），产出 C 数组字体（`font_subset_charset.txt` 即 `lv_font_conv --symbols` 的输入）；各字号档（§3.3）由同一字表分别导出一套，`lv_style_set_text_font` 引用。
- 数字：等宽（`tnum`）或固定字宽位图承接。
- 数值区不混排中文字形；数字与单位分列。
- 长中文（日志消息、弹层说明）需**换行**；LVGL 中由 `lv_label_set_long_mode(label, LV_LABEL_LONG_WRAP)` + `lv_obj_set_width` 固定宽度实现；若 CJK 断行不理想，做渲染端按字数插入软断点的后处理（不改数据）。

### 4.2 六页 ≤2 次触摸导航方案（TT-01）

**结论：常驻底部导航栏（6 项）→ 任意页 ↔ 任意页 = 1 次触摸**，**结构性优于 PRD「≤2 次」要求**（不依赖任何层级跳转，无二级页）。

| 要求 | 本设计满足方式 |
|------|----------------|
| 常驻导航入口，可达全部 6 页 | 底部导航栏 6 项常驻（P1 主状态 / P2 配置 / P3 日志 / P4 安全联锁 / P5 审计 / P6 系统），**任一页均在底部可见** |
| 任意页 → 任一目标页 ≤ 2 次 | **1 次**（点目标页签）。即使是「配置页编辑到一半 → 审计页」，也是 1 次 |
| 子页提供返回控件，位置固定一致 | 页眉左侧 `返回`（64×64，x 12–76，y 4–68），**P1 不显示**，P2–P6 显示且位置完全一致；返回目标 = P1 主状态页 |
| 当前页有明确选中态 | 页签**双通道**：图标 + 文字 + 顶部 4 px 选中条（`#4EA6FF`）+ 底色 `surface_alt` + 文字 `text_primary`；未选中：文字 `text_second`，底色透明 |
| 导航无 AI 类入口 | 6 项之外**无任何其他页签**；**不做置灰占位**（AI 暂停项不给任何视觉痕迹） |

**页签规格**：项 (x=i×170.7, y=696, x+170.7, 768)，尺寸 170.7×72（≥ 64×64）。
- 图标 28 px（居中偏上，y 706–734）+ 文字 26 px（居中偏下，y 736–766）。
- 状态：**默认** 文字 `#A6B6D6` / 图标 `#6E7FA0` / 底 `#141F33`；**选中** 文字 `#F4F7FF` / 图标 `#4EA6FF` / 底 `#1B2942` / 顶部 4 px 条 `#4EA6FF`；**按下** 底 `#2E4066`（反馈 ≤100 ms）；**禁用**（本期无）。
- 相邻项以 1 px `#2A3B57` 竖分隔（左起第 2–6 项左侧）。

### 4.3 返回 / 超时回归主状态页（F15 / TT-12 / TT-13）

| 场景 | 视觉与行为 |
|------|------------|
| 主动返回 | 页眉 `返回` 按钮（64×64）→ 切 P1；按下即反馈 |
| 无操作超时（默认 60 s，`--idle-timeout-secs`） | **超时前 10 s**，页眉右端（时钟左侧）出现**倒计时胶囊**：h 32、底 `#3A2E12`、描边 `#FFB020`、文字 24 px `#FFD75E`，文案「`12 秒后返回主状态页`」，每秒递减；到达 0 s 自动切 P1 |
| 计时重置 | 任何触摸事件（LVGL `LV_EVENT_PRESSED`，挂于全屏输入对象）重置计时，胶囊即刻消失 |
| **有未保存修改（P2 `dirty=true`）** | **不倒计时、不强制切页**（EDGE-11 / TT-12）；页眉下方出现常驻提示条：h 48、底 `#3A2E12`、描边 `#FFB020`、图标 `⚠`、文字 24 px「`有未保存修改`」+ 右侧文字按钮「`放弃修改`」（64 高触区）。用户显式放弃或保存成功后才恢复计时 |
| 确认弹层打开 | **暂停计时且不显示倒计时**（TT-13）；弹层关闭后恢复 |
| 超时回归本身 | 不产生审计记录；不改变页面滚动位置以外的状态（P1 始终从顶部开始） |

## 5. 触摸控件集（可复用组件规范）

> **控件策略（v2.0 反转，替代原「禁用内置控件皮肤、控件全自绘」口径）**：本版**采用 LVGL 内置控件**，配色 / 字体 / 尺寸 / 圆角 / 边框一律通过**自定义主题与样式（`lv_style_t` + `lv_theme`）**表达，**不做控件本体自绘**（KISS：LVGL 内置控件已提供按压态、禁用态、选中态与滚动语义，自绘将重复实现并放大软渲染与触摸命中的风险）。
> 映射关系：**内置控件覆盖不到的语义**（`WarnBanner`、SOC 三段量程条刻线、`NavTab` 顶部 4 px 选中条）才用基础对象（`lv_obj` + `lv_label` + `lv_image`）**组合**实现——这是「组合」，不是「重绘内置控件」。
> 主题落在**单一真源**：§3.2 色板 / §3.3 字号 / §3.5 尺寸常量集中在 `theme.c`（导出 `style_*` 与 `color_*` 常量），页面只引用常量，不硬编码色值。

**需与架构对齐的 3 点**

1. **LVGL 版本口径**：`lv_buttonmatrix` / `lv_obj_set_layout` / `lv_obj_remove_flag` 为 **LVGL v9** API；若锁定 v8.3，对应为 `lv_btnmatrix` / `lv_obj_set_flex_flow`（布局可省略）/ `lv_obj_clear_flag`。**请架构确认版本**（本文件只给语义，不给版本绑定）。
2. **长按保持 1.0 s**：用 **`LV_EVENT_LONG_PRESSED`**（`lv_obj_set_long_press_time(btn, 1000)`；注意 LVGL 默认 400 ms，**必须显式设 1000**）触发提交，配合 `lv_anim` 驱动按钮内进度填充（`LV_PART_MAIN` 的 `bg_grad` 或子对象宽度）；**`LV_EVENT_RELEASED` / `LV_EVENT_PRESS_LOST` 未达时长即复位并取消**。建议在离屏交互测试中先验证（技术设计 R-10 同批）。
3. **滚动条为纯指示（不接收按压 / 拖拽）须经 pin 实现**：**本设计不依赖 LVGL 对 `LV_PART_SCROLLBAR` 的默认交互语义**，技术上须**显式安排其不可交互**（技术设计侧落实）；与「触摸目标 ≥48 px」的口径**一并写入评审结论**（U-3 / V-7 同批真机确认，**现场仅验证指示清晰度，不改「不可拖」结论**）。

> **② 模块筛选：不用横向滚动 chip 行（UI 评审项 ②，2026-09-10 修订）**
> **冲突**：原「横向滚动 chip 行」与 §2.7 / §7.4 / §10「全部页面禁止横向滚动」互斥；而该行承载 **≤50 个模块项**——一旦结构性禁掉横滚，**超出屏宽的模块将永久不可达**（现场表现为「某些模块的日志筛不出来」），直接侵蚀 **LG-03**（模块选项可选）与 **LG-05**（≤3 次触摸）。
> **修订方案（不横滚 + 全项可达）**：模块选择改为**自动换行 chip 网格**——容器 `lv_obj_set_flex_flow(grid, LV_FLEX_FLOW_ROW_WRAP)`（LVGL Flex 换行），chip 复用 §5.1 #5 规格：**高 48、最小宽 96、横纵间距均 16 px**（满足 §2.1「相邻可点控件间距 ≥16 px」硬约束；触摸目标 48×48 ✓）。
> - **容量核算**：chip 取**最窄组合**（宽 96 + 间距 16）时，内容宽 992 px 可容 **9 项/行**（9×96 + 8×16 = 992）；**保守按 8 项/行**计（992 ÷ 112 = 8.86）。**「全部」+ ≤50 模块 = ≤51 项 → 保守最多 7 行**（7 × 64 = 448 px；实际典型 6 行 / 384 px）；**全部模块在任意窗口下可达**（整页纵滚即可触达最后一行）。网格总高上限 448 px **已含在 §6.3 线框的可变高区间内**，不产生新的布局溢出。
> - **「全部」chip 固定首位**（快捷复位语义不变，仍 1 次触摸）。
> - **不引入折叠 / 分页 / 「展开更多」**：任何中间步骤都会把 ② 从 1 次触摸推到 2 次，使 ①+②+③ 变成 **4 次**，**破坏 LG-05「≤3 次」**。故**换行网格是本约束下唯一不牺牲触摸次数的方案**。
> - **与禁横滚一致**：网格自身**不产生横向滚动**（Flex 换行 + 定宽 chip），滚动只发生在**页面级纵向**。
> - **备选（若评审认为 7 行过高）**：模块按来源分组（`core-bin / gateway / intercore / southd / 其它`）+ 组标题辅助扫读，**默认全展开**（保持 1 次触摸）；**不得默认折叠**。属版式微调，**不改 §2.1 触摸目标与 LG-05 结论**。

- 筛选结果更新 ≤1 s；筛选条件变化**不弹确认**（LG-05「不引入额外确认步骤」）。
- 「全部」chip 为快捷复位（1 次触摸清空该维度）。

**列表区**
- 行高 **44 px**（≥40 px，LG-06）；斑马纹：偶行 `#141F33` / 奇行 `#1B2942`。
- 每行：时间 24 px 等宽 `text_second`（宽 160）| 级别色块 88×28 + 文字 24 px | 模块 24 px `text_weak`（宽 140，超长截断加 `…`）| 消息 24 px `text_primary`（**换行 / 软断点，不横滚**）。

### 7.4 滚动规范

- 全部页面**仅纵向滚动**，横向一律禁止（LVGL：`lv_obj_set_scroll_dir(obj, LV_DIR_VER)`，§5.3）。
- 滚动条：见 §3.5；**严格纯指示、不可拖**（避免 8 px 触区违反 §2.1「≥48 px 触摸目标」硬规则）——**经 pin 实现为不可交互**（**技术设计已安排显式不可交互实现，不依赖 LVGL 框架默认行为**），仅在滚动发生时显现；**触摸滑动手势（Flickable 语义）保留**。
- 内容不可横滚的**替代策略**（长文本 / 宽表格）：
  - 日志消息 → 换行（必要时插软断点）；
  - 审计前后值摘要 → 截断 + `…`，完整值不在屏上展开（本期无详情页）；
  - 表头列宽固定，超长内容截断。
- 滑动与点击不互误触发（TT-11）：依赖 LVGL 滚动容器的「按下—抬起位移超过滚动阈值即转入滚动、不派发 `LV_EVENT_CLICKED`」语义（`LV_EVENT_SCROLL_BEGIN` 后子对象点击被抑制）；列为**真机验证项**（§11）。

### 7.5 动效与防烧屏（对齐 PRD §4.2 与 v1.0 §8）

1. **只更新脏区**：帧到仅重绘变化的数值格 / 状态点 / 角标，不做整屏重绘——LVGL 原生**失效区（invalidation）**机制即只重绘脏区（`lv_obj_invalidate`），前提是**不整对象删除重建**（数值更新只调 `lv_label_set_text`）。
2. **数字等宽防抖**：逐位替换无宽度抖动。
3. **状态切换一次性淡入** 200 ms（充↔放↔停↔待机、联锁态翻转）；**同一状态长期保持时零动画**。
4. **闪烁纪律**：任何元素持续闪烁 ≤ 0.5 Hz，**最多 3 个周期后转常亮**；仅限警告角标 / 指示灯；**核心数值永不闪烁**。PRD 指定的「连接中」黄灯 1 s 闪烁按此收敛为 3 周期后常亮。
5. **禁止**：滚动动画、翻页动画、页面切换淡入、循环装饰动画（软渲染预算与「无忙等」双约束）。
6. **防烧屏**：仅对**静态装饰**（分隔线、页眉标题、卡片底色、量程条底色）做周期 ≤2 px 微移或长静置一次低占空反色节拍；**核心数值区位置与内容不得移动 / 抖动**。数值随时间戳自然变化即是主要防烧屏手段。
7. **触摸不可用降级**：触摸设备异常时，页眉右端显示 24 px `#FFB020`「`触摸不可用`」角标；**数据刷新与其他画面完全不受影响**（EDGE-13）。

| 触摸无效（EDGE-13） | 全局 | 页眉右上「`触摸不可用`」琥珀角标；数据刷新不受影响 |
| 检索范围超限（EDGE-15） | P3 / P5 | 列表区上方 `WarnBanner`：「`检索范围超限，请缩小时间范围`」 |
| 版本 / 序列号缺失（EDGE-16） | P6 | 「`未提供`」 |
| **审计源不可用（EDGE-17）** | P5 | `UnavailableState`：「`审计记录不可用`」——**不得显「无审计记录」** |
| 审计不可写（EDGE-18） | P2/P4 | Toast「`审计不可用，操作未执行`」（fail-closed） |
| 提交时状态已变化（EDGE-19） | P4 | 弹层内「`联锁状态已变化，请刷新后重试`」 |
| 控制通带可达但读通道断（EDGE-20） | 全局 | 页眉**同时显示两种状态**：左侧 `与主进程数据通道断开`（红）+ 右侧正常时钟；P2/P4 写操作仍可用，实时数值沿用冻结帧并打标 |

### 8.4 「无权限」语义（无登录模型下的等价表达）

本模块**无登录 / 无会话 / 无 PIN / 无 RBAC**（T-3）。因此**不存在**「未登录 / 权限不足 / 请登录」这类视觉。取而代之：

| 原「权限」语义 | 本设计的等价表达 |
|----------------|------------------|
| 用户未认证 | **不存在**——物理在场即授权；界面**不得出现**任何登录入口、用户名、头像、锁屏 |
| 操作前置条件不满足 | 按钮 `disabled` + **就地原因文字**（如「`处于自锁态，须先释放联锁`」）——取代「无权限」提示 |
| 操作凭据 | **审计记录**：每次写操作的 `StatusChip`「`已记入审计`」在 Toast 中出现 1 次，强化「无身份把关、以留痕补偿」的心智 |

2. **LVGL 版本口径**：`lv_buttonmatrix` / `lv_obj_set_layout` / `lv_obj_remove_flag` 为 **v9** API；v8.3 下为 `lv_btnmatrix` / `lv_obj_set_flex_flow` / `lv_obj_clear_flag`。**请架构确认锁定版本**。
3. **长按保持 1.0 s**：`lv_obj_set_long_press_time(btn, 1000)` + `LV_EVENT_LONG_PRESSED`（**LVGL 默认 400 ms，必须显式改 1000**）；`LV_EVENT_RELEASED / PRESS_LOST` 即取消。**建议在离屏交互测试中先验证**（技术设计 R-10 同批）。
4. **滚动条为纯指示、不可拖**：**经 pin 实现**（**显式安排 `LV_PART_SCROLLBAR` 不接收按压 / 拖拽，不依赖框架默认行为**）；与「触摸目标 ≥48 px」的冲突由此**结构性规避**（手势保留）；同步写入评审结论（U-3 / V-7）。

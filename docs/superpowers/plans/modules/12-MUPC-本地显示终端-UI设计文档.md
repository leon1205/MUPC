## 1. 文档目的与读法

本文件给开发可直接照做的**就地运行状态屏视觉规范**，覆盖：信息分区、坐标、字号、色板、状态三态（正常 / 掉线 / 字段缺失）语义、刷新与动效约束、对 PRD 验收逐条呼应。**不做**：数据获取/裁决（mupcd 域值化）、跨进程通道形态、渲染栈选型、历史趋势屏、交互层。

**铁律总原则（对齐 PRD §5）**：源不可得 → 显式「不可得」，任何区块**不得用 0 / 陈旧值 / 臆测值冒充实时真值**。

## 2. 设计原则

### 2.1 就地可读优先（0.5–1.5 m，大字高对比）

- 目标阅读距离 0.5–1.5 m。按 8 寸 6.3 px/mm 折算：1.5 m 处舒适可读字符高约 40 px 起，主读数应 ≥ 64 px（见 §6.3 字号推导）。
- **信息层级 = 三个扫读档位**：
  1. **L1 主读数（1 s 内扫读）**：SOC 数值、PCS 充放状态词 —— 特大字号 + 语义色。
  2. **L2 过程量（2–3 s 确认）**：三相有功 P、三相电流 I —— 大字号表格式。
  3. **L3 佐证/标注（按需细看）**：SOC 源标签、区间警示、方向一致角标、新鲜度状态点 —— 小字号。
- 层级不得互相压挤：L1 区块之间留 ≥ 24 px 视觉缝隙，数值区不留装饰性渐变干扰。

### 2.2 固定分区、位置稳定

- 布局为**静态固定网格**：值变化只改数字/状态字，**不改变任何区块坐标与尺寸**（对齐 PRD §4.2.3）。
- 现场记忆规则：「左上读 SOC、右上读充放、下方读三相」——三个画面角色与柜面安装方向一致，便于远程电话对拍。

### 2.3 状态语义三重冗余（对齐 PRD §4.2.2）

- 任何状态表达必须是 **「文字 + 语义色 + 图标/几何」** 三种信道同时出现，**不依赖单一颜色信道**（色弱/单色屏可读）。
- 数值方向性（充/放）一律取 PCS 状态（REG 1013）为主判据，**不**从功率/电流符号自判（对齐 PRD F2.2 / §8 追认缺口）。功率符号**如实显示**（可为负），不作为方向依据。

### 2.4 降级可见、绝不造假

- 一切不可得状态要有**明确、稳定、不闪烁**的视觉标识，且数值区以占位符 `--`（而非 0）表达（对齐 PRD F3.4/F4.3/§6.4–6.5）。
- 全局遵循「点级 valid 标志独立降级」：A 相失败不影响 B/C 相刷新（对齐 PRD F5.5）。

## 3. 风格方向决策：**深色仪表风格（暗夜仪表盘）**

### 3.1 结论

采用 **深色仪表风格**：近黑藏蓝底（`#0B1220`）+ 高亮数值文字 + 语义色状态区。配色见 §6。

### 3.2 理由（Why）

| 考量 | 分析 | 结论 |
|------|------|------|
| **柜内环境照度** | 台区储能/配电柜现场以柜内荧光或低照度走廊为主，非强直射日光。深底低反射、不刺眼；大面积白底在荧光下易**整面反光眩光**，干扰小字标签判读。 | 深色胜 |
| **日光抗性** | 深色屏对**强直射日光**抗性弱（阳光洗白深底）。补偿：① 主数值用极高亮度文字（局部对比大，弱光下仍可辨）；② 亮度档位可设（渲染端提供「日间高亮」档——硬件背光提升或切一套浅色高亮变体，属架构可选项，默认深色）。 | 深色 + 高亮补偿 |
| **字体渲染成本** | 轻量原生渲染栈（无浏览器、可能无高质量亚像素抗锯齿）。本设计主数值 ≥ 64 px 大字：**大字边缘平滑需求低**，深浅底均可；深底亮字以「亮度跃迁」定义边缘，对 AA 精度依赖更低、锯齿观感更可容忍。中文字号较大（≥ 24 px 标签、≥ 64 px 状态词），无小字号清晰度压力。 | 深色不劣化 |
| **行业惯例** | 储能 BMS/EMS/就地监控屏普遍采用深色仪表盘（藏蓝底+青/绿/蓝亮色读数），运维心智已熟悉：亮 = 有值、灰 = 无值。 | 深色符合预期 |
| **读屏疲劳/烧屏** | 深底整面亮度低，液晶长期静态点亮时**总体背光负荷低于白底**，同等防烧屏措施下更耐久。 | 深色辅助 |

### 3.3 风格适用性说明（边界）

- 本决定基于「柜面/柜内中等照度」主场景。若实测部署在**强直射日光**下不可读，界面语义不变，仅需渲染端切「日间高亮」亮度/色板变体（数值仍为深字浅底高对比）；**该变体不改变本文件的布局/分区/三态语义**，仅整体反色。

## 5. 分区块详细规范

### 5.1 SOC 主区（左 L1）

**矩形** (16,88,496,420)，480×332。

内部结构（自上而下）：
1. **标题行**（Y≈110）：左侧「储能电池 SOC」28 px 标题（次级高亮白）；右上角**源标签胶囊**（见下）。
2. **源标签**：右上对齐，胶囊高 30。文本 20 px。
   - `双源一致` → 底色 `#0F3B34`、字 `#35D0C4`（青），前缀双勾图标。
   - `BMS` → 青灰描边胶囊，字 `#A6B6D6`（表示单源可用）。
   - `PCS(REG1010)` → 同上青灰描边胶囊。
   - `SOC 源失效` → 见 §7.1 三态（红底胶囊，触发整卡警示描边）。
3. **大数值区**（Y 160–330，垂直居中基准约 Y 250）：
   - 数字：**148 px**（tabular 等宽数字，白 `#F4F7FF`）；后随 `%` 56 px 次级。
   - 数值颜色 = SOC 区间色（正常青 / 上限邻近琥珀 / 下限邻近红，见 §6.2）。**颜色不是唯一信道**：区间警示同时驱动下限量程条与整卡描边。
   - 冻结/过期时数值仍按最近有效帧显示，但描边与角标切换（见 §7）。
4. **量程条区**（Y≈345–368）：
   - 0–100% 横向条，宽 360，居中，高 16。**三段预着色**：0–15% 红段 / 15–85% 青段 / 85–100% 琥珀段（`soc_min/soc_max` 默认 0.10/0.90，本设计按 PRD 取 15%/85% 警示带，评审放宽则重画断点）。
   - 中央竖刻线=当前 SOC 值；刻度下方小字 0 / 100 两端（20 px 弱灰）。
   - 区间色触发时：条上当前值刻线高亮 + 整卡顶部描边 3 px 变色，形成「值越界一眼可见」。

### 5.2 PCS 运行状态主区（右 L1）

**矩形** (528,88,1008,420)，480×332。

内部结构：
1. **标题行**（Y≈110）：「PCS 运行状态」28 px；右上「REG1013」20 px 弱灰角标（便于电话对拍编号）。
2. **状态主表达**（垂直居中，Y≈170–330）：
   - **状态词大字**：120 px（二字如「充电」「放电」并排=240 宽；「停机」同宽；「待机」同宽），垂直居中。颜色=语义色（§6.2）。
   - **语义色底/描边**：状态词后置一块**色块描边**（整卡左缘 6 px 竖条 + 顶部 3 px，色=状态色）；不整面铺色（避免大面积纯色在 1 Hz 下观感突兀）。
   - **图标**：状态词前 64 px 几何图标——**充电 `▼`（能量向下存入电池）、放电 `▲`（能量向上送出电池）**，以「能量进出电池」为意象，全文档统一：**充=▼（向下存储）、放=▲（向上送出）**（与 §4.2 线框、§5.3 图例/方向箭头、§6.2 语义色行一致）；停机 `■`；待机 `❚❚`。图标色=语义色。
   - 形成「**文字 + 语义色 + 图标**」三重冗余。
3. **佐证行**（Y≈360–400，20–22 px）：
   - `方向一致`（青点）：`佐证 ΣP 与状态一致 +12.5 kW`。
   - `方向不一致`（品红胶囊，见 §7）：`方向不一致`——主状态仍以 1013 大字为准，仅加角标。
   - PCS 离线时整卡状态见 §7.2。

### 5.3 三相功率与电流区（下 L2）

**矩形** (16,444,1008,752)，992×308。

内部结构：
1. **面板标题行**（Y 460–492）：
   - 左：「三相输出 A/B/C」26 px；中（弱灰 20 px）：`单位 kW / A · 数值如实读，方向随 PCS 状态`；
   - 右（弱灰 20 px）：图例 `▲ 放电 / ▼ 充电 / ● 实时 / ○ 停更`。
2. **4 卡片区**（Y 508–736，卡高 228）：
   - 卡宽：面板内边距 16，内宽 960；(960 − 3×16)÷4 = **228/卡**；间隙 16。
   - A 卡 (32,508,260,736)；B 卡 (276,508,504,736)；C 卡 (520,508,748,736)；总卡 (764,508,992,736)。
3. **每张 A/B/C 卡垂直结构**（自上而下）：
   - **卡头行**：左「A 相」30 px 白（加粗）；右**新鲜度状态点** 12 px（●实时青 / ○空心灰停更 / 过期转琥珀小点）。
   - **有功功率行**：标签「有功功率」22 px 弱灰 → 主值行：数值 **64 px**（tabular 等宽）+ 单位 `kW` 26 px；方向箭头 30 px（`▲放`/`▼充`，色=语义色，取自 F2 状态）。
   - **电流行**：标签「电流」22 px 弱灰 → 值 **48 px**（≥48 px 以保 1.5 m 读距）+ `A` 24 px（无方向箭头，方向语义已由上方 P 行/面板统一表达）。
   - 卡底 12 px 留作字段级状态点/角标区。
4. **总卡（REG 1032）**：卡头「总有功 / 1032」；主值 64 px + kW；标注 22 px「设备总有功」；**无电流**（该卡常显占位小字「—」避免空白歧义，但若 1032 valid 才显值）。
5. **数值语义**：
   - 显示值 = mupcd 域值（读值×0.1），**如实呈现，可含负号**（如 `-12.5`）。负号不代表方向结论——方向一律由状态箭头表达（追认缺口内）。
   - 负值显示：数值前「−」与数字同字号，无额外反色（避免暗示方向造假）。

> **色弱与色彩冲突自检**：充电绿 vs 放电蓝 vs 停机冷灰 vs 待机明黄，在红绿与蓝黄两轴均有差异 + 字形/图标三重冗余；SOC 高限橙 `#FFA94D` 与待机明黄 `#FFD75E` 分处不同区块不并排，且均有文字信道。四态可区分性由「文字 + 图标」兜底。

### 6.3 字号阶梯（设计基准，px 尺寸即字符 em）

| 层 | 用途 | 字号 | 阅读距离换算（1.5 m） |
|----|------|------|------------------------|
| L1-特大 | SOC 数字 | 148 px | ≈ 23 mm 字高，远超舒适阈 |

| L1-单位 | SOC `%` | 56 px | ≈ 8.8 mm |
| L2-主值 | 三相 P 数值 | 64 px | ≈ 10 mm（>40 px 舒适阈） |
| L2-次值 | 三相 I 数值 | 48 px（≥48 保 1.5 m 读距） | ≈ 7.6 mm |
| L2-图标 | 充放方向箭头/状态图标 | 30–64 px | — |
| 标签 | 区块标题/相标/标签 | 24–30 px | ≈ 4.4 mm（标签最小 ≥24 px） |
| 单位 | kW/A/% | 24–30 px | — |
| 佐证/角标 | 一致性/过期/未取数 | 20–24 px | 按需细读 |

| 弱注 | REG 编号/图例/刻度 | 20 px（**下限**，不再小） | — |

### 6.4 对比度要求

- 主文本 `#F4F7FF` 于卡底 `#141F33`：对比度 ≈ **14:1**（AA/AAA 达标）。
- 次文本 `#A6B6D6` 于卡底：≈ **7.5:1**（≥ AA）。
- 语义色文字（状态词）于深底须 ≥ **6:1**（充电绿/放电蓝/待机黄/停机灰均按高亮度选值达标）。
- 降级 `--` 灰 `#96A2BC` 于深底：≈ **6.8:1**——灰但清晰，避免「看不清」被误判为断显。
- **待机明黄 `#FFD75E` 与停机冷灰 `#8C98AC` 须并排可辨**（亮温差大）；过期琥珀 `#FFB020` 与数据异常红 `#FF6B6B` 同属警示但分角标位置，均以文字标注。

### 6.5 字体规范（设计要求，实现归架构）

- 中文：**无衬线黑体**（如思源黑体 Noto Sans CJK SC / 文泉驿正黑 / 阿里巴巴普惠体）——就地远读黑体字形开放度高。
- 数字：**必须等宽（tabular figures）或做等宽化处理**。原因：数值逐位刷新时避免字形宽度抖动引起整区微闪（对齐 PRD §4.2.3 / 4.1.1）。若所选字体无 `tnum`，架构须对数值区做**固定字宽位图/网格**承接。
- 数字与单位分行/分列，数值区不混排中文字形。

## 7. 组件三态显示规范（核心交付物）

### 7.1 状态字典与通用语法

每区块/字段都有三态，共用可叠加视觉语法：

| 语法元素 | 视觉 |
|----------|------|
| **字段状态点**（卡片右上） | ●实心青=本字段有效；○空心=停更/未取数；过期转琥珀点 |
| **值占位** | `--`（灰 `#96A2BC`） | 
| **区块级胶囊角标** | 半透明深底+描边文字，置于区块内角落 |
| **描边/底色变化** | 警示时区块顶部/左缘描边变色（不整面闪动） |

**三类根因判定（由帧内 valid 标志驱动，渲染端只按标志展示）：**

| 态 | 触发 | 原则 |
|----|------|------|
| **正常值** | 字段 valid=true 且帧新鲜 | 如实显示 |
| **字段缺失 / 点表未到**（PRD 6.4/6.5） | 该字段 valid=false（点级） | 该字段显 `--` + 角标；**不影响同区块/其它相** |
| **掉线 / 通道断**（PRD 6.1/6.3） | PCS 离线 or 主进程通道断 | 整块/整屏降级，见 7.4 |

### 7.2 SOC 主区三态

| 态 | 数值区 | 区间/量程条 | 源标签 | 附加角标/描边 |
|----|--------|-------------|--------|----------------|
| **正常** | 数字（区间色）+ `%` | 刻线在值处，正常青 | `双源一致`(青) / `BMS` / `PCS(REG1010)`(青灰) | 值 ≤15%→描边红；≥85%→描边橙 |
| **单源失效（仍有另一源）** | 显示另一有效源裁决值 | 同正常 | 显示**正在用的源名**（青灰单源胶囊） | 无（值可信则正常色） |
| **双源皆失**（6.2） | `--`（不补 0、不沿用旧值） | 整体灰化 | `SOC 源失效`（红底胶囊） | 整卡描边红 3px + 值区灰化 |
| **字段过期**（>2s） | **保留最近有效值** | 同该值 | 源名保留 | 数值上方琥珀小标 `数据过期`；**不冒充实时** |
| **主进程通道断** | 冻结帧 + `冻结/过期` | 灰化 | 灰化 | 整屏进 7.4 覆盖 |

> SOC 双源皆失**刻意不冻结旧值**（对齐 6.2），唯一允许冻结的仅是「通道断」全局态（6.3）或「数据过期」的字段级帧保留，且必打标。

### 7.3 PCS 状态主区三态

| 态 | 状态词 | 图标 | 卡描边 | 佐证行 | 角标 |
|----|--------|------|--------|--------|------|
| **正常** | `充电`/`放电`/`停机`/`待机`（语义色） | 对应几何图标 | 状态色 | `方向一致 ΣP≈x` 青点 | 无 |

| **PCS 离线**（6.1） | `PCS 离线`（降级灰） | 断线图标 `✕` | 灰 | 隐藏 | 灰胶囊 `PCS 离线` |

## 8. 刷新与动效约束

目标：**1 Hz 帧刷新下稳定、无整屏闪烁、无残影**（对齐 PRD §4.1/4.2）。

1. **只更新脏区**：帧到仅重绘发生变化的数值格/状态点/角标矩形，**不做整屏重绘**；静态装饰（底色、量程条底色、卡描边）不随帧重画。
2. **数字等宽防抖**：数值用 tabular 数字（§6.5），逐位替换无宽度抖动。
3. **值变即时、无循环动画**：数值更新直接 blit；禁止滚动/翻页/残影尾迹。刷新生效 ≤500 ms。
4. **状态切换（枚举变）**：充↔放↔停↔待机切换允许**一次性 200–300 ms 色相淡入**（非循环）；同一状态长期保持时**零动画**。
5. **闪烁纪律**：任何元素持续闪烁频率 ≤ **0.5 Hz**，且**最多 3 个周期后转常亮**；仅限警告角标/状态点，**核心数值永不闪烁**。
6. **防烧屏**（长期静态）：仅对**静态装饰**（分隔线、页眉标题、量程条底色）做低影响处理——每 60 s 周期整体微移 ≤2 px，或长静置后一次低占空反色节拍；**核心数值区位置与内容不得因防烧屏移动/抖动**（对齐 PRD §4.2.4）。数值随时间戳自然变化即是主要防烧屏手段。
7. **无忙等**：空闲帧间不产生视觉活动（视觉规范上无自旋性动画残留）；满载（断）时保持当前降级画面静止。

## 10. 本设计明确不涉及（范围外）

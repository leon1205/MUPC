# 台区储能控制策略设计（方案A：分时状态机 + 三通道控制 + S1 前馈吸收）

> 日期：2026-08-25（初版）；2026-09-01（重构至当前控制逻辑）
> 状态：设计已确认，已实现并离线回放验证（net 闭环模型，6-27/7-04 数据）

---

## 1. 目标与优先级

台区配光伏 + 储能 + 三相四桥臂 PCS，通过储能控制实现三个治理目标：

1. **降低光伏返送**：缩短返送时长、压缩返送幅值（软目标，偶尔返送可接受）；
2. **降低三相电流不平衡度**：目标 <20%（电网公司口径 `(1 − MIN(Ia,Ib,Ic)/MAX(Ia,Ib,Ic)) × 100%`，幅值式）；
3. **提高功率因数**：大部分时间接近 1。

**优先级**（受 120kWh 电池容量限制，"零返送"与"晚峰全削峰"不可同时完美达成，冲突时按此顺序妥协）：

```
日终 SOC 清空（S4 硬约束） > 不平衡度 <20%（物理极限内尽力） > 降低返送（软目标） > PF（软目标）
```

**晚峰削峰为软目标**：120kWh 电池（10~90% 可用带仅 96kWh，18:00 前 70% 上限时约 67kWh）无法同时满足白天吸收返送、晚峰削峰、日终清空。7-04 型晚峰（17-19h 62~77kW）削峰到 +5kW 需约 200kWh，只能**部分削峰约 30%**，且按 +5kW 目标会"先深削后放空"（满放约 1.6h 即到 10%）。

## 2. 硬件与系统约束

| 项 | 取值 |
|---|---|
| PCS | 125kW，三相四桥臂，分相 PQ 独立可控 |
| 电池 | 60kW / 120kWh |
| 测量 | 台区总表（20s 延时）；PCS/EMS 均无交采模块，无本地实时测点，秒级瞬态不可测 |
| 控制 | 分钟级（T=60s）下发分相 P/Q 设定值 |
| 预测 | 纯实时，无光伏/负荷预测 |
| PCS 容量边界 | 每相/中线额定电流 190A，过载 1.1×长期（209A）/ 1.2×1min（228A），超 228A 过载保护；总视在 125kVA |

**SOC 系统约束**（全局硬约束，贯穿所有状态）：
- **运行带**：10%~90%；接近 90%（≥88%）充电线性降额至 90% 归零，接近 10%（≤12%）放电线性降额至 10% 归零；
- **分时上限**：18:00 前 SOC ≤70%（`soc_cap_day`），18:00 后释放至 90%（为晚峰放电留容量）；上限值用离线回放标定（扫 60/70/80%），平衡"白天消纳"与"晚间反送"；
- **日终清空（硬约束）**：日终必须回到 10%，允许晚间反送（线损管理优先）。前提是**电网允许晚间反送**——若电网禁止，S4 无法完全执行，须与电网公司确认边界。

## 3. 总体架构

每个控制周期（T=60s）执行一次：

```
读总表(滑动滤波) → 状态机判态
  → 算 分相Q(PF) + 共模P(能量) + 差模P(三相平衡)
  → 每相容量仲裁/裁剪 → 下发 PCS 分相 P/Q 设定
```

**控制器接口（纯函数：跨周期状态显式传入/传出，由回放循环保存）：**

```
control(meter_data, soc, t_now, st, P_st, Q_active, dP_active, Q_last, meter_buf)
    -> (P_A_ref, Q_A_ref, P_B_ref, Q_B_ref, P_C_ref, Q_C_ref,
        st', P_st', Q_active', dP_active', Q_last', meter_buf')
# 跨周期状态量（st/P_st/Q_pcs/dP/Q_active/dP_active/Q_last/meter_buf）由回放循环保存并回传

meter_data = {
  P, Q, PF,                 # 三相总
  Ua,Ub,Uc, Ia,Ib,Ic,       # 三相电压电流
  Pa,Pb,Pc, Sa,Sb,Sc,       # 分相有功/视在
  Qa,Qb,Qc（含符号）,          # 分相无功（data_rule 字段提供，见 §11）
}
```

**符号约定**（必须统一，避免方向错误）：
- 台区总表：`P_表 > 0` = 台区从电网受电；`P_表 < 0` = 台区向电网反送；
- PCS：`P_pcs > 0` = 向台区母线注入（放电）；`P_pcs < 0` = 从母线吸收（充电）；
- 母线平衡：`P_表 = P_负荷 − P_光伏 − P_储能放电`。

## 4. 状态机（4 状态）

| 状态 | 触发 | 主目标 | 共模 P 方向 |
|---|---|---|---|
| S1 光伏吸收 | 白天，重构基线返送超 `p_abs_trig`（见 §7）且 SOC < 分时上限−滞回 | 吸收返送 | 充电 |
| S2 平段 | 其他时间 | 三相平衡 + PF | 0 |
| S3 高峰放电 | 任一时刻总表受电超 `p_dis_trig` | 放电供负荷 + 平衡 | 放电 |
| S4 日终清空 | 临近日终（`t_clear_start_secs`）且 SOC>10% | 强制放电到 10% | 强制放电（允许晚反送） |

**S1 进出用「重构基线」判断**：S1 前馈吸收把净功率稳定拉到目标进口 +2kW，**净功率不再反映返送是否存在**。因此 S1 进出判断一律用**重构基线** `P_基线 = P_表净 + P_out[k−1]`（当前净功率 + 储能上周期输出，抵消储能自身出力效应）。S1 退出延迟到「P_基线 ≥ 退出阈值 **且** 储能已大步回 0」，防基线骤转受电时 S2 慢斜坡期间储能从电网取电。

**切换规则**：
- 触发带滞回（进入阈值 ≠ 退出阈值）；S1 退出在目标另一侧（基线受电达 +4kW 或 SOC 顶格），防"达目标即退→返送复现→重进"抖振；
- S3 退出 = 共模积分回零 且 进口 ≤ 目标 +5kW（削峰完成）；退出**不可设在进口数值上**（积分把进口恒压到 +5，固定退出阈值不可达）；
- **S3 全天负荷触发（无时段门控）**：任一时刻受电超阈值即放电。此电池配置下"省电池给晚峰"不成立（7-04 晚峰需约 120kWh 超可用带），且低负荷日省电会转成 S4 强制晚反送（更糟）。保护交给 SOC 地板与 S4 日终兜底；**差模平衡零净能量、不耗电池，早晨放电不影响平衡能力**；
- 优先级：S4（线损硬约束）> S1 > S3 > S2，冲突时后者让位；
- S1 充电受**分时 SOC 上限**约束：到顶后不再重入 S1，留在 S2 接受剩余返送（软目标），防 S1↔S2 反复切换；
- **failsafe**：总表数据超时（>150s）或校验失败 → 冻结积分并**斜坡回归 0**，保持最后有效 Q（无功补偿相对安全），恢复后从 0 重新积分。

**触发阈值数值**（`p_abs_trig` / `s1_exit` / `p_dis_trig`）见 §7 参数清单，此处不重复。

## 5. 控制律（三通道）

### 5.1 分相 Q（PF 补偿，常开通道）

```
Q_i[k] = clamp( Q_i[k−1] + s·K_q × Q_meter_i[k],  −Q_i_max, +Q_i_max )   # 积分式，把表计无功归零
死区: |Q_meter_i| > 1.5kVAr（或 |PF_i|<0.95）进入积分；PF_i>0.98 退出并斜坡回归 0
Q_i_max = sqrt(S_相² − P_i²)     # 每相无功余量（arbitrate 落实）
```

**必须积分式**：表计无功**包含 PCS 自身注入**（作动器在测量回路内），比例式"抵消实测"闭环特征根 +1，稳态只收敛一半或发散；积分式稳态收敛到 `Q_表=0`（PF→1）。
**符号 s=±1 以表计/PCS 约定为准**——增量方向须使 Q_表 归零，用错会正反馈发散；投运前用小幅 Q 阶跃 + 分相注流核相（强制，见 §11 第 6 条）。反送/受电方向不需特例——积分式对任意方向统一收敛。

**准稳态设计（延时与瞬变处理）**：控制器为准稳态设计——分钟级下发 + 20s 表计延时，物理上追不了秒级瞬变。滑动滤波（`window_size=5`，约 5 分钟均值）把无功/电流低通、死区门槛过滤瞬态，控制器只响应慢变分量，**主动忽略秒级瞬变**（等指令到达时瞬变多已结束，追赶反而震荡）。PCS/EMS 均无交采模块，秒级瞬态在本系统硬件下不可感知、不可处理——如需覆盖须增设 PCS 交采模块实现本地快速无功环（硬件升级，见 §10）。三相不平衡通道同此策略。

### 5.2 共模 P（能量通道）——S1 前馈吸收 / S2/S3/S4 增量式斜坡

母线平衡 `P_表 = P_负荷 − P_光伏 − P_st`（P_st=储能放电为正）。

**S1 前馈吸收**：net 闭环下表计测的是**净功率**（含储能自身输出），直接对净功率做绝对设定会因储能出力变化而稳态不收敛。改为**重构外部基线**抵消自身效应后做绝对前馈，一周期到位：

```
P_基线[k] = P_表净[k] + P_out[k−1]            # 当前净功率 + 上周期储能输出 → 外部基线
P_st目标  = clamp( P_基线[k] − P_目标进口,  −P_cap, 0 )   # 吸收返送并保持 +2kW 进口
P_st[k]   = move_toward( P_st[k−1], P_st目标, s1_ff_step_kw )   # 大步斜坡，默认 = P_cap 一周期到位
```

该目标自动覆盖全部场景，无需条件分支：
- **持续返送**（P_基线 恒定）→ P_st 收敛到 P_基线−2，净恒 +2，无振荡；
- **返送减小仍返送**（储能超吸收，净从电网取电超目标）→ P_基线 重构不变、目标自动降载，**不停充**，把从电网取电压回 +2；
- **基线受电**（P_基线>0）→ 目标 >0 → clamp 0 → 停充；
- **基线骤转受电** → 大步斜坡一周期回 0（配合 §4 S1 延迟退出，防从电网取电）。

大步斜坡步长 `s1_ff_step_kw` 默认 = `p_cap`（60kW/周期），**返送陡坡当拍即可吸收**，返送峰值压至第一拍滞后极限（7-04 峰值 47.9→32.5kW）。

**S2/S3/S4 保留增量式斜坡（非前馈）**：

| 状态 | 输出 | 说明 |
|---|---|---|
| S2 平段 | `P_st = move_toward(P_st, 0, SLOPE)` | 斜坡回归 0，防阶跃 |
| S3 放电 | `P_st = clamp(P_st + clamp(Kp×(P_表−P_目标S3), −SLOPE, SLOPE), 0, P_cap)`，再 `P_st = min(P_st, (P_表−P_目标S3).max(0))` | 放电补到进口≈+5kW；`s3_margin_limit` 防负荷快速回落时过冲返送 |
| S4 清空 | `P_st = move_toward(P_st, P_强制, SLOPE)` | `P_强制 = (SOC−0.10)×120kWh ÷ (截止−现在)`，允许晚反送 |

说明：S1 前馈无需 Kp（直接按重构基线）；**Kp 仅 S3 用**（0.6），配合滑动滤波与斜坡限速防过调。

**晚峰能量预算（可选增强，回放对比）**：若希望晚峰削峰更持久（而非"先深削后放空"），S3 目标进口可用动态值 `P_目标 = max(+5kW, P_表 − P_预算率)`，其中 `P_预算率 = (SOC−0.10)×120kWh ÷ 剩余小时(至 T_清空起点)`——把可用能量平摊到整个晚峰，电池不易提前放空；固定/动态两种模式在回放中对比削峰率与晚反送。

### 5.3 差模 P（三相平衡，零净能量）——积分式

表计电流**包含 PCS 自身注入**，比例式 `ΔP=U_i×(I_i−均值)` 每周期重算、无积分，稳态只收敛到 `(自然电流+均值)/2`（只消除一半不平衡）。**必须积分式**把各相电流收敛到均值：

```
ΔP_i[k] = clamp( ΔP_i[k−1] + K_diff × U_i × (I_i[k] − I_均值[k]),  −ΔP_max, +ΔP_max )
死区: 不平衡度 >25% 进入, <15% 退出; 增量死区: |K_diff×U_i×(I_i−均值)| > max(0.5kW, 5%×P_相) 才积分
三相增量 Σ=0（Σ(I_i−均值)=0），故 ΣΔP 恒为 0，零净能量自动保持（电压不平衡时轻微残差，可忽略）
```

**要点**：
- **与 Q 通道协作**：Q 先把各相 PF 校正到 1（使 S→P），ΔP 再平衡各相净有功/电流，两通道不重复作用；
- **斜坡限速需保持三相 ΔP 和 = 0**：对三相统一限速或重归一化，否则破坏零净能量；§6 每相电流裁剪后同样需重归一化（等比缩放回 ΣΔP=0）。电压不平衡度实测中位数仅 0.4%/0.5%、最大 <1%——零净残差可忽略，无需电压不平衡补偿项（若未来电压不平衡 >10% 再评估 `ΔP_i += K_u×(U_i−U_均值)`）；
- **S1 反送相**：ΔP 会把反送相电流拉向均值，与共模充电共同完成"吸收 + 平衡"（差模零净，不影响总吸收量）；
- **单相/两相返送（光伏随机接相）**：某相返送而总表仍净受电 → **不触发 S1 共模充电**，改由差模 P 把返送相反向电流拉向均值（返送相充电吸收、受电相放电注入，**零净能量、不耗电池**）；仅当总表净返送超阈值才叠加 S1 充电。单相返送幅值受每相/中线 190A 限制（约 40kW/相），超出部分差模部分平衡、残余流向电网（软目标）；
- **评估口径（KPI，电网公司考核算法）**：`(1 − MIN(Ia,Ib,Ic) / MAX(Ia,Ib,Ic)) × 100%`，幅值式、方向盲；**单相返送会被该口径自动捕捉**（返送相幅值进 MAX），无需方向信息。注意幅值式对"小电流相"敏感：一相很小/反向 + 另一相很大时，PCS 容量可能拉不平，`<20%` 部分时段物理不可达，回放量化实际可达值；
- **I_i 必须为带符号电流**：ΔP 公式中的 I_i 是带方向的净电流（由分相有功 Pa 的符号或相角导出，如 I_i≈Pa_i/U_i），**不能直接用表计电流幅值**——单相返送时幅值法会给出相反方向，反向加重不平衡。

### 5.4 每相指令合成

```
P_i = P_cm/3 + ΔP_i
Q_i = Q_i_补偿
```

## 6. 容量仲裁与裁剪（每相、每周期）

- **约束**：
  - 每相电流 `|I_i| ≤ 190A` 额定（对应视在 S_相 ≈ 220V×190A ≈ 41.8kVA，与 125/3 一致）；过载限 `≤ 209A`（1.1×）长期、`≤ 228A`（1.2×）最多 1min，**超 228A 触发过载保护**；
  - **中线电流 `|I_中性| ≤ 190A`**——三相四桥臂补偿不平衡消耗中线电流，常比每相先到顶，是差模 P 的实际上限；`I_N=|Σ_i I_i∠θ_i|`（三相电流相量和，用 data_rule 相角列计算）；重平衡时约 130A 留有余量；
  - 总视在 `ΣS_i ≤ 125kVA`；总有功 `|ΣP_i| ≤ 60kW`（电池）。
- **裁剪顺序**（按优先级 返送>不平衡>PF）：先减 **Q**（PF 软目标）→ 再减 **差模 P**（不平衡）→ 最后减 **共模 P**（返送/能量，最刚需）；仅 SOC 保护可剪共模 P，S4 时不可剪；
- **裁剪算法（迭代）**：① 计算每相电流 `I_i=√(P_i²+Q_i²)/U_i`；② 若任一相 `I_i>190A` 或 `|I_N|>190A` 或 `ΣS_i>125kVA` → 按顺序逐级降：先该相 `Q_i=0`，再**等比缩差模 P**（`dP×k`，裁剪后重归一 ΣΔP=0），最后缩**共模 P**（S4 不可剪）；③ 重复 ② 至全部满足或仅剩共模 P；④ 总有功 `|ΣP_i|≤60kW`；
- **PF 硬考核兜底**：上述顺序默认 PF 最先妥协；若电网公司对功率因数有**硬性罚款门槛**（如 <0.9 罚款），仲裁需加 **PF 地板约束**：`|PF_i|` 不得低于阈值（如 0.9），必要时让差模 P 先让步保 Q——是否启用须与电网公司确认考核口径（见 §11 第 6 条）；
- **特例**：S4 时共模 P 不可剪，只剪差模和 Q；
- **SOC 保护**：充电 SOC≥90% → 共模 P 剪到 0（剩余返送接受）；放电 SOC≤10% → 共模 P=0；
- **斜坡限速**：S2/S3/S4 的 P_cm 与 ΔP_i 每周期变化 ≤6kW（`slope`）；S1 前馈大步斜坡不受此限。

## 7. 参数清单（TaiStorageConfig）

所有参数代码名/默认值如下，**作用与使用**均结合 7-04 实测数据说明。

**① 状态机触发（决定储能"动不动"）**

| 参数 | 值 | 作用与使用（结合数据） |
|---|---|---|
| `p_abs_trig` | 2.0 kW | **进 S1 的门槛**：重构基线返送超过 2kW 就进 S1 充电吸收。例：11:58 基线返送 15.9kW（>2）→ 进 S1。标定前是 10kW，调成 2kW 后捕获更小返送（7-04 返送时长 9.6%→5.6%） |
| `s1_exit` | 4 kW | **出 S1 的门槛**：基线受电达到 4kW **且储能已停充**才退出 S1。退出在目标另一侧（目标 +2，退出 +4），防"刚吸到目标就退→返送复现→又进"抖振 |
| `p_dis_trig` | 30 kW | **进 S3 的门槛**：总表受电超过 30kW 进 S3 放电削峰。例：7-04 晚峰 77.6kW → S3 放电削峰。数据标定：7-04 晚峰 15h 起 32→77.6kW，30kW 使 S3 于约 16h 起持续放电；6-27 晚峰仅 31.5kW 几乎不触发（无门控，早晨峰约 34kW 亦触发，有意为之） |

**② 目标进口（储能要把净功率停在哪）**

| 参数 | 值 | 作用与使用 |
|---|---|---|
| `p_tgt_s1` | 2 kW | S1 吸收返送时，让净功率停在"受电 2kW"（留 2kW 给电网）。例：基线返送 50.3kW，储能充 50.3−2=48.3kW → 净功率正好 +2。**这 2kW 允许储能从电网少量取电，避免吸收过头** |
| `p_tgt_s3` | 5 kW | S3 削峰时，让净功率停在"受电 5kW"（保持受电裕度，不反送） |

**③ 功率边界（储能能出多大力）**

| 参数 | 值 | 作用与使用 |
|---|---|---|
| `p_cap` | 60 kW | 储能最大充/放电功率（电池额定）。例：基线返送 57kW，储能最多充 60kW，净功率 = 57−60 = +3（受电） |
| `s1_ff_step_kw` | 60 | **S1 前馈大步斜坡**：每周期最多改变 60kW，从任何值到目标一周期到位。例：11:59 储能从 −18 直接跳到 −52（一步吸收 50kW 返送），这是峰值压降的关键（47.9→32.5kW） |
| `slope` | 6 kW/周期 | **S2/S3/S4 斜坡限速**：这些状态每周期最多变 6kW（平缓、防过调）。S1 不受此限（用大步斜坡） |
| `dp_max` | 40 kW/相 | 差模 P 每相最多调 40kW（受 190A 电流限制折算） |
| `q_i_max` | 30 kVAr/相 | 每相无功补偿最多 30kVAr |

**④ 积分增益（响应快慢）**

| 参数 | 值 | 作用与使用 |
|---|---|---|
| `kp` | 0.6 | S3 放电的积分增益（只 S3 用；S1 前馈不需要）。越大响应越快，过大易超调 |
| `k_diff` | 0.4 | 差模 P 积分增益：三相不平衡时，每周期按"该相电流−三相均值"积分，把电流大的相拉下来 |
| `k_q` | 0.4 | 分相 Q 积分增益：把各相表计无功积分归零（PF→1） |

**⑤ 安全与 SOC 边界（保护设备）**

| 参数 | 值 | 作用与使用 |
|---|---|---|
| `i_rated` | 190 A | 每相/中线电流上限，超了仲裁裁剪（先减 Q → 再减差模 → 最后减共模） |
| `s_rated` | 125 kVA | 总视在上限，超了等比缩小差模 |
| `soc_cap_day` | 0.70 | **18:00 前 SOC 上限 70%**：防止白天把电池充太满，导致晚上被迫大功率反送清空。例：7-04 SOC 峰值 61.8%（<70% 未触顶） |
| `soc_hys` | 0.03 | SOC 滞回：进 S1 需 SOC < 70%−3%=67%，防临界点反复进出 |
| `s3_margin_limit` | true | S3 放电不超当前负荷裕度：`p_st = min(p_st, P_表−p_tgt_s3)`，负荷快速回落时即时跟随，杜绝过冲返送 |
| `s4_limit_margin_kw` | 0.0 | S4 清空限幅裕度：0 = 满额清空（允许晚反送）；>0 则 `P_强制 ≤ P_表+裕度`（防夜间过度反送，牺牲部分清空） |

**⑥ 时序与滤波**

| 参数 | 值 | 作用与使用 |
|---|---|---|
| `control_period_s` | 60 | 控制周期（决定多久做一次决定） |
| `t_release_secs` | 18:00 | 分时 SOC 上限释放时刻：18:00 后 `soc_cap_day` 放宽到 90%，为晚峰放电留容量 |
| `t_clear_start_secs` / `t_clear_end_secs` | 21:00 / 23:30 | S4 清空时段：21:00 起强制放电到 10%，23:30 为达标目标（SOC≤12% 视为达标，防 SOC 误差致剩电） |
| `window_size` | 5 | 滑动平均窗口（5 点≈5 分钟）：平滑 20s 表计延时噪声，只响应慢变分量，忽略秒级瞬态 |
| `battery_capacity_kwh` | 120 | 电池容量，用于 SOC 积分与 S4 `P_强制` 计算 |

**⑦ 死区（防抖）**

| 参数 | 值 | 作用 |
|---|---|---|
| 不平衡死区 | 进入 25% / 退出 15% | 差模 P 防抖（目标 20%） |
| 最小差模功率 | max(0.5kW, 5%×P_相) | 差模增量死区，防低载期抖动 |
| PF 死区 | 进入 \|PF\|<0.95 / 退出 >0.98 | Q 通道防抖 |

**参数配合关系（直观）**：`p_abs_trig`(2) 决定"什么时候开始吸" → `p_tgt_s1`(2) 决定"吸到哪停" → `s1_ff_step_kw`(60) 决定"一周期能吸多快" → `p_cap`(60) 决定"最多吸多少"。白天这条链把返送吸掉；`p_dis_trig`(30) → `p_tgt_s3`(5) → `slope`(6) 这条链在晚峰放电削峰；`soc_cap_day`(0.70) 在中间平衡"白天吸多少"与"晚上放多少"。

## 8. 单周期控制主流程（伪代码，实现基准）

**接口**：`control(meter_data, soc, t_now, st, P_st, Q_pcs, dP, Q_active, dP_active, Q_last, meter_buf) → (P_A,Q_A, P_B,Q_B, P_C,Q_C, 更新后状态量)`（纯函数，见 §3）
输入含三相总/分相 P、Q（含符号）、PF、视在、电流幅值、电压；输出为 PCS 分相 P/Q 设定（正=放电/注入）。soc 用 0~1 小数。
**跨周期状态量**：`st`（当前状态）、`P_st`（共模出力）、`Q_pcs[3]`（无功积分状态）、`dP[3]`（差模积分状态）、`Q_active[3]`/`dP_active`（死区滞回锁存）、`Q_last[3]`（最近有效 Q，failsafe 用）、`meter_buf`（滑动滤波窗口缓冲）。
**首周期初值**：st=S2、P_st=0、Q_pcs=dP=0、Q_active=dP_active=False、Q_last=0、meter_buf=空（首周期直接取当前测量）。

```
# ---------- 0 常量（值见 §7）----------
P_abs_trig=2; P_dis_in=30                    # S1 返送 / S3 高峰触发阈值
S1_exit=4                                    # S1 退出阈值（重构基线≥+4 且储能已回0）
P_tgt={S1:+2, S3:+5}; P_cap=60; SLOPE=6      # 目标进口 / 电池功率 / 斜坡限速
S1_FF_STEP=60; Kp_S3=0.6; S3_MARGIN_LIMIT=True  # S1 前馈大步斜坡 / S3 增益 / S3 裕度限幅
K_diff=0.4; K_q=0.4                          # 差模/无功积分增益
DP_max=40; Q_i_max=30                        # 差模上限 / 无功上限
I_rated=190; S_rated=125                     # 电流 / 视在限
SOC_cap_day=0.70; SOC_hys=0.03; T_release=18:00  # 分时SOC上限 / 滞回 / 释放时刻
T_clr=[21:00, 23:30]; STALE_T=150            # S4 清空时段 / failsafe 超时

def control(meter, soc, t_now, st, P_st, Q_pcs, dP, Q_active, dP_active, Q_last, meter_buf):
    # 1 滤波与符号 --------------------------------------------------
    P, Pi, Qi, PFi, Ui, Ii_mag = sliding_avg(meter_buf, meter, window_size)  # 低通
    Ii = sign(Pi) * Ii_mag                              # 带符号电流（§5.3）
    Imean = mean(Ii)
    I_max = max(Ii_mag)
    unbal = 0 if I_max < 1 else (1 - min(Ii_mag)/I_max)*100  # 电网公司口径；除零守卫

    # 2 failsafe（§4）-----------------------------------------------
    if stale(meter) or bad(meter):
        P_st = move_toward(P_st, 0, SLOPE)              # 斜坡回归 0
        return per_phase(P_st, Q_last), (st, P_st, Q_pcs, dP, Q_active, dP_active, Q_last, meter_buf)

    # 3 状态机（§4，滞回锁存；优先级 S4>S1>S3>S2）-------------------
    # 重构基线：当前净功 + 上周期储能输出，抵消储能自身出力效应
    P_基线 = P + P_st
    SOC_cap = SOC_cap_day if t_now < T_release else 0.90
    P_force = clamp((soc-0.10)*120 / max(hours_to(T_clr[1]), 0.1), 0, P_cap)
    if max(Ui) > 235: P_force = min(P_force, max(P, 0))  # 电压越限保护：限夜间反送抬压
    if t_now >= T_clr[0] and soc > 0.10:                  # 进入 S4（未到 10% 则继续，P_force 限幅兜底）
        st = S4
    elif st == S1:                                        # 持至基线返送消失且储能回 0，或 SOC 顶格
        st = S1 if ((P_基线 < S1_exit or P_st < -1) and soc < SOC_cap) else S2
    elif st == S3:                                        # 持至积分回零且进口≤目标（削峰完成）才退
        st = S3 if (P_st > 0 or P > P_tgt[S3]) else S2
    elif P_基线 < -P_abs_trig and soc < SOC_cap - SOC_hys:
        st = S1
    elif P > P_dis_in:
        st = S3
    else:
        st = S2

    # 4 分相 Q（§5.1，积分式 + 死区锁存）-----------------------
    Q = [0,0,0]
    for i in 0..2:
        if abs(PFi[i]) > 0.98: Q_active[i] = False       # 退出：PF 已好
        elif abs(PFi[i]) < 0.95: Q_active[i] = True      # 进入：PF 差
        if Q_active[i]:
            Q_pcs[i] = clamp(Q_pcs[i] + s*K_q*Qi[i], -Q_i_max, Q_i_max)  # 积分归零表计无功
            Q[i] = Q_pcs[i]
        else:
            Q_pcs[i] = move_toward(Q_pcs[i], 0, Q_i_max)  # 惰化：斜坡回归 0
            Q[i] = Q_pcs[i]

    # 5 共模 P（§5.2）----------------------------------------------
    if   st==S1: P_st = move_toward(P_st, clamp(P_基线 - P_tgt[S1], -P_cap, 0), S1_FF_STEP)  # 前馈吸收
    elif st==S2: P_st = move_toward(P_st, 0, SLOPE)      # 斜坡回归 0，防阶跃
    elif st==S3:                                          # 放电补到进口≈+5kW
        P_st = clamp(P_st + clamp(Kp_S3*(P - P_tgt[S3]), -SLOPE, SLOPE), 0, P_cap)
        if S3_MARGIN_LIMIT: P_st = min(P_st, max(P - P_tgt[S3], 0))  # 放电不超当前负荷裕度
    elif st==S4: P_st = move_toward(P_st, P_force, SLOPE)  # 斜坡逼近强制值
    P_st = soc_protect(P_st, soc)                        # ≥88% 充电降额/≤12% 放电降额；90%/10% 钳位

    # 6 差模 P（§5.3，积分式 + 死区锁存，零净能量）-----------
    if unbal < 15: dP_active = False
    elif unbal > 25: dP_active = True
    for i in 0..2:
        inc = K_diff * Ui[i] * (Ii[i] - Imean)
        if dP_active and abs(inc) > max(0.5, 0.05*abs(Pi[i])):   # 增量死区
            dP[i] = clamp(dP[i] + inc, -DP_max, DP_max)          # 积分：三相增量 Σ=0
        else:
            dP[i] = move_toward(dP[i], 0, DP_max)                # 惰化：斜坡回归 0

    # 7 指令合成（§5.4）--------------------------------------------
    Pcmd = [P_st/3 + dP[i] for i in 0..2]

    # 8 容量仲裁/裁剪（§6）-----------------------------------------
    #   (a) ΔP 裁剪后重归一化 ΣΔP=0（否则 ΣP_i≠P_st，破电池 60kW 总量限）
    #   (b) 裁剪顺序：①Q → ②差模P → ③共模P（S4 不可剪）
    #   (c) 约束：每相/中线电流 ≤190A、总视在 ≤125kVA、总有功 ≤60kW
    #   (d) SOC 保护：充电≥90% 共模P剪0、放电≤10% 共模P=0
    Pcmd, Q = arbitrate(Pcmd, Q, st, P_st, I_rated, S_rated, P_cap, SLOPE)

    Q_last = Q                                            # 更新最近有效 Q
    return (Pcmd[0],Q[0], Pcmd[1],Q[1], Pcmd[2],Q[2]), (st, P_st, Q_pcs, dP, Q_active, dP_active, Q_last, meter_buf)
```

**辅助函数语义**：
- `sliding_avg(buf, meter, n)`：meter 推入窗口缓冲，返回 n 点均值（缓冲未满时直接取当前值，避免首周期全零）；
- `sign(x)`=符号；`hours_to(t)`=距 t 时刻的小时数；`move_toward(x,t,s)`=x 每周期向 t 最多移动 s；`clamp(x,lo,hi)`=限幅；
- `soc_protect(P_st,soc)`=降额/钳位：soc≥88% 充电线性降额至 90% 归零；soc≤12% 放电线性降额至 10% 归零；
- `per_phase(P_st,Q)`=把共模 P_st 均分三相与 Q 合成分相指令元组（failsafe 用）；
- `arbitrate(Pcmd,Q,st,P_st,...)`=§6：统一限 ΔP 斜坡 → 逐相电流 ≤190A / 中线 ≤190A / 总视在 ≤125kVA 钳位 → 按 ①Q ②差模P ③共模P 顺序裁剪 → **ΔP 重归一**（裁剪后若 `resid=ΣΔP≠0`，`dP[i] −= resid/3` 均匀回补）→ 共模 P 总量 ≤60kW。**中线电流** `I_N=|Σ_i I_i∠θ_i|`（用 data_rule 相角列计算）≤190A。可选 PF 地板：若启用 `|PF_i|≥PF_floor`，差模 P 先让保 Q。

## 9. 离线回放验证

按 §8 伪代码实现控制器（跨周期状态由回放循环保存回传），用历史数据（**6-27 / 7-04** data_rule 时序，即 §11 第 4 条标定所用原始负荷基线）逐周期回放，累计 SOC，验证。**回放初始条件**：首周期 st=S2、P_st=0、Q_pcs=dP=0、SOC=0.50；时间戳按 T=60s 步进对齐，数据缺段跳过不累计。

**net 反馈模型**：回放由 gross（开环）改为 **net 反馈模型**——每个控制周期以 `P_净[i] = P_基线[i] − 储能上周期输出[i]` 作为表计测量送入控制器（储能输出在测量环内，与运行时闭环一致）；KPI/SOC 记账用生效间隔输出。S1 前馈的重构基线 `P_基线 = P_净 + P_out[k−1]` 正依赖该模型。

**KPI 时间口径**：不平衡度/PF/返送按时段瞬时值、15min 均值、日最大分别统计，与电网公司考核口径对齐后判定达标。
**返送转移现实**：本策略把白天返送转为晚间反送（S4），**净返送能量未必下降**——回放同时统计"白天返送 vs 晚反送"的总量与幅值。
**差模积分收敛校验**：积分式差模应使各相电流收敛到均值，验证 6-27 现状约 87% 级不平衡能否压向 <20%（受 190A/中线限约束）。
**Q 方向自检（最先执行）**：回放第一步下发小幅 Q 阶跃（如 +5kVAr/相），验证 Q_表 反方向响应（同向即发散）→ 翻转 s；这是 PF 通道稳定性前提，先于一切标定。

**核心验证项**：
1. 返送时长/幅值是否下降（对比"不装储能"基线）；
2. 三相不平衡度是否收敛到 <20%（电网公司口径）；
3. PF 是否大部分时间接近 1；
4. SOC 日终回到 10%，且始终在 10~90% 带内。

**边界用例**：
- 中午大返送 + SOC 快满 → 剪充电、接受部分返送；
- S1 到分时 SOC 上限后返送仍持续 → **不重入 S1、留 S2 接受返送**（验证无 S1↔S2 振荡）；
- **返送陡坡**：2 分钟骤增（如 7-04 11:58→12:00 基线 0→−57kW）→ 前馈大步斜坡一周期吸收，验证返送峰值压至第一拍滞后极限；
- **返送减小仍返送**：储能超吸收（净从电网取电超目标）→ 前馈目标自动降载、**不停充**，把从电网取电压回 +2；
- **基线骤转受电**：储能未回 0 时 S1 延迟退出并大步回 0，防 S2 慢斜坡期间从电网取电；
- 晚峰负荷小 → S4 强制清空产生晚反送（线损优先）；
- 返送 + 不平衡同时 → 仲裁顺序正确；
- **单相/两相返送**：某相返送而总表净受电 → 仅差模重分配、不触发 S1；总表净返送 → S1+差模协同吸收；校验每相/中线电流 ≤190A；
- **21:00 S3→S4 交接**：晚峰未结束时 S4 接管，下发指令无阶跃；
- **通信故障注入**：总表断连/重连 → failsafe 斜坡回归 0，重连无阶跃；
- **数据缺口**：分钟数据缺段逐周期处理不报错。

**回放验证结果（net 反馈模型，SOC 初值 0.50）：**

| 日 | 指标 | 基线（无储能） | 控制后（当前前馈） |
|---|---|---|---|
| 7-04 | 返送时长 | 16.5% | **5.6%** |
| 7-04 | 返送峰值(kW) | 57.0 | **32.5** |
| 7-04 | 返送能量(kWh) | 58.0 | **8.5** |
| 7-04 | SOC 日终 | — | 10.0% |
| 6-27 | 返送时长 | 6.2% | **2.7%** |
| 6-27 | 返送峰值(kW) | 25.3 | **10.4** |
| 6-27 | 返送能量(kWh) | 10.0 | **2.3** |
| 6-27 | SOC 日终 | — | 10.2% |

两日受电峰值不劣化（7-04 77.6 / 6-27 41.5 kW）；SOC 日终清空不变。前馈把 7-04 返送峰值压至 32.5kW（≈第一拍滞后极限）。

**补充校验**：
- **SOC 误差扫描（±3%）**：日终剩余电量是否仍满足线损管理要求；
- **分时 SOC 上限标定**：扫 60/70/80%，对比"日反送 vs 晚反送"的总量与幅值；
- **中线电流校验**：差模最大出力时 `|I_中性| ≤ I_中性额定`；
- **不可达窗口统计**：统计"<20% 物理不可达"的时段占比，量化实际可压到的最低不平衡度与达标时长占比；**目标：不平衡度<20% 达标时长占比 ≥80%**；

- **参数灵敏度**：扫死区/斜坡/目标进口/Kp（及差模/Q 增益），定初值；
- **S3 门控对比**：有无时段门控对比 S4 晚反送量、早晨峰削峰效果、SOC 日终达标。

## 附录 A：运行原理速览（通俗版）

**这个策略怎么工作（大白话）**：每隔 `control_period_s=60` 秒，策略看一眼台区总表，让储能干合适的事。核心一句话：**台区缺电（受电）储能就待着；台区多电（光伏返送）储能就充电把多出来的电吸走；晚上储能把白天吸的电放出去、把电池清空**，同时顺手平衡三相、补无功。

**四个状态是干什么的**：
- **S1 光伏吸收**（白天光伏发多了）：总表显示电在往电网倒灌（返送）→ 储能**充电**，把返送的电吸进电池，不让它白白送回电网；
- **S2 平段**（没大返送也没大负荷）：储能**待机**，共模出力归 0，只剩"平衡三相 + 补无功"两个软任务；
- **S3 高峰放电**（晚上负荷大）：总表受电功率超过 `p_dis_trig=30kW` → 储能**放电**，帮电网供一部分负荷，把高峰削下来；
- **S4 日终清空**（21:00 后）：把电池里剩的电**全放出去**，回到 10%，保证明天还有空间再吸收返送（允许少量晚反送，线损优先）。

**关键一问：怎么知道"返送了多少"？** 台区总表读到的其实是**净功率**（已经减掉了储能自己刚出的力）。策略用一个巧办法还原真实差额：**重构基线 = 总表净功率 + 储能上一次出力**。这样就知道"光伏和负荷的真实差"到底是多少，然后让储能出力 = 这个差额 − 2kW（留 2kW 给电网，防止吸收过头倒灌到反方向）。这就是 S1 的**前馈吸收**——一周期就能把返送吸干净，不用像老算法那样慢慢爬坡。

**用 7-04 数据走一遍（11:58→12:01，返送尖峰）：**

| 时刻 | 总表净功率 | 储能上次出力 | 重构基线返送 | 策略让储能 | 效果 |
|---|---|---|---|---|---|
| 11:58 | −15.9 | 0 | ≈15.9 | 充电 ≈16 | 返送被吸走，净功率回到 +2 |
| 11:59 | −50.3 | −18 | ≈50.3 | 充电 ≈52（大步斜坡一周期到位） | 净返送瞬间压住，只剩第一拍滞后 |
| 12:00 | −57.0 | −52 | ≈57 | 充电 ≈59（到 60 上限） | 净功率 ≈+2 |
| 12:01 | 基线返送回落到 53.7 | −60 | ≈53.7 | 自动降到 ≈55.7 | 吸收过头从电网取 6.3 → 收敛回 +2 |

**储能出力还有两个"辅助通道"**（跟共模充电同时进行，互不干扰）：
- **差模 P**（三相之间微调）：三相电流不平衡时，把充电/放电往电流大的相多分一点、电流小的相少分一点。三相之间倒来倒去，**总量不变、不额外耗电池**；
- **分相 Q**（无功）：哪相功率因数低了，就发/收无功把它补回接近 1。

所以每个周期最终下发的是**六个数字**：A/B/C 三相各自的有功设定 + 三相各自的无功设定（`phase_p_set` / `phase_q_set`），经核间 V3 帧给到台区储能 PCS。

# S2 · DI/DO 安全联锁实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 PCS（储能变流器）实现安全联锁：急停/水浸/消防报警 DI 触发**可靠停机（REG_START_STOP 500=0）并锁存禁启**（DB 持久化、重启读回仍禁），门禁 DI 仅事件；DO1/DO2 运行/故障灯按 PCS 状态与联锁驱动；Web/CLI 人工释放。

**Architecture:** ①intercore transport 增显式停机原语与双 latch 模型（transport `stopped_latched` + DB latch；触发沿经 `restore_interlock_latched(true)` 无条件置位、`stop()` 仅写 500=0+复位缓存；latch 期间整条下行中止；心跳维护 `last_run_state` 并 M1 加 `!stopped_latched` 豁免）。②新 crate `mupc-io`（GPIO 抽象，sysfs 先落地 + mock）。③core-bin `interlock` 控制器（100ms 轮询 DI 去抖→触发/释放状态机→调 stop→DO 驱动→events/SSE），经 web-api 定义的 `InterlockApi` trait 注入 `AppState`（status/release/ack_m1 端点）。④storage events 扩展按类型查询用于 DB latch 读回。

**Tech Stack:** Rust（async-trait、tokio、serde/serde_yaml、axum）、Linux sysfs GPIO（`/sys/class/gpio`）、SQLite（storage crate）。

**设计合同：** 核间 10 §12.2-§12.5 `[DESIGN_APPROVED: 2026-09-08]`（含 C-1 双 latch / S-4 前置读 / M1 豁免 / DO 语义 / io schema / R-I 等全部修订）；BECG GPIO：DI1 急停=124、DI2 水浸=125、DI3 消防=102、DI4 门禁=103、DO1 运行灯=97、DO2 故障灯=107。

```rust
    async fn ensure_started(&self) -> Result<(), MupcError> {
        if *self.stopped_latched.read().await {
            return Err(MupcError::new(ErrorCode::OperationFailed,
                "interlock stopped：禁止自动启动", "intercore"));
        }
        if *self.started.read().await {
            return Ok(()); // 已启动缓存
        }
        // S-4：链路恢复/冷启动首个写启动前，先读一次 RUN_STATE 校验非停机
        let st = self.read_input_once(REG_RUN_STATE, 1).await?;
        let run = decode_run_state(st.get(0).copied().unwrap_or(u16::MAX));
        if run == 0 {
            tracing::warn!("M1 前置校验：RUN_STATE=0（停机/保护跳闸），不自动启动，交上层");
            return Err(MupcError::new(ErrorCode::OperationFailed,
                "RUN_STATE=0 不允许自动启动（M1 守卫）", "intercore"));
        }
        self.write_reg_once(REG_START_STOP, 1).await?; // 启动
        *self.started.write().await = true;
        Ok(())
    }
```

        // 写 500=0（latch 期间仍允许，供 interlock 周期重试）；不设/清 latch

//! 数字 IO 抽象（BECG-3568 DI/DO，sysfs 先落地；gpiod 后端接口预留）。
//! sysfs 路径 /sys/class/gpio/gpio{num}/{direction,value}；DI 读原始电平（1/0 硬件态，
//! active_low 语义由上层按配置反相），DO 写原始电平（active_high 由上层决定 0/1）。

use std::path::PathBuf;

#[derive(Debug, thiserror::Error)]
pub enum IoError {
    #[error("GPIO 初始化失败 {0}: {1}")]
    Init(String, String),
    #[error("GPIO 读写失败 {0}: {1}")]
    Io(String, String),
}

/// 数字输入（光耦 DI）
pub trait DigitalIn: Send + Sync {
    fn read_level(&self) -> Result<bool, IoError>; // true = 硬件高电平
}

/// 数字输出（继电器 DO）
pub trait DigitalOut: Send + Sync {
    fn set_level(&self, high: bool) -> Result<(), IoError>;
}

/// sysfs 输入：export + direction in + 读 value
pub struct SysfsIn { path: PathBuf }
impl SysfsIn {
    pub fn new(gpio: u32) -> Result<Self, IoError> {
        let gpio_dir = PathBuf::from(format!("/sys/class/gpio/gpio{gpio}"));
        if !gpio_dir.exists() {
            std::fs::write("/sys/class/gpio/export", gpio.to_string())
                .map_err(|e| IoError::Init(format!("export gpio{gpio}"), e.to_string()))?;
            // export 后等待 udev 建目录
            std::thread::sleep(std::time::Duration::from_millis(50));
        }
        std::fs::write(gpio_dir.join("direction"), "in")
            .map_err(|e| IoError::Init(format!("dir gpio{gpio}"), e.to_string()))?;
        Ok(Self { path: gpio_dir.join("value") })
    }
}
impl DigitalIn for SysfsIn {
    fn read_level(&self) -> Result<bool, IoError> {
        let v = std::fs::read_to_string(&self.path)
            .map_err(|e| IoError::Io(self.path.display().to_string(), e.to_string()))?;
        Ok(v.trim() == "1")
    }
}

/// sysfs 输出：export + direction out + 写 value（active 电平由上层换算）
pub struct SysfsOut { path: PathBuf }
impl SysfsOut {
    pub fn new(gpio: u32) -> Result<Self, IoError> {
        let gpio_dir = PathBuf::from(format!("/sys/class/gpio/gpio{gpio}"));
        if !gpio_dir.exists() {
            std::fs::write("/sys/class/gpio/export", gpio.to_string())
                .map_err(|e| IoError::Init(format!("export gpio{gpio}"), e.to_string()))?;
            std::thread::sleep(std::time::Duration::from_millis(50));
        }
        std::fs::write(gpio_dir.join("direction"), "out")
            .map_err(|e| IoError::Init(format!("dir gpio{gpio}"), e.to_string()))?;
        Ok(Self { path: gpio_dir.join("value") })
    }
}
impl DigitalOut for SysfsOut {
    fn set_level(&self, high: bool) -> Result<(), IoError> {
        std::fs::write(&self.path, if high { "1" } else { "0" })
            .map_err(|e| IoError::Io(self.path.display().to_string(), e.to_string()))
    }
}

/// 测试 mock（内存电平）
pub struct MockIn { level: std::sync::RwLock<bool> }
impl MockIn {
    pub fn new() -> Self { Self { level: std::sync::RwLock::new(false) } }
    pub fn set(&self, high: bool) { *self.level.write().unwrap() = high; }
}
impl DigitalIn for MockIn {
    fn read_level(&self) -> Result<bool, IoError> { Ok(*self.level.read().unwrap()) }
}
pub struct MockOut { level: std::sync::RwLock<bool> }
impl MockOut {
    pub fn new() -> Self { Self { level: std::sync::RwLock::new(false) } }
    pub fn get(&self) -> bool { *self.level.read().unwrap() }
}
impl DigitalOut for MockOut {
    fn set_level(&self, high: bool) -> Result<(), IoError> {
        *self.level.write().unwrap() = high; Ok(())
    }
}

### Task 5: core-bin — 联锁状态机纯逻辑（可测，无 IO/transport 依赖）

**Files:**

```rust
//! 安全联锁状态机（纯逻辑，便于单测）：输入 = 各 DI 去抖后有效态 + PCS run_state/在线；
//! 输出 = latch 决策 + DO1/DO2 目标电平（active 层由装配换算）。
//! 语义（§12.3/§12.4）：pcs_stop 源有效沿 → latch 触发（restore true，装配负责 transport+DB）；
//! 释放（auto=false）须触发源全复位且保持 >= release_hold_secs 且外部 request_release；auto=true 则保持后自动。
//! fail-safe：GPIO 读失败由装配按触发处理（此处只吃 bool 有效态）。

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum InterlockSource { Estop, Flood, Fire, Door /* 门禁仅 event */ }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DoDecision { LampRun, LampFault }

#[derive(Debug, Clone)]
pub struct InterlockState {
    pub latched: bool,               // DB/transport latch 语义（含 stop_failed）
    pub stop_failed: bool,
    pub active_pcs_stop_sources: u32, // bit: Estop/Flood/Fire
    pub source_safe_since: Option<u64>, // 全部触发源复位后的 tick（秒）
    pub last_fault_lamp_reason: FaultReason,
}
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FaultReason { None, Interlock, PcsOffline, M1Stopped }

/// tick 一次：返回需要装配执行的命令
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Action { None, TriggerLatch, ReleaseLatch(#[allow(dead_code)] bool) /* true=已前置 Web 确认 */ }

pub struct StateMachine {
    pub auto_release: bool,
    pub release_hold_secs: u64,
    debounce: std::collections::HashMap<u32, u32>, // di index -> 计数（内部）
}

impl StateMachine {
    pub fn new(auto_release: bool, release_hold_secs: u64) -> Self { .. }
    /// raw 电平 + active_low 由装配换算成 tripped(raw,source)；now=秒
    pub fn tick(&mut self, s: &mut InterlockState,
                 tripped: &[(InterlockSource, bool)],
                 web_release_pending: bool,
                 run_state_ok: bool, pcs_online: bool,
                 now: u64) -> (Action, DoDecision) { .. }
}
```
实现要点：
- 有效触发源（Estop/Flood/Fire tripped true）沿（上拍无→本拍有）→ `TriggerLatch`，更新 `active_pcs_stop_sources`。
- 全部触发源复位：若此前 latched 且本拍全 false：记录 `source_safe_since = now`；保持 ≥ hold：
  - `web_release_pending`（人工明确放行，可容忍 stop_failed 态）或 `auto_release && !stop_failed`（停机已确认）
    → `ReleaseLatch`（清 latched/stop_failed/safe_since）; else 维持。
- **auto 释放要求 `!stop_failed`**（stop() 停机确认超时置位后禁止自动解 latch，防联锁静默失效；仅人工 web 可放行，装配对人工放行补审计事件）。
- latch 期间不重复 Trigger。
- DO 决策：`run_state_ok = last_run_state∈{1,2,3}`；`fault = latched||stop_failed || !pcs_online || m1(pcs_online&&!run_state_ok&&!latched)`。DO1 = run_state_ok && !latched；DO2 = fault（持久态）。
- 门禁 DI 变化仅作事件（由装配检测 event-only；状态机可不含，装配单独发事件）。

- [ ] **Step 2: 单测（interlock 状态机纯函数）**

触发沿→TriggerLatch；复位+hold 到→auto_release ReleaseLatch；非 auto 且无 web→仍 latch；web_release_pending 且 safe→release；stop_failed 由装配置（可经 setter 或 tick 输入）→DO2；M1（online 且 !run_state_ok 且 !latched）→DO2 fault；run ok 且 !latched→DO1。

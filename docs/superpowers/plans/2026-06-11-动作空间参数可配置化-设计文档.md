**背景：** AI 引擎的动作空间参数（`p_batt_set`、`load_shedding` 取值范围）目前在 `action_validator.rs` 中硬编码为固定值，无法满足台区运维人员根据现场实际情况动态调整的需求。

## 1. 技术选型：数据库优先的加载逻辑

### 1.1 加载优先级

```
启动时 ConfigLoader 加载逻辑：

1. 读取 ai_engine.toml 的 action_space 配置
2. 连接 SQLite 数据库，查询 action_space_config 表
3. 数据库配置优先于文件配置（支持运行时动态调整）
4. 执行参数校验（ASC-01 ~ ASC-05）
5. 构建 ActionSpaceConfig 实例，注入 ActionValidator
```

**设计原则：**
- 数据库配置覆盖文件配置（永久生效）
- 文件配置仅作"默认模板"（首次初始化）
- 运行时修改数据库配置，立即生效（热加载）

### 1.2 热加载机制

配置变更通过 Web API 写入数据库后，通过 `Arc<RwLock>` 实时同步到内存：

```
Web API (PUT /api/v1/ai/action-space)
    │
    ▼
StorageService.update_action_space_config()
    │
    ▼
ConfigLoader.reload()       // 写入 DB + 更新内存缓存
    │
    ▼
ActionSpaceValidator.reload() // 重新读取最新配置
```

### 1.3 向后兼容

若配置文件未指定 `action_space` 节，系统必须：
1. 使用默认值（与原硬编码一致）：`max_batt_charge_power = 50.0`, `max_batt_discharge_power = 50.0`, `max_load_shedding = 60.0`
2. 记录 WARN 日志：`action_space not configured, using defaults`

pub struct ConfigLoader {

    /// 更新配置（写 DB + 刷新缓存）

### 2.3 动作空间参数结构

按 PRD 第3.1.1 节定义，`ActionSpaceConfig` 包含以下三个核心参数：

| 参数名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `max_batt_charge_power` | f64 (kW) | 电池最大充电功率（正值） | > 0 |
| `max_batt_discharge_power` | f64 (kW) | 电池最大放电功率（正值） | > 0 |
| `max_load_shedding` | f64 (kW) | 最大可中断负荷量 | >= 0 |

与现有 `ActionConstraintConfig` 的关系（PRD 第 3.1.3 节）：

| 现有配置 | 用途 | 与 ActionSpaceConfig 的关系 |
|----------|------|----------------------------|
| `p_batt_ramp_limit_kw` | 变化率限制 | 独立参数，不依赖 ActionSpaceConfig |

| `max_apparent_power_kva` | 视在功率上限 | 独立参数（用于 ASC-04/ASC-05 校验） |
| `pv_limit_min` | 光伏限功率下限 | 独立参数 |
| **`max_batt_charge_power`** | **电池充电上限** | **新增，替换硬编码 -50** |
| **`max_batt_discharge_power`** | **电池放电上限** | **新增，替换硬编码 +50** |
| **`max_load_shedding`** | **可中断负荷上限** | **新增，替换硬编码 60** |

## 3. 数据库设计

### 3.1 表结构

按 PRD 第 3.2.2 节，数据库表字段与 PRD 一致：

```sql
CREATE TABLE action_space_config (
    id                          INTEGER PRIMARY KEY AUTOINCREMENT,
    transformer_id              TEXT NOT NULL UNIQUE,  -- 台区ID
    max_batt_charge_power       REAL NOT NULL DEFAULT 50.0, -- 电池最大充电功率 (kW)
    max_batt_discharge_power    REAL NOT NULL DEFAULT 50.0, -- 电池最大放电功率 (kW)
    max_load_shedding           REAL NOT NULL DEFAULT 60.0, -- 最大可中断负荷 (kW)
    created_at                  TEXT NOT NULL, -- 创建时间（ISO 8601）
    updated_at                  TEXT NOT NULL, -- 更新时间（ISO 8601）
    updated_by                  TEXT DEFAULT 'system'  -- 最后更新者
);

CREATE INDEX idx_action_space_transformer ON action_space_config(transformer_id);
```

**唯一约束**: `(transformer_id)` 唯一索引。

### 3.2 初始数据（文件配置模板）

```sql
-- 首次初始化时插入默认记录
INSERT INTO action_space_config (transformer_id, max_batt_charge_power, max_batt_discharge_power, max_load_shedding, created_at, updated_at)
VALUES ('default', 50.0, 50.0, 60.0, datetime('now'), datetime('now'));
```

### 3.3 Rust 模型定义

```rust
/// 动作空间配置（数据库模型）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ActionSpaceConfig {
    pub id: Option<i64>,
    pub transformer_id: String,
    pub max_batt_charge_power: f64,
    pub max_batt_discharge_power: f64,
    pub max_load_shedding: f64,
    pub created_at: String,
    pub updated_at: String,
    pub updated_by: String,
}

impl ActionSpaceConfig {
    /// 校验配置参数合法性（ASC-01 ~ ASC-05）
    pub fn validate(&self, max_apparent_power_kva: f64) -> Result<(), AiEngineError> {
        // ASC-01: max_batt_charge_power > 0
        if self.max_batt_charge_power <= 0.0 {
            return Err(AiEngineError::ConfigError(
                "ASC-01: max_batt_charge_power must be > 0".into(),
            ));
        }
        // ASC-02: max_batt_discharge_power > 0
        if self.max_batt_discharge_power <= 0.0 {
            return Err(AiEngineError::ConfigError(
                "ASC-02: max_batt_discharge_power must be > 0".into(),
            ));
        }
        // ASC-03: max_load_shedding >= 0
        if self.max_load_shedding < 0.0 {
            return Err(AiEngineError::ConfigError(
                "ASC-03: max_load_shedding must be >= 0".into(),
            ));
        }
        // ASC-04: max_batt_charge_power <= max_apparent_power_kva
        if self.max_batt_charge_power > max_apparent_power_kva {
            return Err(AiEngineError::ConfigError(
                format!(
                    "ASC-04: max_batt_charge_power ({}) must be <= max_apparent_power_kva ({})",
                    self.max_batt_charge_power, max_apparent_power_kva
                ),
            ));
        }
        // ASC-05: max_batt_discharge_power <= max_apparent_power_kva
        if self.max_batt_discharge_power > max_apparent_power_kva {
            return Err(AiEngineError::ConfigError(
                format!(
                    "ASC-05: max_batt_discharge_power ({}) must be <= max_apparent_power_kva ({})",
                    self.max_batt_discharge_power, max_apparent_power_kva
                ),
            ));
        }
        Ok(())
    }

    /// 默认配置（向后兼容）
    pub fn default_config() -> Self {
        Self {
            id: None,
            transformer_id: "default".to_string(),
            max_batt_charge_power: 50.0,
            max_batt_discharge_power: 50.0,
            max_load_shedding: 60.0,
            created_at: chrono::Utc::now().to_rfc3339(),
            updated_at: chrono::Utc::now().to_rfc3339(),
            updated_by: "system".to_string(),
        }
    }
}
```

## 4. API 接口定义

### 4.1 接口列表

按 PRD 第 3.3.3 节，API 路径统一为 `/api/v1/ai/action-space`：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/ai/action-space` | 查询当前配置（单台区或全部） |
| PUT | `/api/v1/ai/action-space` | 全量更新配置 |
| PATCH | `/api/v1/ai/action-space` | 部分更新配置 |

### 4.2 请求/响应格式

**GET /api/v1/ai/action-space?transformer_id=xxx**

查询参数：
- `transformer_id`（可选）：台区ID，不提供则返回所有台区配置

响应（单台区）：
```json
{
  "transformer_id": "agri_area_01",
  "max_batt_charge_power": 50.0,
  "max_batt_discharge_power": 50.0,
  "max_load_shedding": 60.0,
  "updated_at": "2026-06-11T08:00:00Z",
  "updated_by": "admin"
}
```

响应（全部台区）：
```json
{
  "configs": [
    {
      "transformer_id": "agri_area_01",
      "max_batt_charge_power": 50.0,
      "max_batt_discharge_power": 50.0,
      "max_load_shedding": 60.0,
      "updated_at": "2026-06-11T08:00:00Z",
      "updated_by": "admin"
    }
  ]
}
```

**PUT /api/v1/ai/action-space**

全量更新（要求提供所有字段）：

```json
{
  "transformer_id": "agri_area_01",
  "max_batt_charge_power": 40.0,
  "max_batt_discharge_power": 40.0,
  "max_load_shedding": 50.0
}
```

响应：
```json
{
  "status": "ok",
  "transformer_id": "agri_area_01"
}
```

**PATCH /api/v1/ai/action-space**

部分更新（仅提供需要变更的字段）：

```json
{
  "transformer_id": "agri_area_01",
  "max_batt_charge_power": 30.0
}
```

### 4.3 错误响应

| HTTP 状态码 | 场景 | 响应体 |
|-------------|------|--------|
| 404 | 台区配置不存在 | `{"error": "transformer_id not found", "transformer_id": "xxx"}` |
| 400 | 参数校验失败（ASC-01~ASC-05） | `{"error": "validation failed", "details": "ASC-04: ..."}` |
| 403 | 无管理员权限 | `{"error": "forbidden", "message": "admin role required"}` |

### 4.4 配置文件格式

在 `ai_engine.toml` 中新增 `action_space` 节：

```toml
[action_space]
max_batt_charge_power = 50.0    # kW，正值
max_batt_discharge_power = 50.0 # kW，正值
max_load_shedding = 60.0        # kW
```

## 6. ActionValidator 集成方案

### 6.1 集成架构

```
ConfigLoader (mupc-ai-engine)
    │
    ├── load()         启动时从 DB 加载配置到缓存
    ├── reload()       热加载：DB → 内存缓存
    └── get_config()   运行时查询配置
           │
           ▼
ActionValidator (mupc-ai-engine)
    │
    ├── validate()  使用可配置参数校验动作输出
    └── parse_action_output()  使用可配置范围进行 clamp
```

### 6.2 validate() 改造

按 PRD 第 3.4.1 节，`action_validator.rs` 第 163-166 行的硬编码 clamp 替换为动态配置：

```rust
// 替换前（硬编码）
validated.p_batt_set = validated.p_batt_set.clamp(-50.0, 50.0);
validated.load_shedding = validated.load_shedding.clamp(0.0, 60.0);

// 替换后（配置驱动）
validated.p_batt_set = validated.p_batt_set.clamp(
    -self.config.action_space.max_batt_charge_power,
     self.config.action_space.max_batt_discharge_power
);
validated.load_shedding = validated.load_shedding.clamp(0.0, self.config.action_space.max_load_shedding);
```

### 6.3 parse_action_output() 改造

```rust
/// 解析 RL 模型输出向量为 ActionOutput（可配置范围）
pub fn parse_action_output(raw: &[f32], config: &ActionSpaceConfig) -> Option<ActionOutput> {
    if raw.len() < 3 {
        return None;
    }
    Some(ActionOutput {
        p_batt_set: (raw[0] as f64).clamp(
            -config.max_batt_charge_power,
             config.max_batt_discharge_power,
        ),
        load_shedding: (raw[1] as f64).clamp(0.0, config.max_load_shedding),
        pv_limit: raw[2] as f64, // pv_limit 由其他配置控制，此处不限制
    })
}
```

### 6.4 与 ModelManager 集成

在 `full_decision_cycle()` 的 Step 7（动作约束校验）中注入台区配置：

```rust
// Step 7: 动作约束校验（使用可配置参数）
let transformer_id = fused_state.transformer_id.clone();
let config = self.config_loader
    .get_config(&transformer_id)
    .await
    .unwrap_or_else(|| ActionSpaceConfig::default_config());

let (validated, violations) = self.action_validator
    .validate_with_config(&rl_action, fused_state.dispatch_p_set, is_anti_reverse, &config)
    .await;
```

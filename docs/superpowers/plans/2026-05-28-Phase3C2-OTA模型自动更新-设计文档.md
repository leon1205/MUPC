## 1. 需求概述

### 1.1 项目背景

Phase 3C 已实现 AI 优化引擎（LSTM 预测、MADDPG/PPO 决策），Phase 3C.2 在此基础上实现**模型自动更新（OTA）**功能，使 AI 模型能够在现场运行时接收并应用更新，无需人工干预。

### 1.2 目标

1. 实现可靠的模型 OTA 更新机制
2. 支持断点续传和增量更新
3. 确保模型安全性（签名验证）
4. 提供自动回滚机制保障业务连续性

### 1.3 技术栈

| 组件 | 选择 | 说明 |
|------|------|------|
| 语言 | Rust 1.75+ | |
| 异步运行时 | Tokio 1.x | |

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum OtaState {
    /// 空闲状态
    #[default]
    Idle,
    /// 检查更新中
    Checking,
    /// 下载中
    Downloading { progress: u8 },
    /// 验证中
    Verifying,
    /// 应用中
    Applying,
    /// 已应用（模型已替换，等待策略引擎加载）

    /// 已完成
    Completed,
    /// 回滚中
    RollingBack,
    /// 失败

}
```

```
                      └──────┬─────┘     │
                             │            │

                       ┌──────────┐  ┌──────────┐
                       │COMPLETE  │  │  FAILED  │
                       └──────────┘  └──────────┘
```

### 3.3 状态转换规则

| 当前状态 | 事件 | 下一状态 | 动作 |
|---------|------|---------|------|
| Idle | check_updates() | Checking | - |
| Checking | found_update | Downloading | 初始化下载器 |
| Checking | no_update | Idle | - |
| Checking | error | Failed | 记录错误 |
| Downloading | download_complete | Verifying | 停止下载器 |
| Downloading | retry_failed | Failed | 增加重试计数 |
| Downloading | cancel() | Idle | 清理临时文件 |
| Verifying | verify_success | Applying | 启动模型应用器 |
| Verifying | verify_failed | Failed | 清理更新包 |
| Applying | apply_success | Applied | 通知策略引擎加载模型 |
| Applying | apply_failed | RollingBack | 触发回滚 |
| Applied | model_loaded | Completed | 更新 version.json |
| Applied | load_failed | RollingBack | 触发回滚 |
| RollingBack | rollback_success | Idle | 记录回滚事件 |
| RollingBack | rollback_failed | Failed | 进入安全模式 |

## 7. 核心模块实现

### 7.1 下载器（downloader.rs）

```rust
//! 下载器模块 - 支持断点续传

use crate::error::OtaError;
use crate::config::{DownloadParams, OtaConfig};
use reqwest::Client;
use std::path::PathBuf;
use tokio::fs::File;
use tokio::io::{AsyncWriteExt, AsyncSeekExt};
use tracing::{info, warn, error};

/// 下载进度回调
pub type ProgressCallback = Box<dyn Fn(u64, u64) + Send + Sync>;

/// 下载器
pub struct Downloader {
    client: Client,
    config: OtaConfig,
}

impl Downloader {
    pub fn new(config: &OtaConfig) -> Self {
        let client = Client::builder()
            .timeout(std::time::Duration::from_secs(config.download_timeout))
            .build()
            .expect("Failed to create HTTP client");

        Self {
            client,
            config: config.clone(),
        }
    }

    /// 断点续传下载
    pub async fn download_with_resume(
        &self,
        params: &DownloadParams,
        temp_dir: &PathBuf,
        progress_callback: Option<ProgressCallback>,
    ) -> Result<PathBuf, OtaError> {
        let file_name = format!("{}_{}.tmp", params.model_type, params.target_version);
        let temp_path = temp_dir.join(file_name);
        let offset = self.get_resume_offset(&temp_path).await?;

        info!("Starting download: {}, offset={}", params.url, offset);

        let mut file = File::create(&temp_path).await
            .map_err(|e| OtaError::IoError(e.to_string()))?;

        let mut request = self.client.get(&params.url);

        if offset > 0 {
            request = request.header("Range", format!("bytes={}-", offset));
        }

        let response = request.send().await
            .map_err(|e| OtaError::NetworkError(e.to_string()))?;

        let total_size = response.content_length()
            .unwrap_or(0);
        let mut downloaded = offset;

        let mut stream = response.bytes_stream();
        let mut last_progress = 0u8;

        while let Some(chunk_result) = stream.next().await {
            let chunk = chunk_result.map_err(|e| OtaError::DownloadFailed(e.to_string()))?;
            file.write_all(&chunk).await
                .map_err(|e| OtaError::IoError(e.to_string()))?;
            downloaded += chunk.len() as u64;

            // 回调进度
            if let Some(ref cb) = progress_callback {
                if total_size > 0 {
                    let progress = ((downloaded * 100) / total_size) as u8;
                    if progress != last_progress {
                        cb(downloaded, total_size);
                        last_progress = progress;
                    }
                }
            }
        }

        file.flush().await
            .map_err(|e| OtaError::IoError(e.to_string()))?;

        info!("Download completed: {} bytes", downloaded);
        Ok(temp_path)
    }

    /// 获取断点续传的偏移量
    async fn get_resume_offset(&self, path: &PathBuf) -> Result<u64, OtaError> {
        let metadata = tokio::fs::metadata(path).await;

        match metadata {
            Ok(meta) => {
                let size = meta.len();
                info!("Resuming from byte: {}", size);
                Ok(size)
            }
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
                Ok(0)
            }
```

```rust
    /// SHA-256 文件校验
    pub async fn verify_checksum(&self, path: &Path, expected: &str) -> Result<bool, OtaError> {
        let mut file = File::open(path)
            .map_err(|e| OtaError::IoError(e.to_string()))?;
        let mut reader = BufReader::new(file);
        let mut hasher = Sha256::new();
        let mut buffer = [0u8; 8192];

        loop {
            let bytes_read = reader.read(&mut buffer)
                .map_err(|e| OtaError::IoError(e.to_string()))?;
            if bytes_read == 0 {
                break;
            }
            hasher.update(&buffer[..bytes_read]);
        }

        let result = hasher.finalize();
        let hex = hex::encode(result);

        info!("Expected checksum: {}", expected);
        info!("Actual checksum: {}", hex);

        Ok(hex.eq_ignore_ascii_case(expected))
    }

    /// 签名验证
    #[cfg(feature = "ed25519")]
    pub async fn verify_signature_ed25519(
        &self,
        data: &[u8],
        signature: &[u8],
    ) -> Result<bool, OtaError> {
        use ed25519_dalek::{Signature, VerifyingKey};

        let key_data = tokio::fs::read(&self.public_key_path).await
            .map_err(|e| OtaError::IoError(e.to_string()))?;

        let verifying_key = VerifyingKey::from_bytes(&key_data)
            .map_err(|e| OtaError::VerificationFailed(e.to_string()))?;

        let sig = Signature::from_bytes(signature)
            .map_err(|e| OtaError::VerificationFailed(e.to_string()))?;

        Ok(verifying_key.verify(data, &sig).is_ok())
    }

    /// SM2 签名验证
    #[cfg(feature = "sm2")]
    pub async fn verify_signature_sm2(
        &self,
        data: &[u8],
        signature: &[u8],
    ) -> Result<bool, OtaError> {
        use sm2::signature::Verifier;

        let key_data = tokio::fs::read(&self.public_key_path).await
            .map_err(|e| OtaError::IoError(e.to_string()))?;

        let public_key = sm2::PublicKey::from_bytes(&key_data)
            .map_err(|e| OtaError::VerificationFailed(e.to_string()))?;

        let sig = sm2::Signature::from_bytes(signature)
            .map_err(|e| OtaError::VerificationFailed(e.to_string()))?;

        Ok(public_key.verify(data, &sig).is_ok())
    }

    /// 统一签名验证入口
    pub async fn verify_signature(
        &self,
        data: &[u8],
        signature: &[u8],
        algorithm: SignatureAlgorithm,
    ) -> Result<bool, OtaError> {
        match algorithm {
            SignatureAlgorithm::Ed25519 => {

                #[cfg(not(feature = "ed25519"))]

                #[cfg(not(feature = "sm2"))]

        }
    }
```

```rust
use crate::config::OtaConfig;
use crate::error::OtaError;

/// 定时调度器

    /// 启动定时调度
    pub async fn start<F, Fut>(&self, check_callback: F) -> Result<(), OtaError>
    where
        F: Fn() -> Fut + Send + Sync + 'static,
        Fut: std::future::Future<Output = ()> + Send,
    {
        let check_interval = Duration::from_secs(self.config.check_interval);
        let window_start = self.parse_time(&self.config.download_window_start)?;
        let window_end = self.parse_time(&self.config.download_window_end)?;

        info!("Scheduler started, interval: {:?}", check_interval);
        info!("Download window: {} - {}", self.config.download_window_start, self.config.download_window_end);

        let mut ticker = interval(check_interval);
        let mut stopped = false;

        while !stopped {
            tokio::select! {
                _ = ticker.tick() => {
                    let now = chrono::Local::now();
                    let current_minutes = now.hour() * 60 + now.minute();

                    if Self::is_in_download_window(current_minutes, window_start, window_end) {
                        info!("Within download window, triggering check");
                        check_callback().await;
                    } else {
                        info!("Outside download window, skipping check");
                    }
                }
            }
        }

        Ok(())
    }

    /// 启动调度器（支持启动时检查和命令接收）
    pub async fn start_with_commands<F, Fut>(
        config: OtaConfig,
        check_callback: F,
        check_on_startup: bool,
    ) -> Result<(), OtaError>
    where
        F: Fn() -> Fut + Send + Sync + 'static,
        Fut: std::future::Future<Output = ()> + Send,
    {
        let check_interval = Duration::from_secs(config.check_interval);
        let window_start = Self::parse_time_impl(&config.download_window_start)?;
        let window_end = Self::parse_time_impl(&config.download_window_end)?;
        let (command_tx, mut command_rx) = tokio::sync::mpsc::channel::<SchedulerCommand>(10);

        info!("Scheduler started, interval: {:?}", check_interval);
        info!("Download window: {} - {}", config.download_window_start, config.download_window_end);

        let mut ticker = interval(check_interval);
        let mut stopped = false;

        // 启动时检查（如果启用）
        if check_on_startup {
            info!("Triggering startup check");
            check_callback().await;
        }

        while !stopped {
            tokio::select! {
                _ = ticker.tick() => {
                    let now = chrono::Local::now();
                    let current_minutes = now.hour() * 60 + now.minute();

                    if Self::is_in_download_window(current_minutes, window_start, window_end) {
                        info!("Within download window, triggering check");
                        check_callback().await;
                    } else {
                        info!("Outside download window, skipping check");
                    }
                }
                Some(cmd) = command_rx.recv() => {
                    match cmd {
                        SchedulerCommand::CheckNow => {
                            info!("Received CheckNow command");
                            check_callback().await;
                        }
                        SchedulerCommand::Stop => {
                            info!("Received Stop command");
                            stopped = true;
                        }
                    }
                }
            }
        }

        Ok(())
    }

    /// 停止调度器
    pub fn stop(&self) {
        let _ = self.command_tx.blocking_send(SchedulerCommand::Stop);
    }

    /// 解析时间字符串 (HH:MM)
    fn parse_time(&self, time_str: &str) -> Result<u32, OtaError> {
        Self::parse_time_impl(time_str)
    }

    /// 解析时间字符串 (HH:MM) - 静态方法
    fn parse_time_impl(time_str: &str) -> Result<u32, OtaError> {
        let parts: Vec<&str> = time_str.split(':').collect();
        if parts.len() != 2 {
            return Err(OtaError::ConfigError(
                format!("Invalid time format: {}", time_str)
            ));
        }

        let hour: u32 = parts[0].parse()
            .map_err(|_| OtaError::ConfigError(
                format!("Invalid hour: {}", parts[0])
            ))?;
        let minute: u32 = parts[1].parse()
            .map_err(|_| OtaError::ConfigError(
                format!("Invalid minute: {}", parts[1])
            ))?;

        Ok(hour * 60 + minute)
    }

    /// 判断是否在下载窗口内
    fn is_in_download_window(current_minutes: u32, start: u32, end: u32) -> bool {
        if start <= end {
            current_minutes >= start && current_minutes <= end
        } else {
            // 跨天情况（如 22:00 - 06:00）
            current_minutes >= start || current_minutes <= end
        }
    }
}
```

```rust
        Self {

        }
    }

    /// 启动定时调度
    pub async fn start_scheduler(&self) -> Result<(), OtaError> {
        let scheduler = Scheduler::new(self.config.clone());
        let manager = Arc::new(self.clone());

        scheduler.start(move || {
            let mgr = manager.clone();
            async move {
                if let Err(e) = mgr.check_updates().await {
                    error!("Scheduled update check failed: {}", e);
                }
            }
        }).await;

        *self.scheduler.write().await = Some(scheduler);
        Ok(())
    }

    /// 更新状态
    async fn set_state(&self, new_state: OtaState) {
        *self.state.write().await = new_state.clone();

        if let Some(ref mut task) = *self.current_task.write().await {
            task.state = new_state;
            task.updated_at = Utc::now();
        }
    }

    /// 验证更新状态
    fn validate_state(&self, expected: OtaState) -> Result<(), OtaError> {
        let current = self.get_state();
        if current != expected {
            return Err(OtaError::StateMachineError(
                format!("Invalid state: expected {:?}, got {:?}", expected, current)
            ));
        }
        Ok(())
    }

impl OtaManager for OtaManagerImpl {
    fn get_current_version(&self, model_type: ModelType) -> Result<ModelVersion, OtaError> {
        let version_file = self.config.model_storage_path.join("version.json");

        if !version_file.exists() {
            return Err(OtaError::VerificationFailed(
                format!("Version file not found: {:?}", version_file)
            ));
        }

        let content = std::fs::read_to_string(&version_file)
            .map_err(|e| OtaError::IoError(e.to_string()))?;

        let versions: serde_json::Value = serde_json::from_str(&content)
            .map_err(|e| OtaError::VerificationFailed(e.to_string()))?;

        let key = match model_type {
            ModelType::Lstm => "lstm",
            ModelType::Maddpg => "maddpg",
        };

        let model_info = versions.get(key)
            .ok_or(OtaError::VerificationFailed(
                format!("Model not found in version.json: {}", key)
            ))?;

        Ok(ModelVersion {
            model_type,
            version: model_info["version"].as_str().unwrap_or("0.0.0").to_string(),
            updated_at: chrono::DateTime::parse_rfc3339(
                model_info["updated_at"].as_str().unwrap_or("1970-01-01T00:00:00Z")
            ).map(|dt| dt.with_timezone(&Utc))
            .unwrap_or_else(|_| Utc::now()),
            md5: model_info["md5"].as_str().unwrap_or("").to_string(),
            size: model_info["size"].as_u64().unwrap_or(0),
            path: PathBuf::from(model_info["path"].as_str().unwrap_or("")),
        })
    }

    async fn check_updates(&self) -> Result<Vec<UpdateInfo>, OtaError> {
        self.set_state(OtaState::Checking).await;

        // TODO: 连接 OTA 服务器获取更新列表

        self.set_state(OtaState::Idle).await;

    async fn start_download(&self, update_info: &UpdateInfo) -> Result<String, OtaError> {
        self.validate_state(OtaState::Idle)?;

        let task_id = uuid::Uuid::new_v4().to_string();
        let params = DownloadParams {
            url: update_info.url.clone(),
            signature: update_info.signature.clone(),
            checksum: update_info.checksum.clone(),
            model_type: update_info.model_type,
            target_version: update_info.available_version.clone(),
        };

        let temp_dir = self.config.model_storage_path.join("temp");
        tokio::fs::create_dir_all(&temp_dir).await
            .map_err(|e| OtaError::IoError(e.to_string()))?;

        // 创建任务
        let task = OtaTask {
            task_id: task_id.clone(),
            model_type: update_info.model_type,
            from_version: update_info.current_version.clone(),
            to_version: update_info.available_version.clone(),
            state: OtaState::Downloading { progress: 0 },
            progress: 0,
            created_at: Utc::now(),
            updated_at: Utc::now(),
        };
        *self.current_task.write().await = Some(task);

        self.set_state(OtaState::Downloading { progress: 0 }).await;

        // 下载回调
        let progress_callback = Box::new(|downloaded: u64, total: u64| {
            let progress = if total > 0 {
                ((downloaded * 100) / total) as u8
            } else {
                0
            };
            // 更新进度
            tracing::debug!("Download progress: {}%", progress);
        });

        // 执行下载
        let _temp_path = self.downloader.download_with_resume(
            &params,
            &temp_dir,
            Some(progress_callback),
        ).await?;

        self.set_state(OtaState::Verifying).await;

        Ok(task_id)
    }

    fn get_download_progress(&self, task_id: &str) -> Result<u8, OtaError> {
        let task = self.current_task.read().await;
        if let Some(ref t) = *task {
            if t.task_id == task_id {
                return Ok(t.progress);
            }
        }
        Err(OtaError::StateMachineError(
            format!("Task not found: {}", task_id)
        ))
    }

    async fn cancel_download(&self, task_id: &str) -> Result<(), OtaError> {
        let task = self.current_task.read().await;
        if task.as_ref().map(|t| &t.task_id).filter(|id| *id == task_id).is_none() {
            return Err(OtaError::StateMachineError(
                format!("Task not found: {}", task_id)
            ));
        }
        drop(task);

        info!("Cancelling download for task: {}", task_id);

        // 清理临时文件
        let temp_dir = self.config.model_storage_path.join("temp");
        if temp_dir.exists() {
            // 删除该任务的临时文件
            let tmp_files = fs::read_dir(&temp_dir).await
                .map_err(|e| OtaError::IoError(e.to_string()))?;
            let task = self.current_task.read().await;
            if let Some(ref t) = *task {
                let prefix = format!("{}_{}", t.model_type, t.to_version);
                // 清理逻辑...
            }
        }

        // 重置状态
        *self.current_task.write().await = None;
        self.set_state(OtaState::Idle).await;

        info!("Download cancelled: {}", task_id);
        Ok(())
    }

    async fn apply_update(&self, task_id: &str) -> Result<(), OtaError> {
        self.validate_state(OtaState::Verifying)?;

        let task = self.current_task.read().await;
        let task = task.as_ref()
            .ok_or(OtaError::StateMachineError(
                format!("Task not found: {}", task_id)
            ))?;

        self.set_state(OtaState::Applying).await;

        // 备份当前模型
        self.applicator.backup_current(task.model_type, &task.from_version).await?;

        // 应用新模型（包含解压、MD5计算、预热）
        let model_version = self.applicator.apply(task.model_type, &task.to_version).await?;

        // 通知策略引擎加载新模型
        // Placeholder: strategy_engine.notify_model_updated(task.model_type, model_version.version).await?;

        // 清理旧备份
        self.applicator.cleanup_old_model(task.model_type, &task.to_version).await?;

        self.set_state(OtaState::Applied).await;

        info!("Model applied successfully, waiting for strategy engine to load: {:?}", task.model_type);

        Ok(())
    }

    async fn rollback(&self, model_type: ModelType) -> Result<(), OtaError> {
        self.set_state(OtaState::RollingBack).await;

        let task = self.current_task.read().await;
        let task = task.as_ref()
            .ok_or(OtaError::StateMachineError("No active task".to_string()))?;

        let mut rollback_mgr = self.rollback_manager.lock();
        rollback_mgr.rollback(model_type, &task.from_version).await?;

        self.set_state(OtaState::Idle).await;

        Ok(())
    }

    fn get_state(&self) -> OtaState {
        self.state.read().await.clone()
    }

    fn get_current_task(&self) -> Option<OtaTask> {
        self.current_task.read().await.clone()
    }

    fn get_update_history(&self, limit: usize) -> Result<Vec<UpdateRecord>, OtaError> {
        let history = self.update_history.read();
        Ok(history.iter().rev().take(limit).cloned().collect())
    }

    fn query_versions(&self) -> Result<Vec<VersionQueryResponse>, OtaError> {
        let mut responses = Vec::new();

        for model_type in &[ModelType::Lstm, ModelType::Maddpg] {
            let current = self.get_current_version(*model_type)?;
            responses.push(VersionQueryResponse {
                model_type: *model_type,
                current_version: current.version,
                available_updates: Vec::new(), // 需连接 OTA 服务器获取
                last_check: Utc::now(),
            });
        }

        Ok(responses)
    }

    async fn handle_command(&self, cmd: OtaUpdateCommand) -> Result<OtaUpdateResponse, OtaError> {
        info!("Received OTA command: {:?}", cmd);

        match cmd.cmd.as_str() {
            "ota_update" => {
                let update_info = UpdateInfo {
                    model_type: cmd.model_type,
                    current_version: self.get_current_version(cmd.model_type)?.version,
                    available_version: cmd.version,
                    size: 0,
                    checksum: cmd.checksum,
                    signature: cmd.signature,
                    url: cmd.url,
                    is_incremental: false,
                    base_version: None,
                };

                let task_id = self.start_download(&update_info).await?;
                Ok(OtaUpdateResponse {
                    task_id,
                    model_type: cmd.model_type,
                    status: self.get_state(),
                    progress: Some(self.get_download_progress(&task_id)?),
                    error_message: None,
                })
            }
            "ota_cancel" => {
                let current_task = self.current_task.read().await;
                if let Some(ref task) = *current_task {
                    self.cancel_download(&task.task_id).await?;
                }
                Ok(OtaUpdateResponse {
                    task_id: cmd.task_id,
                    model_type: cmd.model_type,
                    status: OtaState::Idle,
                    progress: None,
                    error_message: None,
                })
            }
            "ota_status" => {
                Ok(OtaUpdateResponse {
                    task_id: cmd.task_id,
                    model_type: cmd.model_type,
                    status: self.get_state(),
                    progress: Some(0),
                    error_message: None,
                })
            }
            _ => Err(OtaError::StateMachineError(
                format!("Unknown command: {}", cmd.cmd)
            ))
        }
    }
}
```

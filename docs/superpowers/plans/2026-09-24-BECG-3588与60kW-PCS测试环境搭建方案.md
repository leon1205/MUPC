## 1. 目标与验收定义

### 1.1 目标（按风险从低到高分四级，逐级放行）

| 级 | 名称 | 高压侧状态 | 验证内容 |
|----|------|-----------|---------|
| **L0** | 桌面仿真 | 无 PCS、无 BECG（或仅 PC） | 点表/字节序/控制帧/联锁逻辑在仿真从站上全通 |
| **L1** | 通信联调 | PCS **仅控制上电**（交流 breaker 合、直流不接、交流输出不接） | 3 区遥测全读、4 区读写、启停与急停链路（不输出功率） |
| **L2** | 小功率带电 | 直流源**限流**接入；交流空载或≤5kW 阻性负载 | 低功率充/放/无功指令、斜坡、保护动作（急停/故障复位） |
| **L3** | 并网/带载（**可选，条件具备才做**） | 完整保护配置 + 持证电工 | 额定区间功率指令、并离网、保护定值核验 |

> **放行原则**：下一级未验收通过，不得进入上一级通电状态。**L0/L1 不需要任何高压作业**，应占本测试环境 80% 的工作量。

### 1.2 验收清单（L1 最小集）

| # | 项 | 方法 | 判据 | 依据 |
|---|----|------|------|------|
| A1 | BECG 启动且 `mupcd` 服务 active | `systemctl status mupcd` | active (running)，无 restart 循环 | `[部署]` |
| A2 | 8 路 RS485 节点齐全 | `ls /dev/ttyS0 /dev/ttyS3 /dev/ttyS7 /dev/ttyS8 /dev/ttyP0..3` | 8 个节点全在 | `[3588规格]§1.5` |
| A3 | PCS 链路建立 | `journalctl -u mupcd` 看 intercore 心跳 | 读到 3 区 `1013 模块运行状态` 且周期刷新 | `[PCS协议]p9` |
| A4 | 3 区全量读一致 | MUPC 读数 vs ModbusPoll 同寄存器比对 | 逐点相等（含字节序换算） | `[PCS协议]p4,9-12` |
| A5 | 4 区写-回读 | 写 `1001=±小值` 后回读 | 回读 = 写入值 | `[PCS协议]p13` |
| A6 | 停止指令 | 写 `500=0` | `1013` 变为 0（停机） | `[PCS协议]p13` |
| A7 | 急停硬链路 | 按下急停按钮（S1 干接点） | PCS 报急停故障（告警1 bit2 / 故障代码 11；L0 仿真的急停故障位经 `PcsSimState::set_alarm` 置位） | `[PCS协议]p6,p15` |
| A8 | 南向从站仿真 | **5 路**接 ModbusSlave 仿真表（bms/meter_batt/fire/hvac/grid_meter） | `southd` 各站 online、遥测入库 | `[配置]`、`[工具]` |

**串口节点映射（`[3588规格]§1.5` COM1-8 表）——本方案最重要的表之一**：

| 物理通道（A/B 标号） | 20 芯凤凰端子引脚 | 设备节点 |

| CH1 A0/B0 | 1 / 3 | **ttyS0** |
| CH2 A5/B5 | 2 / 4 | **ttyP0** |
| CH3 A2/B2 | 7 / 9 | **ttyS3** |
| CH4 A6/B6 | 8 / 10 | **ttyP1** |
| CH5 A3/B3 | 11 / 13 | **ttyS7** |
| CH6 A7/B7 | 12 / 14 | **ttyP2** |

### 2.2 PCS CoEPCS60-DL2M（`[PCS规格]`、`[PCS手册]`、`[PCS协议]`）

| 项 | 值 |
|----|----|
| 功率 / 拓扑 | 60kW；**双级式（DCDC+DCAC）；无变压器隔离** |
| 直流 | **48–850V**（满功率 335–850V）；额定 180A |
| 交流（并网） | 380/400V −15…+15%；额定 **90A**；45–65Hz；THDi<3%；PF>0.99（−1…+1 可调）；110% 10min、120% 1min |
| 防护 / 冷却 / 噪声 | **IP20**；智能风冷 445 CFM；≤65dB |
| 尺寸 / 环境 | 500×600×200 mm；−25–60℃（>45℃ 降额）；≤3000m |
| 通信 | **RS485 Modbus RTU**（+CAN2.0）；**默认 19200 N-8-1**；地址拨码，默认 1；**EMS 接 485 的 A2/B2**（大屏接 A1/B1）；**存在高 8 位与低 8 位互换** |
| 点表 | **3 区（FC04 只读）1000–1075**；**4 区（FC03 读 / FC06 写，一次一个）500–1057** |
| 关键控制寄存器 | `500` 启停；`501` 故障复位；`1000` 运行模式（0 交流恒功率/1 恒流/2 分相/5 离网主机）；`1001` 有功 ±100kW；`1002` 无功 ±100kvar；`1016` 无功模式（**默认 0=禁止无功**）；`1018` 功率变化率（默认 10 W/ms）；`1020` EMS 波特率（0=19200/1=9600）；`1021` BMS 协议（**默认 1=派能 CAN**）；`1023` 进线方式（默认 4=三相四线）；`1030–1032` 干接点输入 S1–S3 功能；`1033–1035` 干接点输出 K1–K3 |
| 二次端子 | L1/L2/L3/N；BUS+/BUS−；COM1/2 并机、COM3 STS 采样、COM4 驱动 STS；终端电阻拨码；485A1/B1、485A2/B2、24V/GND；CT1–3；S1/S1N/S2/S2N；SCI |
| 线缆（`[PCS手册]§3.7.2` 表3-2） | 直流 >70mm²；交流 >70mm²；**接地 >10mm²**；二次端子 2 芯双绞屏蔽；通讯 屏蔽线 |
| 接地（`§3.7.3`） | **先接地后接线**；接地电阻 **<5Ω**；**与防雷接地分开** |
| 断路器（`§3.7.4`） | **PCS 与交流侧之间必须装外置交流断路器** |
| 力矩（`§3.7.6`） | M6/M8 = **12 N·m**（破坏 16 N·m），适用 CoEPCS60-DL2M |
| 上电现象（`§4.2`） | 合交流断路器 → RUN 闪、WARN 常亮；直流+交流均正常 → WARN 灭、待机；上位机启动 → RUN 常亮 |

     │

     │                              │
     │   ┌─[QF1 交流断路器 4P]── PCS 交流侧 L1/L2/L3/N        （L1 级: 仅控制上电, 输出不接）
     │   │                          │
     │   │        直流源/电池 ─[QF2 直流 2P 断路器]─ PCS BUS+/BUS−   （L2 起, 限流!）

  BECG-3588

### 5.4 PCS 侧寄存器初始化（L1 上电后、任何控制试验前）

| 寄存器 | 建议值 | 理由 |
|---|---|---|
| `1020` EMS 波特率 | 0（19200） | 与 `[配置]` 一致 |
| `1021` BMS 协议 | **按实际**：有电池且协议匹配→对应值；**无电池/无 BMS→0（无 BMS 通信）** | 默认 1=派能 CAN；无 BMS 时保持 1 会持续报"BMS 失联"（告警1 bit15） |
| `1023` 进线方式 | 4（三相四线） | 默认即 4；与台架接线一致 |
| `1030` S1 功能 | **1（开路故障=急停）** | 硬急停链路 |
| `1018` 功率变化率 | 试验期调小（单位 **W/ms**，1 W/ms = 1 kW/s；范围 1–60000，默认 10；如置 1 ⇒ 1 kW/s） | 限制功率阶跃 |
| `1001/1002` | 0 | 上电零功率 |
| `1016` 无功模式 | 0（禁止）→ 需无功试验时再置 10/20/30 | 默认禁止无功 |

## 6. 分阶段实施步骤

### 6.0 L0 桌面仿真（无高压、无 BECG 也可）

1. **L0 主手段 = 进程内 e2e（无需任何串口硬件/驱动）**：`cd mupc && cargo test -p mupc-intercore e2e_pcs_sim`。传输缝**仅 `#[cfg(test)]`**（`PcsStream::Test` + `test_seam` 工厂，生产二进制编译期消除不含 Test 分支）：`ModbusRtuTransport` 的真实 Modbus RTU 客户端栈经进程内 `tokio::io::duplex` 对接 `pcs_sim` 从站仿真（原 `pcs_slave.rs` 逻辑已沉 lib，bin/测试共用）。覆盖 §1.2 A3–A7 的传输层等价物（E1–E6）：链路+心跳（1013）、3 区读+字节互换线格式、4 区有符号写-回读、启停/方向状态机、急停故障位可读（经 `PcsSimState::set_alarm` 置位——**R2 边界已消除**）、并发不串线。
2. **备选手段（双进程/真机前）**：`cargo run -p mupc-intercore --bin pcs_slave -- <串口> 19200 1`（`pcs_sim` 薄壳，行为不变）+ 虚拟串口对（Linux socat / Windows com0com）或 USB-RS485 回环接 `mupcd` x86 构建（亦可直接用 `mupc-sim-bridge`/既有仿真环境，`[部署] deploy-sim.sh`）；如需自造从站：PC 装 ModbusSlave，建从站地址 1、**19200 N-8-1**；按 `[PCS协议]` 3 区 1000–1075 / 4 区 500–1057 建寄存器表，**含高/低 8 位互换**——例：740.0V ⇒ 7400 = 0x1CE8 ⇒ 从站寄存器内填 **0xE81C**；**UInt32 点（1042–1045 / 1072–1075）需"寄存器内字节互换 + 字序 lo_hi"双重处理**；用 ModbusPoll 对读验证互换规则后再给 MUPC 用。
3. 验收：`e2e_pcs_sim` 全绿为 L0 主判据；走备选双进程手段时，§1.2 的 A3–A7 在仿真上全通（急停故障位经 `PcsSimState::set_alarm` 置位，如 `set_alarm(0, 1<<2)` = 告警1 bit2 急停）。
4. 同时用 ModbusSlave 建 5 个从站（bms/hvac/grid/meter_batt/fire，地址与波特率按 §5.2），验 `southd` 上线与遥测。

### 6.1 L1 通信联调（BECG 到位后；PCS 仅控制上电）

**前置**：§7 安全检查全过；PCS 交流侧**只到端子**（不接输出线缆）；直流不接；负载不接。

1. 装机：BECG 上 DIN/挂耳、接 FG；确认 Linux 发行版与 8 个串口节点（§1.2 A2）。
2. 交叉编译与部署：`./deploy/scripts/build-for-rk3588.sh --cross` → `./deploy/scripts/deploy.sh <BECG_IP> --full`；`systemctl enable --now mupcd`。
3. 按 §5.2/§5.3 改配置并重启服务；`journalctl -u mupcd -f` 观察。
4. 合 QF3（BECG 适配器）→ 合 QF1（PCS 控制上电）→ 观察 PCS 面板：**RUN 闪、WARN 常亮**（直流未接，属预期）→ 确认 MUPC 仍能读 3 区（**待厂商确认：直流缺时 3 区是否可读/是否报直流欠压故障而不响应通信**，见 §9-Q3）。
5. 接 PCS 485（CH1↔A2/B2）；**先执行 §5.4 寄存器初始化（含 `1030=1`——不写则 A7 的急停故障位不会报）**，再执行 §1.2 A3–A7。
6. 接 5 路仿真从站，执行 A8。
7. **回退**：任何异常 → 断 QF1 → 断 QF3 → 挂牌。

### 6.2 L2 小功率带电（直流限流接入）

**前置**：L1 全过；直流源限流设定（如 400V/2A）；QF2 为 DC 规格；急停回路已验（L1 的 A7）；**§9-Q4（`1021=0` 无 BMS 能否启动/有无功率限制）与 §9-Q7（恒功率并网是否必接 CT1–3）已获厂商书面答复**（未确认不进入本级，§9 表头）。

1. 断电状态接直流缆（先接 PCS 侧接地复核）→ 合 QF2 → 观察 PCS：直流+交流正常 ⇒ **WARN 灭、待机**（`[PCS手册]§4.2` 步骤2）。
2. 经 MUPC 写 `500=1` 启动 → RUN 常亮。
3. 小功率指令：`1000=0` + `1001` 逐级。**台阶上限写死 ≤ Vdc × Ilim × 0.8**（例：400V×2A×0.8 ≈ 0.64kW ⇒ 台阶 ≤0.6kW），否则拉垮直流源触发"外部直流欠压"（告警4 bit14）误跳；**负功率（充电）台阶仅在直流源具备 sink/回馈能力时允许**，否则禁负台阶（充电向源灌能 ⇒ 直流过压风险）。观察 3 区 `1029/1032` 功率反馈与直流源电流限制是否吻合。
4. 无功试验：`1016=10` + `1002=±小值`；验 `1036` 反馈。
5. 保护验证：**按急停** → PCS 停机+告警位；`501=1` 复位 → 恢复待机。
6. 停机与放电顺序（`[PCS手册]§6.1`）：`500=0` → **等 20s 运行灯熄灭** → 断 QF2 → 断 QF1（断开处挂牌防误合闸）→ **等待 ≥20 分钟（或接放电电阻）至内部电容放电完毕** → 万用表验交流+直流接线均不带电 → 方可开柜/触碰端子 → 断 QF3 → 挂牌上锁。

### 6.3 L3 并网/带载（可选，条件清单全满足才做）

条件：QF1 换 125A 级、电缆 ≥70mm²、接地 <5Ω 实测、核相正序、持证电工两人、负载/并网点许可。**否则不做**——L0–L2 已覆盖本项目软件的全部验证目标。

## 7. 电气安全保障（专项）

### 7.1 层级化防护（从内到外）

| 层 | 措施 | 依据 |
|----|------|------|
| L1 本质限制 | 试验功率/电流上限（L1=0；L2 = **min(≤5kW, Vdc×Ilim×0.8)**，见 §6.2 步骤3）；`1018` 斜坡限小；`1012–1015` 直流电压窗 | 本方案 |
| L2 器件保护 | QF1/QF2 断路器；PCS 内部 68 项故障保护（`[PCS协议]p6-8`）：电网过/欠压、频率、过流、过温、直流母线过/欠压、防孤岛、高低穿 | `[PCS协议]` |
| L3 急停链 | **软停 `500=0`（MUPC）→ 硬急停 S1 干接点（按钮）→ 断路器 QF1/QF2**；三层独立、任一层可单独停机 | `[PCS协议]p13,15`、`[配置]` 联锁设计 |
| L4 物理隔离 | PCS **IP20 ⇒ 柜内/围挡+门锁**；带电端子遮蔽；警示标识于前后级开关 | `[PCS规格]`、`[PCS手册]§1.1` |
| L5 管理措施 | LOTO 上锁挂牌；**两人作业**（**手册加严/行业惯例**：手册 §1.2 仅要求"具备资质的专业人员"）；禁止带电接线/开柜；雷雨不插拔；作业前验电 | LOTO≈`[PCS手册]§1.3/§6.1` 防误合闸意图；两人作业=加严 |

### 7.2 硬约束清单（照抄即合规，均出自手册）

1. **先接地、后接线；拆时地线最后拆**；接地电阻 **<5Ω**；**与防雷接地分开**（`§3.7.3`）。
2. **PCS 与交流侧之间必须有外置交流断路器**（`§3.7.4`）。
3. 接线前**万用表验电**确认线缆不带电；**核相仪确认正序**（L3）（`§3.7.4` 步骤2/3）。
4. 直流接线前**确认电池极性**与端口电压在 48–850V 内（`§3.7.5`）。
5. 端子力矩 **12 N·m**（M6/M8），用**力矩扳手**并记录（`§3.7.6`）。
6. 线缆：功率回路 ≥70mm² 铜；接地 ≥10mm²；二次 2 芯双绞屏蔽（`§3.7.2` 表3-2）。**偏离登记**：表3-2 最小线径**无工况限定**；本台架 L1/L2 按"载流量 ≥ 断路器整定"选小截面属偏离，仅限小电流工况，**L3 恢复 ≥70mm²**（同 §4 缺件#11）。
7. **严禁通电开柜/触碰端子**（`§1.1.1`）；空置端子密封（`§4.1`）。
8. 启动前按 `§4.1` **十三条**逐项检查并**签字留档**。
9. **断电后等待电容放电（`§1.1.1` 危险级 / `§6.1` 步骤3–4 / `§6.2`）**：断开电网及电池连接后，**等待至少 20 分钟（或接放电电阻）**待内部电容放电完毕，**再**用万用表确认交流+直流接线均不带电，方可维护/开柜/触碰端子。**本条为 Z1 评审阻塞项的修复，任何停电作业序列必须包含。**

### 7.3 本台架特有的风险与对策

| 风险 | 说明 | 对策 |
|------|------|------|
| **无变压器隔离** | PCS 为无隔离拓扑 ⇒ **直流侧对地可能带高电位**，直流母排/线缆按带电体管理 | 直流侧全绝缘包覆；直流断路器用 **DC 规格**（灭弧）；禁止单手触碰直流任一极 |
| **IP20 裸机** | 实验室易触碰带电体 | 柜/围挡+门锁+标识；柜门开 ⇒ 视同停电作业 |
| **风扇 445CFM/65dB** | 柜内散热与噪声 | 通风孔对角布置或强排；噪声区戴护耳 |
| **DI 反逻辑** | 3588 DI 低=1/高=0，接反会让"急停按下"读成"正常" | §5.3 上电逐路实测两态后回填 `active_low`；**急停回路用 NC + 断线即动作** |
| **继电器 DO 3A** | 直接驱大负载会烧触点 | DO 只驱指示灯/中间继电器线圈 |
| **仿真从站误接真总线** | PC 的 ModbusSlave 与真表同挂一线会冲突 | 每路点对点；换真表前先拔仿真 |
| **锂电池（若用）** | 热失控风险 | 灭火器+烟感+充电限流+BMS 联锁；无人值守不充电 |

### 7.4 上电/停电顺序（贴墙）

- **上电**：验接地 → 合 QF3（BECG）→ 确认 mupcd 正常 → 合 QF1（PCS 控制）→ 看面板 RUN/WARN → （L2）合 QF2 → 软件启动 `500=1`。
- **停电**：软件 `500=0` → **等 20s 运行灯灭** → 断 QF2 → 断 QF1（挂牌防误合）→ **等 ≥20min（或放电电阻）电容放完** → 万用表验交/直流不带电 → 断 QF3 → 挂牌上锁（`[PCS手册]§6.1`）。
- **急停**：任何异常先按急停按钮，**再**查原因；复位必须人工 `501=1` + 现场确认。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落实平台目标调整：① AI 引擎**彻底停用**（模型不加载、删旁路决策空转、观测空间数据停采；观测结构保留待维度重构后再接回），本地策略引擎（TaiStorage 台区储能治理）成为默认且唯一的策略下发引擎；② 国密/安全启动**只保留框架不做实现**（已实现的 SM3/SM4-CBC 保留，未实现项不推进，全部文档标注 framework-only）。

**Tech Stack:** Rust、tokio、strategy-engine（AiIntegrator/dispatch_ai_decision/run_fallback_strategies）、mupc-core-bin（startup.rs）、mupc-security（feature/模块）、web-api（AI 端点）。

### Task 3: dispatch_ai_decision 删 AI 旁路决策 + AI 分支标暂停

- [ ] **Step 1: 删 AI 旁路决策块**

读 `dispatch_ai_decision`（:409-423）。将：

```rust
            if let Some(manager) = self.model_manager.read().await.as_ref() {
                match manager.full_decision_cycle().await {
                    Ok(a) => tracing::debug!(
                        "本地优先模式：AI 旁路决策 p_ref={}, k_droop={}（仅参考，不下发）",
                        a.p_ref,
                        a.k_droop
                    ),
                    Err(e) => tracing::debug!("本地优先模式：AI 旁路决策失败（忽略）: {}", e),
                }
            }
            return self.run_fallback_strategies().await;
        }
```

替换为：

```rust
    pub async fn dispatch_ai_decision(&self) -> Result<(), AiEngineError> {
        // 本地策略优先 = 生产唯一模式（平台目标调整 2026-09-09：AI 引擎暂停）。

        if *self.local_priority.read().await {
```

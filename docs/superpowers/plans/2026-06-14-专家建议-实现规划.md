## 三、v2.12 规划（基于 SCENE-01 专家建议）

> **聚焦范围**：SCENE-01 台区季节性负荷模式的奖励函数优化

### 3.1 高优先级 🔴

#### R-01：奖励子项标准化

| 项目 | 内容 |
|------|------|
| **专家建议** | 不同子项量纲差异大（`R_pv ∈ [0,100]`，`P_batt ∈ [0,1]`），导致某些项主导学习过程 |
| **改进方案** | 引入 `normalize_reward_component()` 标准化各子项到 `[-1, 1]` 区间，或使用自适应归一化（历史统计 + tanh 映射） |
| **影响文件** | `ai-engine/src/reward_calculator.rs` |
| **验收标准** | 各子项量纲一致，训练收敛速度提升 >= 20% |

#### R-02：引入塑造奖励（提前预警）

| 项目 | 内容 |
|------|------|
| **专家建议** | 变压器过载等事件为稀疏奖励，RL 难以学习 |
| **改进方案** | 负载率 >85% 时开始惩罚：`load_warning = -10.0 × (load - 0.85)`；SOC 接近边界时惩罚：`soc_warning = -5.0 × min(\|SOC - 0.15\|, \|SOC - 0.85\|)` |
| **影响文件** | `ai-engine/src/reward_calculator.rs` |
| **验收标准** | 稀疏事件触发频率降低 >= 50% |

#### R-03：SOC 均衡奖励

| 项目 | 内容 |
|------|------|
| **专家建议** | 当前缺少 SOC 均衡奖励，电池寿命受影响 |
| **改进方案** | 新增 `R_soc_balance = -λ × |SOC - 0.5|`，鼓励 SOC 保持在 50% 附近 |
| **影响文件** | `ai-engine/src/reward_calculator.rs` |
| **验收标准** | SOC 长期偏离 50% 的时间比例降低 >= 30% |

### 3.2 中优先级 🟡（已规划，文档已同步）

#### R-04：变压器过载分段惩罚

| 项目 | 内容 |
|------|------|
| **专家建议** | 当前二次函数不够精细，建议分段函数 |
| **改进方案** | 75%~90% 线性增长，90%~100% 指数增长，>100% 硬惩罚 |
| **影响文件** | `ai-engine/src/reward_calculator.rs` |
| **验收标准** | 变压器过载持续时间降低 >= 40% |
| **状态** | 📋 PRD/设计文档已同步（详见 AI引擎-PRD §6.10、AI引擎-设计文档 §5.11） |

#### R-05：电压斜率惩罚动态权重

| 项目 | 内容 |
|------|------|
| **专家建议** | 当前 `w_6` 固定，电压偏差越大应权重越高 |
| **改进方案** | `w_6(v) = base_w6 × (1.0 + k × |ΔV|)`，动态调整 |
| **影响文件** | `ai-engine/src/reward_calculator.rs` |
| **验收标准** | 电压波动幅度降低 >= 25% |
| **状态** | 📋 PRD/设计文档已同步（详见 AI引擎-PRD §6.11、AI引擎-设计文档 §5.12） |

#### R-06：冲击负荷响应奖励

| 项目 | 内容 |
|------|------|
| **专家建议** | 当前缺失冲击负荷响应奖励，需量控制鲁棒性不足 |
| **改进方案** | 结合 v2.11 分位数预测：`R_shock_response = f(load_shedding, response_time, P90)` |
| **影响文件** | `ai-engine/src/reward_calculator.rs` |
| **验收标准** | 需量超标次数降低 >= 30% |
| **状态** | 📋 PRD/设计文档已同步（详见 AI引擎-PRD §6.12、AI引擎-设计文档 §5.13） |

## 六、已拒绝项

| 建议项 | 拒绝理由 |
|--------|----------|
| 多智能体协同（台区群控） | 超出当前项目范围，需要台区间通信基础设施 |
| 数字孪生仿真平台 | 需要额外硬件资源和专业仿真团队维护 |
| 联邦学习（多台区协同训练） | 涉及数据隐私和跨台区通信问题 |
| 可解释 AI（XAI）可视化 | 运维团队暂无此需求，实现成本高收益有限 |
| 碳排放因子动态化 | 所在地区碳市场不成熟 |
| 绿证交易价值 | 绿证交易市场尚不完善 |
| 辅助服务收益细化（SCENE-B3） | 虚拟电厂辅助服务市场规则各省差异大 |

# S1 · BECG-3568 平台落地与接线映射实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 MUPC 串口默认与校验落到 BECG-3568 板载 RS485 节点上（PCS→`/dev/ttyS0`、关口/台区总表→`/dev/ttyS4`），消除 `/dev/ttyS1`（不存在）与 `/dev/ttyUSB0`（USB 转 485）旧假设在目标硬件上的运行失效。

**Architecture:** BECG-3568（RK3568，后续 RK3588 接口一致）板载 8 路隔离 RS485 = COM1-8 ↔ `ttyS0/S2-S8`（**无 ttyS1**）。PCS 主链路 RS485-1/COM1/`ttyS0`（19200 N-8-1，核间 modbus_rtu）；关口表/台区总表 RS485-4/COM4/`ttyS4`（master_meter）。接线契约文档已落盘（核间 10 §12.1/§12.7、deploy.md §九），本计划只改**代码默认/校验注释/部署模板示例**与相关测试。南向传统设备（PV/负荷）口未规划，rs485-plugin/device-trait 的 `/dev/ttyUSB0` 默认与 `validate_master_meter` 对该默认的分离特判**保留**（见 Task 1 scope）。

**Tech Stack:** Rust、serde_yaml 配置（mupc-core-bin core_config）、deploy YAML 模板。

**设计合同：** 核间 10 §12.1/§12.7 `[DESIGN_APPROVED: 2026-09-08]`、deploy.md §九；审查项 M-5/L-2/R-D 落点。

### 4.2 非阻断发现清单（建议随标记同批订正）

> 定性口径：以下均为**文档层**缺陷——**不影响可实施性、不删任何验收判据、不会使实施者构建出错误的东西**（每条都可在读列表/读邻行后自行消解）。依首轮 P-4b（"行号失准=须改、**不单独阻断**"）与第二轮 N-3（"同表不自洽=须改、非阻断"）的先例，判**非阻断**。

- **B-1（最值得订正）「不阻断控制」行残留不可达条件**（`:3449`）：
  该行写「**回读缺失或与写入值不一致** ⇒ `level = warning`」，而同表 `:3446` 明写"**不存在'拿到但与写入值不同'的第三态**"、判据②（`:3452`）已把该分支判为"**不可达**"并删除。
  **两种读法**：(a) 字面读 = 同表自相矛盾（"不一致"既可达又不可达）；(b) 宽读 = "设备回显不一致"是一种**情形**，其后果即 `Err` ⇒ `readback=None` ⇒ 归入"缺失"，故非矛盾、仅**冗余**。
  **建议**：改为「**回读未取得** ⇒ `warning`；取得（恒等于写入值）⇒ `info`」，与 `:3446` / `:3452` 三行对齐（改 4 字即可）。**判非阻断**：两种读法下实现形态相同（`level = if readback.is_some() { info } else { warning }`），不会误导实施；但鉴于本项目"零判别力断言"的反复教训（该行字面鼓励写一个**永不能红的用例**），建议同批清掉。

- **B-2 T5「改动面（4 处、跨 2 crate）」的 crate 计数与自身清单不符**（`:3542`）：

  **判非阻断**：M-1 的要害是"影响面**被系统性漏报**"，而此处 4 处改动**已逐条列全**（含 core-bin），错仅在括号里的计数；对照首轮 P-4b（引用失准不单独阻断）与"列表优先于括注"的读法，不至于误导实施。

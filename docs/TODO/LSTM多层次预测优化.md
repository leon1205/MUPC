# 论文吸收方案：LSTM 光伏/负荷预测增强

基于 `docs/paper/` 目录 11 篇学术论文的逐篇审读，筛选出 4 篇直接相关的预测方法论文，提出分层混合吸收方案。

---

## 筛选结果

| 论文 | 预测对象 | 核心方法 | 关联度 |
|------|---------|---------|--------|
| Paper 1: 基于VMD-ISPO-BiLSTM的低压台区负荷预测（袁晓燕） | 负荷 | VMD → MIC → IPSO → BiLSTM | 极高（台区级，15min步长对齐） |
| Paper 2: 基于MSSA-BiLSTM-AT的光伏功率预测（李帅） | 光伏 | MSSA → BiLSTM + Attention | 极高（输入特征与 MUPC 一致） |
| Paper 3: 基于光伏/负荷预测的光储微电网优化调度（王林） | 光伏+负荷 | CEEMDAN-SE + FTCN-MOSE + BiLSTM 误差修正 | 极高（双预测管线+误差修正，15min步长） |
| Paper 4: 分布式能源微网负荷预测分析及调度优化（冯涛） | 负荷 | SD-EMD-KPCA-LSTM | 低（CCHP热力系统，仅EMD/KPCA可参考） |

Paper 5/6/7/8 核心贡献在调度策略与配置优化，聚焦预测时搁置。Paper 9/10（柔性互联多台区）、Paper 11（移动储能）场景不相关。

## 混合吸收架构

4 篇论文的方法贡献预测管线中**不同阶段**，分层互补、互不冲突：

```
┌─────────────┬─────────────┬──────────────────┬────────────┬──────────────┐
│  特征工程    │  信号分解    │     神经网络       │   输出层    │   超参优化     │
├─────────────┼─────────────┼──────────────────┼────────────┼──────────────┤
│ Paper 1     │ Paper 1     │ Paper 2          │ MUPC 现有   │ Paper 1/2    │
│ MIC 筛选    │ VMD 分解    │ Attention 机制    │ 分位数预测   │ IPSO/MSSA    │
│             │     或      │        +         │ (P90)      │ 自动调参      │
│             │ Paper 3     │ Paper 1          │            │              │
│             │ CEEMDAN     │ BiLSTM 双向       │            │              │
│  (Paper 4)  │             │                  │            │              │
│  KPCA 降维   │             │ (Paper 3)        │            │              │
│             │             │ 误差修正BiLSTM     │            │              │
└─────────────┴─────────────┴──────────────────┴────────────┴──────────────┘
```

### 各层技术选型

#### 第一层：特征工程

| 来源 | 方法 | 说明 | 开销 |
|------|------|------|------|
| Paper 1 | **MIC 最大信息系数** | 量化气象因素与负荷/光伏的非线性相关性，筛选 top-K 输入特征 | 零（离线分析） |
| Paper 4 | KPCA 核主成分分析 | 降维去噪，但与 MIC 目标重叠，可作为备选 | 零（离线分析） |

**推荐**：优先 MIC。与后续所有方法正交，无冲突。

#### 第二层：信号分解（关键决策）

| 来源 | 方法 | 优势 | 劣势 |
|------|------|------|------|
| Paper 1 | **VMD** 变分模态分解 | 数学基础扎实，避免模态混叠，计算效率高 | 需预设模态数 K |
| Paper 3 | **CEEMDAN-SE** 自适应噪声完备集合经验模态分解 + 样本熵重构 | 自适应、无需预设模态数、SE 重构降低计算量 | 计算比 VMD 重 |

**推荐**：VMD 统一处理负荷和光伏（一套代码维护成本低）。CEEMDAN 对光伏波动性更友好，如需分别处理可负荷用 VMD、光伏用 CEEMDAN。

**关键优势**：分解在 CPU 上预处理，**零 NPU 推理开销**，对 RK3588 部署无影响。

#### 第三层：神经网络（核心增强）

| 来源 | 方法 | 说明 | NPU 开销 |
|------|------|------|---------|
| Paper 2 | **Attention 注意力机制** | 加在 LSTM 输出层，自动关注关键时段（辐照度突变、负荷峰谷） | ~5-10% |
| Paper 1 | **BiLSTM** 双向 LSTM | 替换单向 LSTM，捕获前后时序依赖 | ~2x 参数量 |

**推荐**：第一轮用 Attention only（投入产出比最高），验证收益后再评估 BiLSTM。

Paper 3 的两阶段误差修正（BiLSTM 修正残差）可作为第三轮增强。

#### 第四层：输出层

保持 MUPC 现有设计不变——15 步分位数预测（P90），前层改进对输出层透明。

#### 第五层：超参优化

| 来源 | 方法 | 特点 |
|------|------|------|
| Paper 1 | IPSO 改进粒子群 | 收敛快，实现简单 |
| Paper 2 | MSSA 多策略麻雀搜索 | 全局搜索更强（佳点集+反向学习+Corsi 扰动），但更复杂 |

**推荐**：MSSA 精度更高，IPSO 如果满足需求则更轻量。

## 推荐实施路径

### 第一轮（投入产出比最高）

```
VMD 信号分解 → LSTM（保持单向）+ Attention → 分位数输出
```

- 工作量：2-3 天
- 风险：低（VMD CPU 预处理，Attention 轻量）
- 预期收益：预测误差降低 10-20%

### 第二轮（验证后推进）

```
VMD → BiLSTM + Attention → 误差修正 BiLSTM → 分位数输出
```

- 工作量：3-5 天
- 风险：中（BiLSTM 参数量翻倍，需验证 NPU 推理延迟）
- 预期收益：累计误差降低 20-40%

### 第三轮（自动化）

```
MSSA 超参搜索 + 完整管线自动调优
```

- 工作量：2-3 天
- 风险：低（离线训练阶段，不影响推理）
- 预期收益：减少人工调参工作量

## 关键约束检查

| 约束 | 影响 | 结论 |
|------|------|------|
| RK3588 NPU 推理 | BiLSTM 参数量翻倍需谨慎 | 先上 Attention，保留单向 LSTM |
| 15min 步长 | 论文 Paper 1 和 Paper 3 均使用 15min 步长 | 对齐，无冲突 |
| 15 步输出（225min） | 论文多为单步或多步点预测，非分位数 | 保留 MUPC 分位数输出不改 |
| 输入特征（7 维→可能扩展） | MIC 筛选后可精简或扩展 | 正向优化 |

## 3. 集成链路验证

**全链测试已存在并复用，未重复造。** `mupc/crates/local-display/tests/full_chain.rs`（7 用例）链路：

```
mock 127.0.0.1 HTTP 桩（GET /v1/display/latest → 200 + DisplayFrame JSON）
  └─ DisplayChannelClient（真实 TCP 回环 + 手写 HTTP/1.1）
       └─ DisplayState（新鲜度 / 通道态 / 三态归一）
            └─ layout::render → OffscreenCanvas（像素直方图断言）
```

- 帧 JSON 为**字面量**（非 display-proto 序列化），避免「同源同错」掩盖契约偏差。
- 像素断言：SOC 值区/四卡非背景像素、区间色（青/橙）、降级灰 `--`、过期琥珀、断连覆盖区琥珀、恢复后不残留。
- `full_chain_run_loop_consumes_mock_frames` 覆盖**真实 `run_loop` 消费桩帧**（3 拍）+ 端点契约（命中 3、误路径 0），即设计 §10.1 要求的端到端 smoke。**故未新增额外 smoke。**
- 时序确定：`poll_once`/`Renderer` 接受**注入 Unix 毫秒**，超时/断连无需真等 2s/3s，无 flaky sleep。

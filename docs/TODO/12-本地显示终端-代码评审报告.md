## 2. `[警告]`（建议修，不阻断通过）

### W1 三相展示读失败会放大为「整条核间链路离线」的副作用（跨模块）
- 位置：`mupc/crates/intercore/src/transport/modbus.rs:602`（`read_three_phase`）→ `:290 read_input` → `:246 mark_offline`
- 问题：`read_input` 失败即 `mark_offline()`，而 `mark_offline` 会 `connected=false`、`started=false`、`mode=0xFF`，并**清空 `last_run_state`（DO1 灭）**。本特性新增 1Hz×2 笔读（电流段/有功段），RS485 上任一瞬时报文错误即触发上述复位，下一拍心跳又 `mark_online`，形成「离线→在线」抖动：DO1 闪断、控制侧模式/启停寄存器被反复重写（有 M1/`stopped_latched` 守卫，不会误启动，故非安全问题）。
- 进一步：若真机对 1022-1032 返回非法地址异常（PRD §6.4 明列「点表未覆盖/未接入」场景），将长期呈「PCS 离线」+ 三相 `Offline`，而 PRD §6.4 期望的是该字段 `NotRead`（PCS 实际在线）。
- 建议：展示读走**不带链路副作用**的读路径（或至少不改 `last_run_state`/`started`/`mode`）；对「非法数据地址」类异常按 `NotRead` 而非 `Offline` 归类。
- 备注：设计 §4.1 明确「仅共享 read_input 的锁与在/离线副作用」，故此项属**设计已认可范围**，但 `mark_offline` 的具体副作用集（清 last_run_state/复位 started/mode）超出设计描述字面；建议一并回写设计确认。

### W2 回环通道响应体长度无上限（内存失控面）
- 位置：`mupc/crates/local-display/src/channel.rs:164-181`（`Content-Length` → `body.resize(n, 0)`）
- 问题：`Content-Length` 直接用于预分配，无上限校验；异常/畸形对端（本机被占端口/代理）可致巨额分配或分配失败终止进程。PRD 4.4.3 明确要求「渲染端不得因通道对端行为异常而崩溃或内存失控（对不可信/畸形帧须有防护）」。
- 建议：加常量上限（如 1 MiB）超限即 `Err`（计入失败）；`head` 已有 64 KiB 上限，body 应对齐。

### W3 帧版本一致性未落地
- 位置：`display-proto/src/frame.rs:13 PROTO_VERSION`（生产）/ `channel.rs:182`、`state.rs:253`（消费）
- 问题：`version` 字段只发不校；`seq` 亦未用于设计 §3.3 所述「渲染端判连续/重排」（仅作重绘语义键）。跨版本（PROTO_VERSION 递增 + 语义变更）时可能静默按旧语义展示。PRD 4.4.1 要求「版本一致性手段」或「丢帧重传最新帧」——本设计取后者（轮询取最新快照）已满足底线，故非红线。
- 建议：解码后校验 `version == PROTO_VERSION`，不符即 `Err` 计入失败并告警（约 3 行）。

### W4 UI §5.3「新鲜度状态点」未落地（计算后被丢弃）
- 位置：`mupc/crates/local-display/src/layout.rs:453`（`let dot = live_dot_for(pv, snap.fresh);`）→ `:514`（`_dot: LiveDot`，形参从未使用）
- 问题：UI 设计（`[DESIGN_APPROVED]`）§5.3/§6.4 要求四卡卡头右侧 12px 状态点（●实时青 / ○空心灰停更 / 过期转琥珀），作为「不依赖颜色单一信道」的三态语法之一；实现计算了 `LiveDot` 却从不绘制，卡内降级仅靠 `--` + 角标。PRD 4.2.2 的「文字+语义色+图标三重冗余」在 PCS 态已满足，故不影响 PRD 验收，但属 UI 定案偏差 + 死参数。
- 建议：补绘卡头状态点（`fill_disc`/`fill_disc_outline` 已有原语），或删除该形参与调用以消除死代码，并在 UI 文档回写取舍。

### W5 佐证行「方向一致 ΣP」口径与 6.6 判据输入不同源
- 位置：`mupc/crates/local-display/src/layout.rs:403-405`（显示 `p_total`）vs `mupc/crates/mupc-core-bin/src/display_host.rs:189-202`（判据用 Σ`p_phase`=1029-1031）
- 问题：(a) 佐证行显示 REG1032（设备总有功）却标为「ΣP」，若 1032 ≠ Σ(1029..1031)，屏上数值与判据输入不一致；(b) 任一相为 `Dash` 时 `check_inconsistency` 返回 false，屏上却显示正向断言「方向一致」，属无据陈述（应为「佐证不可用」）。
- 建议：显示 Σ`p_phase`（或同时标注 1032 出处）；无有效 Σ 输入时显示「佐证不可用/未取数」而非「方向一致」。
